## 1. 推理引擎概述

### 1.1 什么是推理引擎？

推理引擎是专门用于执行深度学习模型推理的运行时系统，相比训练框架具有以下优势：

```
训练框架 (PyTorch/TensorFlow)     推理引擎 (ONNX Runtime/TensorRT)
┌─────────────────────────┐      ┌─────────────────────────┐
│  - 灵活的动态图          │      │  - 优化的静态图          │
│  - 支持自动微分          │      │  - 算子融合              │
│  - 开发调试友好          │  →   │  - 内存优化              │
│  - 性能非最优            │      │  - 硬件加速              │
└─────────────────────────┘      └─────────────────────────┘
```

### 1.2 推理引擎的核心优化

| 优化技术 | 描述 | 效果 |
|:---------|:-----|:-----|
| 算子融合 | 合并多个算子为一个 | 减少内存访问 |
| 内存优化 | 复用中间张量内存 | 降低内存占用 |
| 量化推理 | INT8/FP16 计算 | 2-4x 加速 |
| 并行执行 | 多流/多线程 | 提高吞吐量 |
| 图优化 | 常量折叠、死代码消除 | 减少计算量 |

### 1.3 主流推理引擎对比

```
                    通用性
                      ↑
                      │
    ONNX Runtime ●────┼────────────────
                      │
                      │        ● TensorRT
                      │
    ──────────────────┼────────────────→ 性能
                      │
              vLLM ●  │
           (LLM专用)  │
                      │
```

## 2. ONNX Runtime

### 2.1 ONNX 简介

ONNX (Open Neural Network Exchange) 是一种开放的模型格式：

```
PyTorch ─────┐
             │
TensorFlow ──┼──→ ONNX ──→ ONNX Runtime ──→ 多平台部署
             │              │
Keras ───────┘              ├─→ CPU (x86, ARM)
                            ├─→ GPU (CUDA, ROCm)
                            ├─→ NPU (各厂商)
                            └─→ Web (WebAssembly)
```

### 2.2 ONNX 模型结构

```protobuf
// ONNX 模型结构
ModelProto {
    ir_version: 8
    opset_import: [{"": 14}]
    producer_name: "pytorch"
    graph: GraphProto {
        name: "main_graph"
        input: [ValueInfoProto...]
        output: [ValueInfoProto...]
        node: [NodeProto...]      // 计算节点
        initializer: [TensorProto...]  // 权重
    }
}
```

### 2.3 Execution Provider (EP)

ONNX Runtime 通过 EP 支持不同硬件：

```python
import onnxruntime as ort

# 可用的 Execution Providers
providers = [
    'TensorrtExecutionProvider',   # NVIDIA TensorRT
    'CUDAExecutionProvider',       # NVIDIA CUDA
    'ROCMExecutionProvider',       # AMD ROCm
    'DmlExecutionProvider',        # DirectML (Windows)
    'CoreMLExecutionProvider',     # Apple CoreML
    'CPUExecutionProvider',        # CPU (默认)
]

# 创建会话时指定 EP
session = ort.InferenceSession(
    "model.onnx",
    providers=['CUDAExecutionProvider', 'CPUExecutionProvider']
)
```

### 2.6 IO Binding (高性能推理)

```python
# IO Binding 避免 CPU-GPU 数据拷贝
session = ort.InferenceSession("model.onnx", providers=['CUDAExecutionProvider'])

# 创建 IO Binding
io_binding = session.io_binding()

# 在 GPU 上分配输入
input_tensor = ort.OrtValue.ortvalue_from_numpy(
    input_data,
    device_type='cuda',
    device_id=0
)
io_binding.bind_input(
    name='input',
    device_type='cuda',
    device_id=0,
    element_type=np.float32,
    shape=input_data.shape,
    buffer_ptr=input_tensor.data_ptr()
)

# 在 GPU 上分配输出
io_binding.bind_output('output', device_type='cuda', device_id=0)

# 执行推理
session.run_with_iobinding(io_binding)

# 获取输出 (仍在 GPU 上)
output = io_binding.get_outputs()[0]
```

## 3. TensorRT

### 3.1 TensorRT 简介

TensorRT 是 NVIDIA 的高性能深度学习推理优化器和运行时：

```
PyTorch/ONNX Model
        │
        ▼
┌───────────────────┐
│   TensorRT 优化    │
│  ┌─────────────┐  │
│  │  层融合      │  │
│  │  精度校准    │  │
│  │  内核自动调优 │  │
│  │  内存优化    │  │
│  └─────────────┘  │
└───────────────────┘
        │
        ▼
   TensorRT Engine
   (序列化的优化模型)
```

### 3.2 核心优化技术

#### 3.2.1 层融合 (Layer Fusion)

```
优化前:                    优化后:
┌─────┐                   ┌─────────────┐
│Conv │                   │             │
└──┬──┘                   │ Conv+BN+ReLU│
   │                      │  (融合内核)  │
┌──▼──┐                   │             │
│ BN  │         →         └─────────────┘
└──┬──┘
   │
┌──▼──┐
│ReLU │
└─────┘

内存访问: 3次 → 1次
内核启动: 3次 → 1次
```

#### 3.2.2 精度校准 (Calibration)

```python
# INT8 量化需要校准数据
class CalibrationDataset:
    def __init__(self, data_loader, num_samples=1000):
        self.data = []
        for i, (images, _) in enumerate(data_loader):
            if i >= num_samples:
                break
            self.data.append(images.numpy())

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        return self.data[idx]

# 校准过程
# 1. 收集激活值分布
# 2. 计算最优量化参数
# 3. 最小化量化误差
```

#### 3.2.3 内核自动调优 (Kernel Auto-Tuning)

```
TensorRT 会为每个层选择最优实现:

Conv2d (3x3, 64 channels):
  ├─ cuDNN implicit GEMM    → 测试延迟: 0.12ms
  ├─ cuDNN Winograd         → 测试延迟: 0.08ms ✓ 选择
  ├─ cuDNN FFT              → 测试延迟: 0.15ms
  └─ TensorRT native        → 测试延迟: 0.10ms
```

### 3.3 构建 TensorRT 引擎

```python
import tensorrt as trt

# 创建 Builder
logger = trt.Logger(trt.Logger.WARNING)
builder = trt.Builder(logger)

# 创建网络
network = builder.create_network(
    1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH)
)

# 解析 ONNX 模型
parser = trt.OnnxParser(network, logger)
with open("model.onnx", "rb") as f:
    parser.parse(f.read())

# 配置构建选项
config = builder.create_builder_config()
config.set_memory_pool_limit(trt.MemoryPoolType.WORKSPACE, 1 << 30)  # 1GB

# 设置精度
config.set_flag(trt.BuilderFlag.FP16)  # 启用 FP16
# config.set_flag(trt.BuilderFlag.INT8)  # 启用 INT8

# 构建引擎
engine = builder.build_serialized_network(network, config)

# 保存引擎
with open("model.engine", "wb") as f:
    f.write(engine)
```

### 3.4 TensorRT 推理

```python
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoinit

# 加载引擎
runtime = trt.Runtime(logger)
with open("model.engine", "rb") as f:
    engine = runtime.deserialize_cuda_engine(f.read())

# 创建执行上下文
context = engine.create_execution_context()

# 分配内存
inputs = []
outputs = []
bindings = []

for i in range(engine.num_io_tensors):
    name = engine.get_tensor_name(i)
    shape = engine.get_tensor_shape(name)
    dtype = trt.nptype(engine.get_tensor_dtype(name))
    size = trt.volume(shape)

    # 分配设备内存
    device_mem = cuda.mem_alloc(size * dtype().itemsize)
    bindings.append(int(device_mem))

    if engine.get_tensor_mode(name) == trt.TensorIOMode.INPUT:
        inputs.append({'name': name, 'mem': device_mem, 'shape': shape})
    else:
        outputs.append({'name': name, 'mem': device_mem, 'shape': shape})

# 执行推理
stream = cuda.Stream()

# 拷贝输入到 GPU
cuda.memcpy_htod_async(inputs[0]['mem'], input_data, stream)

# 执行
context.execute_async_v3(stream_handle=stream.handle)

# 拷贝输出到 CPU
output_data = np.empty(outputs[0]['shape'], dtype=np.float32)
cuda.memcpy_dtoh_async(output_data, outputs[0]['mem'], stream)

stream.synchronize()
```

## 4. vLLM

### 4.1 vLLM 简介

vLLM 是专门为大语言模型 (LLM) 设计的高性能推理引擎：

```
传统 LLM 推理:              vLLM 推理:
┌─────────────────┐        ┌─────────────────┐
│  每个请求独立    │        │  PagedAttention │
│  KV Cache       │        │  共享 KV Cache  │
│                 │        │                 │
│  内存浪费严重    │   →    │  内存利用率高   │
│  吞吐量低       │        │  吞吐量高       │
└─────────────────┘        └─────────────────┘
```

### 4.2 PagedAttention 原理

传统 KV Cache 问题：
```
请求 1: [████████████░░░░░░░░]  预分配但未使用
请求 2: [██████░░░░░░░░░░░░░░]  大量内存浪费
请求 3: [████████████████░░░░]
        ↑ 实际使用    ↑ 浪费
```

PagedAttention 解决方案：
```
物理内存块 (Pages):
┌────┬────┬────┬────┬────┬────┬────┬────┐
│ P0 │ P1 │ P2 │ P3 │ P4 │ P5 │ P6 │ P7 │
└────┴────┴────┴────┴────┴────┴────┴────┘
  ↑    ↑    ↑    ↑    ↑    ↑
  │    │    │    │    │    │
请求1: [P0, P1, P2]
请求2: [P3, P4]
请求3: [P5, P6, P7]

- 按需分配，无浪费
- 支持动态增长
- 内存利用率接近 100%
```


## 5. 性能优化技术

### 5.1 批处理优化

```python
# 动态批处理
class DynamicBatcher:
    def __init__(self, max_batch_size=32, max_wait_time=0.01):
        self.max_batch_size = max_batch_size
        self.max_wait_time = max_wait_time
        self.queue = []

    async def add_request(self, request):
        self.queue.append(request)

        # 等待批次填满或超时
        if len(self.queue) >= self.max_batch_size:
            return await self.process_batch()

        await asyncio.sleep(self.max_wait_time)
        return await self.process_batch()

    async def process_batch(self):
        batch = self.queue[:self.max_batch_size]
        self.queue = self.queue[self.max_batch_size:]
        return await self.model.infer_batch(batch)
```

### 7.2 模型分片推理

```python
class ShardedONNXModel:
    """大模型分片推理"""
    def __init__(self, shard_paths):
        self.sessions = []
        for path in shard_paths:
            sess = ort.InferenceSession(path, providers=['CUDAExecutionProvider'])
            self.sessions.append(sess)
    
    def forward(self, x):
        for sess in self.sessions:
            outputs = sess.run(None, {'input': x})
            x = outputs[0]
        return x
```

### 7.3 异步推理

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncONNXInference:
    def __init__(self, model_path, max_workers=4):
        self.session = ort.InferenceSession(model_path)
        self.executor = ThreadPoolExecutor(max_workers=max_workers)
    
    async def infer_async(self, input_data):
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            self.executor,
            lambda: self.session.run(None, {'input': input_data})
        )
        return result
    
    async def batch_infer(self, inputs):
        tasks = [self.infer_async(inp) for inp in inputs]
        return await asyncio.gather(*tasks)
```

## 8. TensorRT 高级技术

### 8.1 多流并行

```python
class MultiStreamTRTEngine:
    """多 CUDA 流并行推理"""
    def __init__(self, engine_path, num_streams=2):
        self.runtime = trt.Runtime(trt.Logger())
        with open(engine_path, 'rb') as f:
            self.engine = self.runtime.deserialize_cuda_engine(f.read())
        
        self.contexts = []
        self.streams = []
        for _ in range(num_streams):
            self.contexts.append(self.engine.create_execution_context())
            self.streams.append(cuda.Stream())
    
    def infer_parallel(self, inputs):
        results = []
        for i, inp in enumerate(inputs):
            stream_idx = i % len(self.streams)
            ctx = self.contexts[stream_idx]
            stream = self.streams[stream_idx]
            
            # 异步执行
            cuda.memcpy_htod_async(self.d_input, inp, stream)
            ctx.execute_async_v3(stream_handle=stream.handle)
            cuda.memcpy_dtoh_async(self.h_output, self.d_output, stream)
            results.append(self.h_output.copy())
        
        # 同步所有流
        for stream in self.streams:
            stream.synchronize()
        
        return results
```

```python
class ThroughputOptimizer:
    """吞吐量优化器"""
    def __init__(self, model, target_latency_ms=100):
        self.model = model
        self.target_latency = target_latency_ms
    
    def find_optimal_batch_size(self, sample_input):
        """二分搜索最优批大小"""
        low, high = 1, 256
        optimal = 1
        
        while low <= high:
            mid = (low + high) // 2
            batch = self._create_batch(sample_input, mid)
            
            latency = self._measure_latency(batch)
            
            if latency <= self.target_latency:
                optimal = mid
                low = mid + 1
            else:
                high = mid - 1
        
        return optimal
    
    def _measure_latency(self, batch, warmup=10, iterations=100):
        # 预热
        for _ in range(warmup):
            self.model(batch)
        
        # 测量
        start = time.perf_counter()
        for _ in range(iterations):
            self.model(batch)
        end = time.perf_counter()
        
        return (end - start) / iterations * 1000  # ms
```

```python
class ResilientInferenceService:
    """支持降级的推理服务"""
    def __init__(self, primary_engine, fallback_engine):
        self.primary = primary_engine
        self.fallback = fallback_engine
        self.use_fallback = False
        self.error_count = 0
        self.error_threshold = 5
    
    def infer(self, input_data):
        if self.use_fallback:
            return self._fallback_infer(input_data)
        
        try:
            result = self.primary.infer(input_data)
            self.error_count = 0
            return result
        except Exception as e:
            self.error_count += 1
            if self.error_count >= self.error_threshold:
                self.use_fallback = True
            return self._fallback_infer(input_data)
    
    def _fallback_infer(self, input_data):
        return self.fallback.infer(input_data)
```
