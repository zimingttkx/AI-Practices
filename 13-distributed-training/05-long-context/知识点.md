# Ring Attention 知识点

## 1. 概述

### 1.1 背景与动机

标准 Transformer 注意力的问题：
- 内存复杂度 O(L²)，L 为序列长度
- 单设备内存限制了最大序列长度
- 长文档、长视频等场景受限

Ring Attention 的解决方案：**分布式序列并行**
- 将序列分布到多个设备
- 通过环形通信传递 KV
- 每个设备只需 O(L/P) 内存 (P = 设备数)

### 1.2 核心优势

| 特性 | 标准 Attention | Ring Attention |
|:-----|:---------------|:---------------|
| 内存/设备 | O(L²) | O((L/P)²) |
| 最大序列长度 | ~32K | ~1M+ |
| 通信开销 | 无 | O(P) 次环形传递 |
| 计算效率 | 100% | ~95%+ |

## 2. 理论基础

### 2.1 在线 Softmax 算法

标准 softmax 需要完整序列：
$$\text{softmax}(x)_i = \frac{e^{x_i}}{\sum_j e^{x_j}}$$

在线 softmax 支持分块累积：
```
对于每个新块:
1. 更新最大值: m_new = max(m_old, m_block)
2. 重新缩放: scale = exp(m_old - m_new)
3. 更新分母: d_new = d_old * scale + sum(exp(x_block - m_new))
4. 更新输出: o_new = o_old * scale + softmax_block @ v_block
```

### 2.2 环形通信模式

```
设备 0 ──K,V──► 设备 1 ──K,V──► 设备 2 ──K,V──► 设备 3
   ▲                                              │
   └──────────────────K,V─────────────────────────┘
```

每个设备：
1. 持有 Q 的一部分 (固定)
2. 接收并处理所有 K,V 块 (轮转)
3. 累积注意力输出

## 3. 架构设计

### 3.1 Ring Attention 流程

```
┌─────────────────────────────────────────────────────────┐
│                    Ring Attention                        │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Device 0        Device 1        Device 2        Device 3│
│  ┌─────┐         ┌─────┐         ┌─────┐         ┌─────┐│
│  │Q0,K0│         │Q1,K1│         │Q2,K2│         │Q3,K3││
│  │V0   │         │V1   │         │V2   │         │V3   ││
│  └──┬──┘         └──┬──┘         └──┬──┘         └──┬──┘│
│     │               │               │               │    │
│  Step 0: 计算本地 Q_i @ K_i^T                           │
│     │               │               │               │    │
│  Step 1: 环形传递 K,V                                    │
│     │──────────────►│──────────────►│──────────────►│    │
│     │◄──────────────────────────────────────────────│    │
│     │               │               │               │    │
│  Step 2: 计算 Q_i @ K_{i+1}^T                           │
│     │               │               │               │    │
│  ... 重复 P-1 次 ...                                     │
│     │               │               │               │    │
│  ┌──▼──┐         ┌──▼──┐         ┌──▼──┐         ┌──▼──┐│
│  │ O0  │         │ O1  │         │ O2  │         │ O3  ││
│  └─────┘         └─────┘         └─────┘         └─────┘│
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 3.2 代码示例

```python
from ring_attention import (
    RingAttentionConfig, 
    RingAttention,
    SequenceParallel,
    create_ring_attention,
)

# 创建配置
config = RingAttentionConfig(
    d_model=768,
    n_heads=12,
    block_size=1024,  # 每设备序列长度
    n_devices=8,      # 8 GPU

# 最大支持序列长度
print(f"Max seq len: {config.max_seq_len}")  # 8192

# 创建 Ring Attention
attn = RingAttention(config)

# 前向传播 (单设备模拟)
x = np.random.randn(batch, block_size, d_model)

```

## 4. 实践指南

### 4.1 超参数选择

| 参数 | 推荐值 | 说明 |
|:-----|:-------|:-----|
| block_size | 1024-4096 | 每设备序列长度 |
| n_devices | 4-64 | 环大小 |
| causal | True | 语言模型必须 |

### 4.2 性能优化

1. **重叠通信与计算**: 在计算当前块时预取下一块
2. **Flash Attention**: 结合 Flash Attention 进一步优化
3. **梯度检查点**: 减少激活内存

### 4.3 适用场景

- 长文档理解 (100K+ tokens)
- 长视频处理
- 代码仓库分析
- 多轮对话历史
