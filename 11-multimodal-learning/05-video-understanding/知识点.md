# Video Understanding 知识点

## 1. 概述

### 1.1 背景与动机

视频理解是多模态学习的重要分支，相比静态图像，视频包含丰富的时序信息：
- **时间维度**：动作、事件的发展过程
- **因果关系**：前后帧之间的逻辑联系
- **长程依赖**：跨越多帧的语义理解

Video-LLaVA 将 LLaVA 的图像理解能力扩展到视频领域，实现：
- 视频问答 (Video QA)
- 视频描述生成 (Video Captioning)
- 视频推理 (Video Reasoning)

### 1.2 核心挑战

| 挑战 | 描述 | 解决方案 |
|:-----|:-----|:---------|
| 计算开销 | 视频帧数多，计算量大 | 帧采样、特征压缩 |
| 时序建模 | 捕获跨帧时序关系 | Temporal Transformer/LSTM |
| 长视频理解 | 长视频的全局理解 | 层次化表示、记忆机制 |
| 视频-语言对齐 | 视频特征与语言空间对齐 | 投影层、对比学习 |

## 2. 架构设计

### 2.1 整体流程

```
视频输入 [B, T, 3, H, W]
    │
    ▼
┌─────────────────┐
│   帧采样        │  均匀/随机/关键帧采样
│   (T → N帧)     │
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  视觉编码器     │  ViT: 每帧 → patch tokens
│  (VisionEncoder)│  [B*N, P+1, D_v]
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   时序建模      │  Transformer/LSTM/Pooling
│ (TemporalModel) │  跨帧注意力
└─────────────────┘
    │
    ▼
┌─────────────────┐
│   视频投影      │  D_v → D_llm
│ (VideoProjector)│
└─────────────────┘
    │
    ▼
[视频 tokens] ─────┐
                   │
文本输入 ──────────┼──→ LLaMA ──→ 输出
                   │
```

### 2.2 帧采样策略

```python
class SamplingStrategy(Enum):
    UNIFORM = "uniform"      # 均匀采样：indices = linspace(0, T-1, N)
    RANDOM = "random"        # 随机采样：indices = randperm(T)[:N]
    KEYFRAME = "keyframe"    # 关键帧：基于场景变化检测
    ADAPTIVE = "adaptive"    # 自适应：根据内容动态调整
```

**均匀采样公式**：
$$
\text{indices}_i = \lfloor \frac{i \cdot (T-1)}{N-1} \rfloor, \quad i = 0, 1, ..., N-1
$$

### 2.3 视觉编码器

基于 ViT (Vision Transformer) 架构：

```
图像 [3, H, W]
    │
    ▼
┌─────────────────┐
│  Patch Embed    │  Conv2d(3, D, kernel=P, stride=P)
│  [P×P patches]  │  → [num_patches, D]
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  + CLS Token    │  [1, D] 可学习
│  + Position Emb │  [num_patches+1, D]
└─────────────────┘
    │
    ▼
┌─────────────────┐
│  Transformer    │  L 层 Self-Attention + FFN
│  Encoder        │
└─────────────────┘
    │
    ▼
[num_patches+1, D]
```

**Patch 数量计算**：
$$
\text{num\_patches} = \left(\frac{H}{P}\right) \times \left(\frac{W}{P}\right)
$$

### 2.4 时序建模

#### 2.4.1 Temporal Transformer

```python
class TemporalTransformer:
    """
    输入: [B, N, D]  # N 帧的 CLS 特征
    输出: [B, N, D]  # 时序增强后的特征
    
    流程:
    1. 添加时序位置编码
    2. Transformer Encoder 处理
    3. 跨帧注意力捕获时序关系
    """
```

**时序位置编码**：
$$
PE_{(t, 2i)} = \sin\left(\frac{t}{10000^{2i/d}}\right)
$$
$$
PE_{(t, 2i+1)} = \cos\left(\frac{t}{10000^{2i/d}}\right)
$$

#### 2.4.2 Temporal LSTM

```python
class TemporalLSTM:
    """
    双向 LSTM 捕获时序依赖
    适合顺序性强的视频内容
    """
```

#### 2.4.3 Temporal Pooling

```python
class TemporalPooling:
    """
    简单高效的时序聚合:
    - Mean Pooling: 平均所有帧
    - Max Pooling: 取最显著特征
    - Attention Pooling: 加权聚合
    """
```

**注意力池化公式**：
$$
\alpha_t = \text{softmax}(W_2 \tanh(W_1 h_t))
$$
$$
\text{output} = \sum_{t=1}^{N} \alpha_t h_t
$$

### 2.5 视频投影层

将视觉特征映射到语言模型空间：

```python
# Linear Projector
projector = nn.Linear(D_vision, D_llm)

# MLP Projector (更强表达能力)
projector = nn.Sequential(
    nn.Linear(D_vision, D_llm),
    nn.GELU(),
    nn.Linear(D_llm, D_llm)
)
```

### 2.6 语言模型 (LLaMA)

采用 LLaMA 风格的 Decoder-only Transformer：

**核心组件**：
- **RMSNorm**: 比 LayerNorm 更高效
- **RoPE**: 旋转位置编码，支持长序列外推
- **SwiGLU**: 门控激活函数

**RMSNorm 公式**：
$$
\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^{d}x_i^2 + \epsilon}} \cdot \gamma
$$

**RoPE 公式**：
$$
R_\theta^d = \begin{pmatrix}
\cos\theta & -\sin\theta \\
\sin\theta & \cos\theta
\end{pmatrix}
$$

**SwiGLU 公式**：
$$
\text{SwiGLU}(x) = \text{Swish}(xW_1) \otimes (xW_2)
$$

### 3.2 前向传播

```python
def forward(self, input_ids, videos, attention_mask=None, labels=None):
    # 1. 编码视频
    video_tokens = self.encode_video(videos)  # [B, V, D]
    
    # 2. 嵌入文本
    text_embeds = self.embed_tokens(input_ids)  # [B, T, D]
    
    # 3. 拼接视频和文本
    inputs_embeds = torch.cat([video_tokens, text_embeds], dim=1)
    
    # 4. LLM 生成
    logits = self.language_model(inputs_embeds=inputs_embeds)
    
    # 5. 计算损失
    if labels is not None:
        loss = cross_entropy(logits, labels)
    
    return {"logits": logits, "loss": loss}
```

### 3.3 视频编码流程

```python
def encode_video(self, video, sampling_strategy=SamplingStrategy.UNIFORM):
    # 1. 帧采样
    sampled_frames = sample_frames(video, self.num_frames, sampling_strategy)
    # [B, N, 3, H, W]
    
    # 2. 调整大小
    resized_frames = resize_frames(sampled_frames, (224, 224))
    
    # 3. 展平批次维度
    frames_flat = resized_frames.view(B*N, 3, H, W)
    
    # 4. 视觉编码
    frame_features = self.vision_encoder(frames_flat)
    # [B*N, num_patches+1, D_v]
    
    # 5. 时序建模
    cls_features = frame_features[:, 0].view(B, N, D_v)
    temporal_features = self.temporal_model(cls_features)
    
    # 6. 投影到语言空间
    video_tokens = self.video_projector(temporal_features)
    
    return video_tokens
```

## 4. 模型变体

### 4.1 模型规模

| 规模 | Vision Layers | Vision Width | LLM Layers | LLM Hidden |
|:-----|:-------------|:-------------|:-----------|:-----------|
| Tiny | 6 | 384 | 8 | 512 |
| Base | 24 | 1024 | 32 | 4096 |
| Large | 32 | 1280 | 40 | 5120 |

### 4.2 时序模式对比

| 模式 | 优点 | 缺点 | 适用场景 |
|:-----|:-----|:-----|:---------|
| Transformer | 全局注意力，并行计算 | 计算量大 | 复杂时序关系 |
| LSTM | 顺序建模，参数少 | 难以并行 | 顺序性强的视频 |
| Pooling | 简单高效 | 丢失时序信息 | 静态场景为主 |

## 6. 训练策略

### 6.1 预训练

1. **视频-文本对比学习**：对齐视频和文本表示
2. **视频描述生成**：学习生成视频描述
3. **视频问答**：学习回答视频相关问题

### 6.2 微调

1. **指令微调**：使用指令数据集微调
2. **LoRA 微调**：低秩适应，减少参数量
3. **全参数微调**：在特定任务上全量微调

### 6.3 数据增强

- **时间增强**：随机时间裁剪、速度变化
- **空间增强**：随机裁剪、翻转、颜色抖动
- **混合增强**：MixUp、CutMix

## 7. 性能优化

### 7.1 计算优化

| 技术 | 描述 | 加速比 |
|:-----|:-----|:-------|
| 帧采样 | 减少处理帧数 | 2-4x |

| Flash Attention | 高效注意力计算 | 2-3x |
| 混合精度 | FP16/BF16 训练 | 1.5-2x |
