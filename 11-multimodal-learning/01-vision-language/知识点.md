## 1. 多模态学习基础

### 1.1 什么是多模态学习？

**多模态学习** (Multimodal Learning) 是指同时处理和融合多种类型数据（如图像、文本、音频、视频）的机器学习方法。

**为什么需要多模态？**

```
人类认知的多模态性:
┌─────────────────────────────────────────────────────────┐
│  视觉 (Vision)     → 看到物体、场景、动作              │
│  听觉 (Audio)      → 听到声音、语音、音乐              │
│  语言 (Language)   → 理解文字、对话、指令              │
│  触觉 (Touch)      → 感知纹理、温度、压力              │
│                                                         │
│  大脑自然地融合这些信息形成完整的世界理解              │
└─────────────────────────────────────────────────────────┘
```

**多模态学习的优势：**

| 优势 | 说明 | 示例 |
|:-----|:-----|:-----|
| 信息互补 | 不同模态提供不同视角 | 图像显示外观，文本描述功能 |
| 鲁棒性增强 | 单一模态缺失时仍可工作 | 噪声图像+清晰文本 |
| 语义对齐 | 建立跨模态的语义关联 | "红苹果"对应红色苹果图像 |
| 零样本迁移 | 利用语言知识迁移到视觉 | 未见过的类别通过文本描述识别 |

### 1.3 多模态融合策略

**早期融合 (Early Fusion)**

```python
# 在输入层面融合
def early_fusion(image, text):
    # 提取原始特征
    image_raw = flatten(image)  # [B, H*W*C]
    text_raw = embed(text)      # [B, L*D]
    
    # 直接拼接
    fused = concat([image_raw, text_raw], dim=-1)
    
    # 联合编码
    output = joint_encoder(fused)
    return output

优点: 模态间交互充分
缺点: 计算量大，难以处理异构数据
```

**晚期融合 (Late Fusion)**

```python
# 在决策层面融合
def late_fusion(image, text):
    # 独立编码
    image_feat = image_encoder(image)  # [B, D]
    text_feat = text_encoder(text)     # [B, D]
    
    # 特征融合
    fused = fusion_layer(image_feat, text_feat)
    
    # 最终预测
    output = classifier(fused)
    return output

优点: 模块化，易于预训练
缺点: 模态交互不够深入
```

**交叉注意力融合 (Cross-Attention Fusion)**

```python
# 通过注意力机制融合
def cross_attention_fusion(image_feat, text_feat):
    # 文本作为 Query，图像作为 Key/Value
    text_attended = cross_attn(
        query=text_feat,
        key=image_feat,
        value=image_feat
    )
    
    # 图像作为 Query，文本作为 Key/Value
    image_attended = cross_attn(
        query=image_feat,
        key=text_feat,
        value=text_feat
    )
    
    return image_attended, text_attended

优点: 动态交互，可解释性强
缺点: 计算复杂度 O(N*M)
```

```
目标: 学习共享的嵌入空间，使匹配的图文对距离近，不匹配的距离远

        图像空间                    共享嵌入空间                   文本空间
    ┌───────────┐              ┌─────────────────┐              ┌───────────┐

    └───────────┘              └─────────────────┘              └───────────┘

                               匹配对距离近

```

```
目标: 学习条件生成分布 P(text|image) 或 P(image|text)

图像描述生成:
```

## 2. CLIP 对比学习

### 2.1 核心思想

CLIP (Contrastive Language-Image Pre-training) 是 OpenAI 在 2021 年提出的里程碑式工作，通过对比学习将图像和文本映射到共享的嵌入空间。

**关键创新：**

1. **大规模网络数据**: 使用 4 亿图文对进行预训练
2. **自然语言监督**: 无需人工标注，使用网络爬取的图文对
3. **零样本迁移**: 无需微调即可应用于下游任务
4. **开放词汇**: 不受预定义类别限制

### 2.2 架构设计

```
                        CLIP 架构
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│     图像输入                           文本输入             │
│        ↓                                  ↓                 │
│  ┌──────────────┐                  ┌──────────────┐        │
│  │ 图像编码器   │                  │ 文本编码器   │        │
│  │ (ViT/ResNet) │                  │ (Transformer)│        │
│  └──────────────┘                  └──────────────┘        │
│        ↓                                  ↓                 │
│  ┌──────────────┐                  ┌──────────────┐        │
│  │ 投影层       │                  │ 投影层       │        │
│  │ (Linear)     │                  │ (Linear)     │        │
│  └──────────────┘                  └──────────────┘        │
│        ↓                                  ↓                 │
│  ┌──────────────┐                  ┌──────────────┐        │
│  │ L2 归一化    │                  │ L2 归一化    │        │
│  └──────────────┘                  └──────────────┘        │
│        ↓                                  ↓                 │
│   图像特征 I                         文本特征 T            │
│   [N, D]                             [N, D]                │
│        └──────────────┬──────────────┘                     │
│                       ↓                                     │
│              相似度矩阵 S = I @ T.T                        │
│                    [N, N]                                   │
│                       ↓                                     │
│              对比损失 (InfoNCE)                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 InfoNCE 损失函数详解

**数学公式：**

对于一个 batch 中的 N 个图文对 {(I_i, T_i)}:

```
图像到文本损失:
L_i2t = -1/N * Σᵢ log( exp(sim(Iᵢ, Tᵢ)/τ) / Σⱼ exp(sim(Iᵢ, Tⱼ)/τ) )

文本到图像损失:
L_t2i = -1/N * Σᵢ log( exp(sim(Tᵢ, Iᵢ)/τ) / Σⱼ exp(sim(Tᵢ, Iⱼ)/τ) )

总损失:
L_CLIP = (L_i2t + L_t2i) / 2

其中:
- sim(I, T) = I · T (余弦相似度，因为已经 L2 归一化)
- τ 是可学习的温度参数 (初始化为 0.07)
```

**直观理解：**

```
相似度矩阵 (N=4 的例子):
                T₁    T₂    T₃    T₄
           ┌─────────────────────────┐
      I₁   │ 0.9   0.1   0.2   0.1  │  ← 希望 (I₁,T₁) 最大
      I₂   │ 0.2   0.8   0.1   0.3  │  ← 希望 (I₂,T₂) 最大
      I₃   │ 0.1   0.2   0.9   0.1  │  ← 希望 (I₃,T₃) 最大
      I₄   │ 0.3   0.1   0.2   0.7  │  ← 希望 (I₄,T₄) 最大
           └─────────────────────────┘
                    ↑
           对角线元素应该最大 (正样本)
           非对角线元素应该小 (负样本)
```

**温度参数的作用：**

```python
# 温度参数控制分布的锐度
def softmax_with_temperature(logits, temperature):
    return softmax(logits / temperature)

# τ 小 → 分布更尖锐 → 更关注最相似的样本
# τ 大 → 分布更平滑 → 更均匀地考虑所有样本

# CLIP 使用可学习的 log(τ)，初始化为 log(1/0.07) ≈ 2.66
logit_scale = nn.Parameter(torch.ones([]) * np.log(1 / 0.07))
```

### 2.4 代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CLIP(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.vision_encoder = VisionEncoder(config)
        self.text_encoder = TextEncoder(config)
        self.vision_projection = nn.Linear(config.vision_dim, config.embed_dim)
        self.text_projection = nn.Linear(config.text_dim, config.embed_dim)
        self.logit_scale = nn.Parameter(torch.ones([]) * np.log(1 / 0.07))
    
    def encode_image(self, images):
        """编码图像"""
        features = self.vision_encoder(images)
        features = self.vision_projection(features)
        features = F.normalize(features, dim=-1)
        return features
    
    def encode_text(self, input_ids, attention_mask=None):
        """编码文本"""
        features = self.text_encoder(input_ids, attention_mask)
        features = self.text_projection(features)
        features = F.normalize(features, dim=-1)
        return features
    
    def forward(self, images, input_ids, attention_mask=None):
        """前向传播"""
        image_features = self.encode_image(images)
        text_features = self.encode_text(input_ids, attention_mask)
        
        # 计算相似度
        logit_scale = self.logit_scale.exp()
        logits_per_image = logit_scale * image_features @ text_features.t()
        logits_per_text = logits_per_image.t()
        
        return logits_per_image, logits_per_text

def clip_loss(logits_per_image, logits_per_text):
    """CLIP 对比损失"""
    batch_size = logits_per_image.shape[0]
    labels = torch.arange(batch_size, device=logits_per_image.device)
    
    loss_i2t = F.cross_entropy(logits_per_image, labels)
    loss_t2i = F.cross_entropy(logits_per_text, labels)
    
    return (loss_i2t + loss_t2i) / 2
```

### 2.5 零样本分类

CLIP 最强大的能力之一是零样本分类：

```python
def zero_shot_classify(model, image, class_names, prompt_template="a photo of a {}"):
    """
    零样本分类
    
    Args:
        model: CLIP 模型
        image: 输入图像 [1, 3, H, W]
        class_names: 类别名称列表 ["cat", "dog", "bird", ...]
        prompt_template: 提示模板
    
    Returns:
        预测的类别索引和概率分布
    """
    # 1. 构造文本提示
    prompts = [prompt_template.format(name) for name in class_names]
    
    # 2. 编码图像
    image_features = model.encode_image(image)  # [1, D]
    
    # 3. 编码所有类别文本
    text_features = model.encode_text(tokenize(prompts))  # [C, D]
    
    # 4. 计算相似度
    similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)
    
    # 5. 返回预测
    pred_idx = similarity.argmax().item()
    return pred_idx, similarity[0]

# 使用示例
class_names = ["cat", "dog", "bird", "car", "airplane"]
pred_idx, probs = zero_shot_classify(model, image, class_names)
print(f"预测类别: {class_names[pred_idx]}")
print(f"概率分布: {probs}")
```

```python
def ensemble_zero_shot(model, image, class_names, prompts):
    """提示集成的零样本分类"""
    all_text_features = []
    
    for prompt_template in prompts:
        texts = [prompt_template.format(**{"class": name}) for name in class_names]
        text_features = model.encode_text(tokenize(texts))
        all_text_features.append(text_features)
    
    # 平均所有提示的特征
    text_features = torch.stack(all_text_features).mean(dim=0)

    # 计算相似度

    similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)
    
    return similarity
```

### 2.7 CLIP 的局限性与改进

**局限性：**

| 问题 | 描述 | 示例 |
|:-----|:-----|:-----|
| 细粒度理解弱 | 难以区分相似物体的细微差异 | 不同品种的狗 |
| 计数能力差 | 无法准确计数 | "3只猫" vs "5只猫" |
| 空间关系弱 | 难以理解位置关系 | "左边的红球" |
| 组合泛化差 | 未见过的属性-物体组合 | "紫色的香蕉" |
| 文本理解有限 | 复杂句子理解困难 | 长句、否定句 |

**改进方向：**

```
1. 更大规模数据
   CLIP: 400M → LAION-5B: 5B 图文对

2. 更好的视觉编码器
   ViT-B/32 → ViT-L/14 → ViT-G/14

3. 区域级对比学习
   CLIP (图像级) → RegionCLIP (区域级)

4. 负样本挖掘
   随机负样本 → 困难负样本挖掘

5. 多任务学习
   CLIP (对比) → BLIP (对比+匹配+生成)
```

## 3. BLIP 多任务学习

### 3.1 核心思想

BLIP (Bootstrapping Language-Image Pre-training) 是 Salesforce 在 2022 年提出的统一视觉-语言预训练框架。

**关键创新：**

1. **多任务统一架构**: 同时支持理解和生成任务
2. **CapFilt 数据清洗**: 自动过滤噪声数据
3. **编码器-解码器混合**: 灵活的架构设计

### 3.3 三大预训练任务详解

**任务1: ITC (Image-Text Contrastive)**

```python
def forward_itc(self, images, input_ids):
    """图像-文本对比学习"""
    # 编码图像
    image_embeds = self.vision_encoder(images)
    image_feat = F.normalize(self.vision_proj(image_embeds[:, 0]), dim=-1)
    
    # 编码文本 (单模态)
    text_embeds = self.text_encoder(input_ids)
    text_feat = F.normalize(self.text_proj(text_embeds[:, 0]), dim=-1)
    
    # 计算相似度
    sim_i2t = image_feat @ text_feat.t() / self.temp
    sim_t2i = text_feat @ image_feat.t() / self.temp
    
    return sim_i2t, sim_t2i

# ITC 损失 (同 CLIP)
loss_itc = (F.cross_entropy(sim_i2t, labels) + 
            F.cross_entropy(sim_t2i, labels)) / 2
```

**任务2: ITM (Image-Text Matching)**

```python
def forward_itm(self, images, input_ids, labels):
    """图像-文本匹配"""
    # 编码图像
    image_embeds = self.vision_encoder(images)
    
    # 多模态编码 (交叉注意力)
    multimodal_embeds = self.multimodal_encoder(
        input_ids,
        encoder_hidden_states=image_embeds
    )
    
    # 二分类: 匹配 vs 不匹配
    itm_logits = self.itm_head(multimodal_embeds[:, 0])
    
    return itm_logits

# ITM 损失 (二分类交叉熵)
loss_itm = F.cross_entropy(itm_logits, labels)

# 困难负样本挖掘
def hard_negative_mining(sim_i2t, sim_t2i):
    """基于 ITC 相似度挖掘困难负样本"""
    # 对于每个图像，选择最相似但不匹配的文本
    weights_i2t = F.softmax(sim_i2t, dim=1)
    weights_t2i = F.softmax(sim_t2i, dim=1)
    
    # 采样困难负样本
    neg_text_idx = torch.multinomial(weights_i2t, 1).squeeze()
    neg_image_idx = torch.multinomial(weights_t2i, 1).squeeze()
    
    return neg_text_idx, neg_image_idx
```

**任务3: LM (Language Modeling)**

```python
def forward_lm(self, images, input_ids, labels):
    """图像条件语言建模"""
    # 编码图像
    image_embeds = self.vision_encoder(images)
    
    # 解码器生成 (带交叉注意力)
    decoder_output = self.text_decoder(
        input_ids,
        encoder_hidden_states=image_embeds,
        labels=labels
    )
    
    return decoder_output.loss
```

### 3.4 CapFilt 数据清洗策略

```
┌─────────────────────────────────────────────────────────────────┐
│                    CapFilt 数据清洗流程                         │
```

### 4.4 LLaMA 关键技术详解

**RMSNorm (Root Mean Square Normalization)**

```python
class RMSNorm(nn.Module):
    """
    RMSNorm 比 LayerNorm 更高效
    
    LayerNorm: y = (x - mean) / std * γ + β
    RMSNorm:   y = x / RMS(x) * γ
    
    其中 RMS(x) = sqrt(mean(x²))
    """
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))
    
    def forward(self, x):
        # 计算 RMS
        rms = torch.sqrt(torch.mean(x ** 2, dim=-1, keepdim=True) + self.eps)
        # 归一化并缩放
        return x / rms * self.weight
```

**RoPE (Rotary Position Embedding)**

```python
class RotaryEmbedding(nn.Module):
    """
    旋转位置编码
    
    核心思想: 通过旋转操作编码相对位置
    
    优势:
    1. 相对位置编码，支持长度外推
    2. 计算高效
    3. 与注意力机制自然结合
    """
    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        # 计算频率
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer('inv_freq', inv_freq)
        
        # 预计算位置编码
        t = torch.arange(max_seq_len)
        freqs = torch.einsum('i,j->ij', t, inv_freq)
        emb = torch.cat([freqs, freqs], dim=-1)
        self.register_buffer('cos', emb.cos())
        self.register_buffer('sin', emb.sin())
    
    def forward(self, x, seq_len):
        return self.cos[:seq_len], self.sin[:seq_len]

def apply_rotary_pos_emb(q, k, cos, sin):
    """应用旋转位置编码"""
    def rotate_half(x):
        x1, x2 = x[..., :x.shape[-1]//2], x[..., x.shape[-1]//2:]
        return torch.cat([-x2, x1], dim=-1)
    
    q_embed = q * cos + rotate_half(q) * sin
    k_embed = k * cos + rotate_half(k) * sin
    return q_embed, k_embed
```

```python
class SwiGLU(nn.Module):
    """
    SwiGLU 激活函数
    
    SwiGLU(x) = Swish(xW_gate) ⊙ (xW_up)
    Swish(x) = x * sigmoid(x)
    
    比 ReLU/GELU 效果更好
    """
    def __init__(self, dim, hidden_dim):
        super().__init__()
        self.w_gate = nn.Linear(dim, hidden_dim, bias=False)
        self.w_up = nn.Linear(dim, hidden_dim, bias=False)
        self.w_down = nn.Linear(hidden_dim, dim, bias=False)
    
    def forward(self, x):
        gate = F.silu(self.w_gate(x))  # Swish = SiLU
        up = self.w_up(x)
        return self.w_down(gate * up)
```

### 5.2 Patch Embedding 实现

```python
class PatchEmbedding(nn.Module):
    """
    将图像分割成 patches 并嵌入
    
    Args:
        image_size: 输入图像大小
        patch_size: patch 大小
        in_channels: 输入通道数
        embed_dim: 嵌入维度
    """
    def __init__(self, image_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.image_size = image_size
        self.patch_size = patch_size
        self.num_patches = (image_size // patch_size) ** 2
        
        # 使用卷积实现 patch embedding
        self.proj = nn.Conv2d(
            in_channels, embed_dim,
            kernel_size=patch_size, stride=patch_size
        )
        
        # [CLS] token
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        
        # 位置编码
        self.pos_embed = nn.Parameter(torch.zeros(1, self.num_patches + 1, embed_dim))
        
        # 初始化
        nn.init.trunc_normal_(self.cls_token, std=0.02)
        nn.init.trunc_normal_(self.pos_embed, std=0.02)
    
    def forward(self, x):
        B = x.shape[0]
        
        # Patch embedding: [B, 3, 224, 224] → [B, 768, 14, 14] → [B, 196, 768]
        x = self.proj(x).flatten(2).transpose(1, 2)
        
        # 添加 [CLS] token
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        
        # 添加位置编码
        x = x + self.pos_embed
        
        return x
```

## 6. 注意力机制深入

### 6.1 自注意力 (Self-Attention)

```python
class SelfAttention(nn.Module):
    """
    自注意力机制
    
    Attention(Q, K, V) = softmax(QK^T / √d_k) V
    """
    def __init__(self, dim, num_heads=8, qkv_bias=False, attn_drop=0., proj_drop=0.):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5
        
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)
    
    def forward(self, x, mask=None):
        B, N, C = x.shape
        
        # 计算 Q, K, V
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(2, 0, 3, 1, 4)  # [3, B, heads, N, head_dim]
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # 注意力分数
        attn = (q @ k.transpose(-2, -1)) * self.scale  # [B, heads, N, N]
        
        # 应用 mask
        if mask is not None:
            attn = attn.masked_fill(mask == 0, float('-inf'))
        
        attn = attn.softmax(dim=-1)
        attn = self.attn_drop(attn)
        
        # 加权求和
        x = (attn @ v).transpose(1, 2).reshape(B, N, C)
        x = self.proj(x)
        x = self.proj_drop(x)
        
        return x
```

### 6.2 交叉注意力 (Cross-Attention)

```python
class CrossAttention(nn.Module):
    """
    交叉注意力机制
    
    用于多模态融合:
    - Query 来自一个模态 (如文本)
    - Key, Value 来自另一个模态 (如图像)
    """
    def __init__(self, dim, context_dim=None, num_heads=8):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5
        
        context_dim = context_dim or dim
        
        self.to_q = nn.Linear(dim, dim, bias=False)
        self.to_k = nn.Linear(context_dim, dim, bias=False)
        self.to_v = nn.Linear(context_dim, dim, bias=False)
        self.to_out = nn.Linear(dim, dim)
    
    def forward(self, x, context):
        """
        Args:
            x: Query 输入 [B, N, D]
            context: Key/Value 输入 [B, M, C]
        """
        B, N, _ = x.shape
        M = context.shape[1]
        
        # 计算 Q, K, V
        q = self.to_q(x).reshape(B, N, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.to_k(context).reshape(B, M, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.to_v(context).reshape(B, M, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 注意力
        attn = (q @ k.transpose(-2, -1)) * self.scale
        attn = attn.softmax(dim=-1)
        
        # 输出
        out = (attn @ v).transpose(1, 2).reshape(B, N, -1)
        return self.to_out(out)
```

### 6.3 多头注意力可视化

```
多头注意力的直观理解:

单头注意力:
    Q ──→ [Attention] ←── K, V
              ↓
           Output

多头注意力 (8 heads):
    Q ──→ [Head 1] ←── K, V  →  关注语法关系
    Q ──→ [Head 2] ←── K, V  →  关注语义相似
    Q ──→ [Head 3] ←── K, V  →  关注位置关系
    Q ──→ [Head 4] ←── K, V  →  关注共指关系
    Q ──→ [Head 5] ←── K, V  →  关注修饰关系
    Q ──→ [Head 6] ←── K, V  →  关注因果关系
    Q ──→ [Head 7] ←── K, V  →  关注时序关系
    Q ──→ [Head 8] ←── K, V  →  关注其他模式
              ↓
         Concat + Linear
              ↓
           Output

每个头学习不同的注意力模式，增强模型表达能力
```

### 6.4 Flash Attention

```python
# Flash Attention 是一种高效的注意力实现
# 通过分块计算减少内存访问，提升速度

# 标准注意力: O(N²) 内存
def standard_attention(Q, K, V):
    S = Q @ K.T           # [N, N] - 需要存储完整矩阵
    P = softmax(S)        # [N, N]
    O = P @ V             # [N, D]
    return O

# Flash Attention: O(N) 内存
def flash_attention(Q, K, V, block_size=64):
    """
    分块计算，避免存储完整的 N×N 矩阵
    
    核心思想:
    1. 将 Q, K, V 分成小块
    2. 逐块计算注意力
    3. 使用在线 softmax 算法累积结果
    """
    N = Q.shape[0]
    O = torch.zeros_like(Q)
    
    for i in range(0, N, block_size):
        Qi = Q[i:i+block_size]
        
        # 累积器
        mi = torch.full((block_size,), float('-inf'))
        li = torch.zeros(block_size)
        Oi = torch.zeros_like(Qi)
        
        for j in range(0, N, block_size):
            Kj = K[j:j+block_size]
            Vj = V[j:j+block_size]
            
            # 计算当前块的注意力
            Sij = Qi @ Kj.T
            
            # 在线 softmax 更新
            mi_new = torch.max(mi, Sij.max(dim=-1).values)
            Pij = torch.exp(Sij - mi_new.unsqueeze(-1))
            li_new = torch.exp(mi - mi_new) * li + Pij.sum(dim=-1)
            
            # 更新输出
            Oi = (torch.exp(mi - mi_new).unsqueeze(-1) * Oi + Pij @ Vj)
            
            mi = mi_new
            li = li_new
        
        O[i:i+block_size] = Oi / li.unsqueeze(-1)
    
    return O
```

### 7.1 绝对位置编码

```python

class LearnablePositionalEncoding(nn.Module):

# 2. 正弦位置编码 (原始 Transformer)
class SinusoidalPositionalEncoding(nn.Module):
    def __init__(self, max_len, dim):
        super().__init__()
        pe = torch.zeros(max_len, dim)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        div_term = torch.exp(torch.arange(0, dim, 2).float() * 
                            (-math.log(10000.0) / dim))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        self.register_buffer('pe', pe.unsqueeze(0))
    
    def forward(self, x):
        return x + self.pe[:, :x.shape[1]]
```

### 7.2 相对位置编码

```python
# ALiBi (Attention with Linear Biases)
class ALiBi(nn.Module):
    """
    ALiBi: 通过线性偏置实现相对位置编码
    
    优势:
    1. 无需额外参数
    2. 支持长度外推
    3. 计算高效
    """
    def __init__(self, num_heads):
        super().__init__()
        # 每个头使用不同的斜率
        slopes = torch.tensor([2 ** (-8 * i / num_heads) for i in range(num_heads)])
        self.register_buffer('slopes', slopes)
    
    def forward(self, seq_len):
        # 构建相对位置矩阵
        positions = torch.arange(seq_len)
        relative_positions = positions.unsqueeze(0) - positions.unsqueeze(1)
        
        # 应用斜率
        alibi = self.slopes.unsqueeze(-1).unsqueeze(-1) * relative_positions
        return alibi  # [num_heads, seq_len, seq_len]
```

### 7.3 2D 位置编码 (图像)

```python
class PositionalEncoding2D(nn.Module):
    """
    2D 位置编码，用于图像
    """
    def __init__(self, dim, height, width):
        super().__init__()
        self.dim = dim
        
        # 分别编码 x 和 y 坐标
        pe_h = self._get_1d_sincos(height, dim // 2)
        pe_w = self._get_1d_sincos(width, dim // 2)
        
        # 组合成 2D 编码
        pe = torch.zeros(height, width, dim)
        pe[:, :, :dim//2] = pe_h.unsqueeze(1).expand(-1, width, -1)
        pe[:, :, dim//2:] = pe_w.unsqueeze(0).expand(height, -1, -1)
        
        self.register_buffer('pe', pe.reshape(-1, dim))
    
    def _get_1d_sincos(self, length, dim):
        position = torch.arange(length).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, dim, 2) * (-math.log(10000.0) / dim))
        
        pe = torch.zeros(length, dim)
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        return pe
    
    def forward(self, x):
        return x + self.pe
```

```python
# Warmup + Cosine Decay
def get_cosine_schedule_with_warmup(optimizer, num_warmup_steps, num_training_steps):
    def lr_lambda(current_step):
        if current_step < num_warmup_steps:
            # 线性 warmup
            return float(current_step) / float(max(1, num_warmup_steps))
        # Cosine decay
        progress = float(current_step - num_warmup_steps) / \
                   float(max(1, num_training_steps - num_warmup_steps))
        return max(0.0, 0.5 * (1.0 + math.cos(math.pi * progress)))
    
    return LambdaLR(optimizer, lr_lambda)
```

## 9. 评估指标与基准

### 9.1 图文检索指标

```python
def compute_retrieval_metrics(similarity_matrix, k_values=[1, 5, 10]):
    """
    计算检索指标
    
    Args:
        similarity_matrix: [N, N] 相似度矩阵
        k_values: Recall@K 的 K 值列表
    
    Returns:
        metrics: 包含 R@1, R@5, R@10 等指标
    """
    N = similarity_matrix.shape[0]
    
    # 图像到文本检索
    i2t_ranks = []
    for i in range(N):
        sim = similarity_matrix[i]
        sorted_indices = torch.argsort(sim, descending=True)
        rank = (sorted_indices == i).nonzero().item()
        i2t_ranks.append(rank)
    
    # 文本到图像检索
    t2i_ranks = []
    for i in range(N):
        sim = similarity_matrix[:, i]
        sorted_indices = torch.argsort(sim, descending=True)
        rank = (sorted_indices == i).nonzero().item()
        t2i_ranks.append(rank)
    
    # 计算 Recall@K
    metrics = {}
    for k in k_values:
        metrics[f'i2t_R@{k}'] = sum(r < k for r in i2t_ranks) / N * 100
        metrics[f't2i_R@{k}'] = sum(r < k for r in t2i_ranks) / N * 100
    
    return metrics
```

## 11. 高级主题：多模态融合策略

### 11.1 早期融合 (Early Fusion)

```python
class EarlyFusion(nn.Module):
    """
    早期融合：在特征提取阶段就融合多模态信息
    
    优点：模态间交互充分
    缺点：计算量大，需要对齐的输入
    """
    def __init__(self, image_dim, text_dim, hidden_dim):
        super().__init__()
        self.image_proj = nn.Linear(image_dim, hidden_dim)
        self.text_proj = nn.Linear(text_dim, hidden_dim)
        self.fusion_layers = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(hidden_dim, nhead=8),
            num_layers=6
        )
    
    def forward(self, image_features, text_features):
        # 投影到共同空间
        img = self.image_proj(image_features)  # [B, N_img, D]
        txt = self.text_proj(text_features)    # [B, N_txt, D]
        
        # 拼接并融合
        combined = torch.cat([img, txt], dim=1)  # [B, N_img+N_txt, D]
        fused = self.fusion_layers(combined)
        
        return fused
```

### 11.2 晚期融合 (Late Fusion)

```python
class LateFusion(nn.Module):
    """
    晚期融合：各模态独立编码后再融合
    
    优点：计算高效，模块化
    缺点：模态间交互有限
    """
    def __init__(self, image_dim, text_dim, output_dim):
        super().__init__()
        self.image_encoder = nn.Sequential(
            nn.Linear(image_dim, 512),
            nn.ReLU(),
            nn.Linear(512, output_dim)
        )
        self.text_encoder = nn.Sequential(
            nn.Linear(text_dim, 512),
            nn.ReLU(),
            nn.Linear(512, output_dim)
        )
        self.fusion = nn.Linear(output_dim * 2, output_dim)
    
    def forward(self, image_features, text_features):
        img_emb = self.image_encoder(image_features)
        txt_emb = self.text_encoder(text_features)
        
        # 拼接融合
        combined = torch.cat([img_emb, txt_emb], dim=-1)
        output = self.fusion(combined)
        
        return output
```

### 11.3 交叉注意力融合 (Cross-Attention Fusion)

```python
class CrossAttentionFusion(nn.Module):
    """
    交叉注意力融合：通过注意力机制实现模态间交互
    
    这是 BLIP、Flamingo 等模型的核心机制
    """
    def __init__(self, dim, num_heads=8, num_layers=4):
        super().__init__()
        self.layers = nn.ModuleList([
            CrossAttentionLayer(dim, num_heads)
            for _ in range(num_layers)
        ])
    
    def forward(self, query_features, context_features):
        """
        Args:
            query_features: 查询模态 (如文本) [B, N_q, D]
            context_features: 上下文模态 (如图像) [B, N_c, D]
        """
        x = query_features
        for layer in self.layers:
            x = layer(x, context_features)
        return x

class CrossAttentionLayer(nn.Module):
    def __init__(self, dim, num_heads):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.cross_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Linear(dim * 4, dim)
        )
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)
        self.norm3 = nn.LayerNorm(dim)
    
    def forward(self, x, context):
        # 自注意力
        x = x + self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x))[0]
        # 交叉注意力
        x = x + self.cross_attn(self.norm2(x), context, context)[0]
        # FFN
        x = x + self.ffn(self.norm3(x))
        return x
```

```python
import faiss
import numpy as np
from typing import List, Tuple

class ImageTextRetrieval:
    """
    基于 CLIP 的图文检索系统
    """
    def __init__(self, clip_model, device='cuda'):
        self.model = clip_model.to(device)
        self.device = device
        self.index = None
        self.image_paths = []
    
    def build_index(self, image_paths: List[str], batch_size: int = 32):
        """
        构建图像索引
        """
        self.image_paths = image_paths
        all_features = []
        
        for i in range(0, len(image_paths), batch_size):
            batch_paths = image_paths[i:i+batch_size]
            images = self._load_images(batch_paths)
            
            with torch.no_grad():
                features = self.model.encode_image(images.to(self.device))
                features = F.normalize(features, dim=-1)
            
            all_features.append(features.cpu().numpy())
        
        # 构建 FAISS 索引
        features = np.vstack(all_features).astype('float32')
        dim = features.shape[1]
        
        self.index = faiss.IndexFlatIP(dim)  # 内积 (余弦相似度)
        self.index.add(features)
        
        print(f"索引构建完成: {len(image_paths)} 张图像")
    
    def search_by_text(self, query: str, top_k: int = 10) -> List[Tuple[str, float]]:
        """
        文本搜索图像
        """
        # 编码查询文本
        with torch.no_grad():
            text_features = self.model.encode_text(
                self._tokenize(query).to(self.device)
            )
            text_features = F.normalize(text_features, dim=-1)
        
        # 搜索
        query_vector = text_features.cpu().numpy().astype('float32')
        scores, indices = self.index.search(query_vector, top_k)
        
        results = [
            (self.image_paths[idx], score)
            for idx, score in zip(indices[0], scores[0])
        ]
        
        return results
    
    def search_by_image(self, image_path: str, top_k: int = 10) -> List[Tuple[str, float]]:
        """
        以图搜图
        """
        image = self._load_images([image_path])
        
        with torch.no_grad():
            image_features = self.model.encode_image(image.to(self.device))
            image_features = F.normalize(image_features, dim=-1)
        
        query_vector = image_features.cpu().numpy().astype('float32')
        scores, indices = self.index.search(query_vector, top_k)
        
        results = [
            (self.image_paths[idx], score)
            for idx, score in zip(indices[0], scores[0])
        ]
        
        return results
```

### 13.2 知识蒸馏

```python
class DistillationLoss(nn.Module):
    """
    知识蒸馏损失
    
    将大模型 (Teacher) 的知识迁移到小模型 (Student)
    """
    def __init__(self, temperature=4.0, alpha=0.5):
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.kl_div = nn.KLDivLoss(reduction='batchmean')
    
    def forward(self, student_logits, teacher_logits, labels):
        # 软标签损失 (蒸馏)
        soft_loss = self.kl_div(
            F.log_softmax(student_logits / self.temperature, dim=-1),
            F.softmax(teacher_logits / self.temperature, dim=-1)
        ) * (self.temperature ** 2)
        
        # 硬标签损失 (原始任务)
        hard_loss = F.cross_entropy(student_logits, labels)
        
        # 组合损失
        return self.alpha * soft_loss + (1 - self.alpha) * hard_loss
```

## 14. 常见问题与解决方案

### 14.1 训练不稳定

```
问题: 对比学习训练时损失震荡或发散

解决方案:
1. 降低学习率 (1e-5 ~ 1e-6)
2. 增加 warmup 步数
3. 使用梯度裁剪 (max_norm=1.0)
4. 检查温度参数 τ 是否合理 (0.01 ~ 0.1)
5. 增大批次大小 (对比学习需要足够的负样本)
```

### 14.2 过拟合

```
问题: 验证集性能下降，训练集性能持续提升

解决方案:
1. 增加数据增强
2. 使用 Dropout (0.1 ~ 0.3)
3. 添加权重衰减 (0.01 ~ 0.1)
4. 早停 (Early Stopping)
5. 使用更大的预训练模型
```

### 14.3 显存不足

```
问题: CUDA out of memory

解决方案:
1. 减小批次大小
2. 使用梯度累积
3. 使用混合精度训练 (FP16)
4. 使用梯度检查点 (Gradient Checkpointing)
5. 冻结部分层
```
