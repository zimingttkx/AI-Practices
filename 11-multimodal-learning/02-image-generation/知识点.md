## 1. 生成模型基础

### 1.1 什么是生成模型？

**生成模型** (Generative Model) 学习数据的概率分布 P(x)，能够生成新的、与训练数据相似的样本。

```
判别模型 vs 生成模型:

判别模型 (Discriminative):
    输入 x → P(y|x) → 预测标签 y
    例: 分类器、检测器

生成模型 (Generative):
    噪声 z → P(x) 或 P(x|c) → 生成样本 x
    例: VAE、GAN、Diffusion
```

### 1.3 生成模型的数学框架

```
最大似然估计 (MLE):
    θ* = argmax_θ Σᵢ log P_θ(xᵢ)

变分下界 (ELBO):
    log P(x) ≥ E_q[log P(x|z)] - KL(q(z|x) || P(z))

对抗训练:
    min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]

扩散目标:
    L = E_{t,x₀,ε}[||ε - ε_θ(xₜ, t)||²]
```

## 2. VAE 变分自编码器

### 2.1 核心思想

VAE 将编码器输出建模为概率分布，通过重参数化技巧实现端到端训练。

```
普通自编码器 (AE):
    x → Encoder → z (确定性向量) → Decoder → x̂
    问题: 潜在空间不连续，无法采样生成

变分自编码器 (VAE):
    x → Encoder → (μ, σ) → 采样 z → Decoder → x̂
    优势: 潜在空间连续，支持采样生成
```

### 2.2 数学推导

**目标：最大化数据似然**

```
我们想要最大化 log P(x)，但直接计算困难:

log P(x) = log ∫ P(x|z)P(z) dz  (积分难以计算)

引入变分分布 q(z|x) 来近似真实后验 P(z|x):

log P(x) = E_q[log P(x,z)/q(z|x)] + KL(q(z|x) || P(z|x))
         ≥ E_q[log P(x,z)/q(z|x)]  (因为 KL ≥ 0)
         = E_q[log P(x|z)] - KL(q(z|x) || P(z))
         = ELBO (证据下界)
```

**ELBO 分解：**

```
ELBO = E_q[log P(x|z)] - KL(q(z|x) || P(z))
       \_____________/   \__________________/
        重建项            正则化项
        (重建质量)        (潜在空间约束)
```

### 2.3 重参数化技巧

```python
# 问题: z ~ N(μ, σ²) 的采样操作不可导
# 解决: 将随机性分离出来

# 原始采样 (不可导):
z = sample_from_normal(μ, σ)

# 重参数化 (可导):
ε = sample_from_normal(0, 1)  # 随机性来源
z = μ + σ * ε                  # 确定性变换

# 梯度可以通过 μ 和 σ 反向传播
# ∂L/∂μ = ∂L/∂z * ∂z/∂μ = ∂L/∂z * 1
# ∂L/∂σ = ∂L/∂z * ∂z/∂σ = ∂L/∂z * ε
```

### 2.4 损失函数详解

```python
def vae_loss(x, x_recon, mu, logvar, kl_weight=1.0):
    """
    VAE 损失函数
    
    Args:
        x: 原始输入 [B, C, H, W]
        x_recon: 重建输出 [B, C, H, W]
        mu: 潜在均值 [B, D]
        logvar: 潜在对数方差 [B, D]
        kl_weight: KL 散度权重 (β-VAE)
    """
    # 重建损失 (可选 MSE 或 BCE)
    recon_loss = F.mse_loss(x_recon, x, reduction='sum') / x.shape[0]
    
    # KL 散度 (解析解)
    # KL(N(μ,σ²) || N(0,1)) = -0.5 * Σ(1 + log(σ²) - μ² - σ²)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / x.shape[0]
    
    # 总损失
    total_loss = recon_loss + kl_weight * kl_loss
    
    return total_loss, recon_loss, kl_loss
```

### 2.5 β-VAE 与解耦表示

```
β-VAE: L = L_recon + β * L_KL

β 的作用:
┌─────────────────────────────────────────────────────────────┐
│  β < 1: 更好的重建质量，潜在空间可能不够规整               │
│  β = 1: 标准 VAE                                           │
│  β > 1: 更解耦的潜在空间，但重建质量下降                   │
└─────────────────────────────────────────────────────────────┘

解耦表示的意义:
- 潜在空间的每个维度对应一个独立的语义因素
- 例如: z₁ 控制颜色, z₂ 控制形状, z₃ 控制大小
- 便于可控生成和属性编辑
```

### 2.6 VAE 代码实现

```python
class VAE(nn.Module):
    def __init__(self, in_channels=3, latent_dim=256):
        super().__init__()
        self.latent_dim = latent_dim
        
        # 编码器
        self.encoder = nn.Sequential(
            nn.Conv2d(in_channels, 32, 4, 2, 1),   # 128
            nn.ReLU(),
            nn.Conv2d(32, 64, 4, 2, 1),            # 64
            nn.ReLU(),
            nn.Conv2d(64, 128, 4, 2, 1),           # 32
            nn.ReLU(),
            nn.Conv2d(128, 256, 4, 2, 1),          # 16
            nn.ReLU(),
            nn.Flatten(),
        )
        
        # 潜在空间参数
        self.fc_mu = nn.Linear(256 * 16 * 16, latent_dim)
        self.fc_logvar = nn.Linear(256 * 16 * 16, latent_dim)
        
        # 解码器
        self.fc_decode = nn.Linear(latent_dim, 256 * 16 * 16)
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(256, 128, 4, 2, 1),  # 32
            nn.ReLU(),
            nn.ConvTranspose2d(128, 64, 4, 2, 1),   # 64
            nn.ReLU(),
            nn.ConvTranspose2d(64, 32, 4, 2, 1),    # 128
            nn.ReLU(),
            nn.ConvTranspose2d(32, in_channels, 4, 2, 1),  # 256
            nn.Sigmoid(),
        )
    
    def encode(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        h = self.fc_decode(z).view(-1, 256, 16, 16)
        return self.decoder(h)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z)
        return x_recon, mu, logvar
    
    def sample(self, num_samples, device):
        z = torch.randn(num_samples, self.latent_dim).to(device)
        return self.decode(z)
```

## 3. 扩散模型 DDPM

### 3.1 核心思想

扩散模型通过两个过程工作：
1. **前向过程**：逐步向数据添加噪声直到变成纯噪声
2. **反向过程**：学习从噪声逐步恢复数据

```
前向扩散 (固定，不学习):
x₀ ──→ x₁ ──→ x₂ ──→ ... ──→ x_T ≈ N(0, I)
   +ε₁    +ε₂    +ε₃           纯噪声

反向去噪 (学习):
x_T ──→ x_{T-1} ──→ ... ──→ x₁ ──→ x₀
   -ε̂_T    -ε̂_{T-1}           生成图像
```

### 3.2 前向过程数学

**单步加噪：**

```
q(xₜ | xₜ₋₁) = N(xₜ; √(1-βₜ)·xₜ₋₁, βₜI)

其中 βₜ 是噪声调度，通常从 β₁=0.0001 线性增加到 β_T=0.02
```

**直接采样任意时刻（闭式解）：**

```
定义:
- αₜ = 1 - βₜ
- ᾱₜ = ∏ₛ₌₁ᵗ αₛ (累积乘积)

则:
q(xₜ | x₀) = N(xₜ; √ᾱₜ·x₀, (1-ᾱₜ)I)

采样公式:
xₜ = √ᾱₜ · x₀ + √(1-ᾱₜ) · ε,  ε ~ N(0, I)
```

**直观理解：**

```
t=0:   xₜ ≈ x₀           (原始图像)
t=T/4: xₜ = 0.9·x₀ + 0.1·ε  (轻微噪声)
t=T/2: xₜ = 0.5·x₀ + 0.5·ε  (中等噪声)
t=3T/4: xₜ = 0.1·x₀ + 0.9·ε  (严重噪声)
t=T:   xₜ ≈ ε            (纯噪声)
```

### 3.3 反向过程数学

**去噪分布：**

```
p_θ(xₜ₋₁ | xₜ) = N(xₜ₋₁; μ_θ(xₜ, t), σₜ²I)

我们需要学习 μ_θ(xₜ, t)，即给定 xₜ 预测 xₜ₋₁ 的均值
```

**均值的参数化：**

```
方法1: 直接预测 μ
    μ_θ(xₜ, t) = Neural_Network(xₜ, t)

方法2: 预测 x₀ (DDPM 原始)
    x̂₀ = Neural_Network(xₜ, t)
    μ_θ = (√ᾱₜ₋₁·βₜ·x̂₀ + √αₜ·(1-ᾱₜ₋₁)·xₜ) / (1-ᾱₜ)

方法3: 预测噪声 ε (最常用)
    ε̂ = Neural_Network(xₜ, t)
    μ_θ = 1/√αₜ · (xₜ - βₜ/√(1-ᾱₜ) · ε̂)
```

### 3.4 训练目标

**简化损失函数：**

```
L_simple = E_{t, x₀, ε} [||ε - ε_θ(xₜ, t)||²]

其中:
- t ~ Uniform(1, T)
- x₀ ~ 数据分布
- ε ~ N(0, I)
- xₜ = √ᾱₜ·x₀ + √(1-ᾱₜ)·ε
```

### 3.5 训练算法

```python
def train_step(model, x0, noise_scheduler):
    """DDPM 训练步骤"""
    batch_size = x0.shape[0]
    
    # 1. 随机采样时间步
    t = torch.randint(0, noise_scheduler.num_timesteps, (batch_size,))
    
    # 2. 采样噪声
    noise = torch.randn_like(x0)
    
    # 3. 前向加噪
    xt = noise_scheduler.q_sample(x0, t, noise)
    
    # 4. 预测噪声
    noise_pred = model(xt, t)
    
    # 5. 计算损失
    loss = F.mse_loss(noise_pred, noise)
    
    return loss
```

### 3.6 采样算法

```python
@torch.no_grad()
def ddpm_sample(model, noise_scheduler, shape, device):
    """DDPM 采样"""
    # 从纯噪声开始
    x = torch.randn(shape).to(device)
    
    # 逐步去噪
    for t in reversed(range(noise_scheduler.num_timesteps)):
        t_batch = torch.full((shape[0],), t, device=device)
        
        # 预测噪声
        noise_pred = model(x, t_batch)
        
        # 计算均值
        alpha = noise_scheduler.alphas[t]
        alpha_bar = noise_scheduler.alphas_cumprod[t]
        beta = noise_scheduler.betas[t]
        
        mean = (1 / alpha.sqrt()) * (x - beta / (1 - alpha_bar).sqrt() * noise_pred)
        
        # 添加噪声 (除了最后一步)
        if t > 0:
            noise = torch.randn_like(x)
            sigma = beta.sqrt()
            x = mean + sigma * noise
        else:
            x = mean
    
    return x
```

## 4. DDIM 加速采样

### 4.1 核心思想

DDIM (Denoising Diffusion Implicit Models) 通过非马尔可夫过程实现加速采样。

```
DDPM: 1000 步采样，每步依赖前一步 (马尔可夫)
DDIM: 50 步采样，可跳步 (非马尔可夫)

关键洞察: 前向过程的边缘分布 q(xₜ|x₀) 不依赖中间步骤
```

### 4.2 DDIM 采样公式

```
x_{t-1} = √ᾱ_{t-1} · x̂₀ + √(1-ᾱ_{t-1}-σ²) · ε_θ(xₜ,t) + σ · z

其中:
- x̂₀ = (xₜ - √(1-ᾱₜ)·ε_θ(xₜ,t)) / √ᾱₜ  (预测的 x₀)
- σ 控制随机性:
  - σ = 0: 确定性采样 (DDIM)
  - σ = √((1-ᾱ_{t-1})/(1-ᾱₜ))·√(1-ᾱₜ/ᾱ_{t-1}): 随机采样 (DDPM)
- z ~ N(0, I)
```

### 4.3 DDIM 代码实现

```python
class DDIMSampler:
    def __init__(self, model, scheduler, num_inference_steps=50, eta=0.0):
        self.model = model
        self.scheduler = scheduler
        self.num_inference_steps = num_inference_steps
        self.eta = eta  # 0 = 确定性, 1 = DDPM
        
        # 计算采样时间步子序列
        step_ratio = scheduler.num_timesteps // num_inference_steps
        self.timesteps = torch.arange(0, scheduler.num_timesteps, step_ratio)
    
    @torch.no_grad()
    def sample(self, shape, device):
        x = torch.randn(shape).to(device)
        
        for i in reversed(range(len(self.timesteps))):
            t = self.timesteps[i]
            t_batch = torch.full((shape[0],), t, device=device)
            
            # 预测噪声
            noise_pred = self.model(x, t_batch)
            
            # 获取 alpha 值
            alpha_bar_t = self.scheduler.alphas_cumprod[t]
            alpha_bar_prev = self.scheduler.alphas_cumprod[self.timesteps[i-1]] if i > 0 else 1.0
            
            # 预测 x₀
            x0_pred = (x - (1 - alpha_bar_t).sqrt() * noise_pred) / alpha_bar_t.sqrt()
            x0_pred = x0_pred.clamp(-1, 1)  # 可选的裁剪
            
            # 计算方差
            sigma = self.eta * ((1 - alpha_bar_prev) / (1 - alpha_bar_t) * 
                               (1 - alpha_bar_t / alpha_bar_prev)).sqrt()
            
            # 计算方向
            dir_xt = (1 - alpha_bar_prev - sigma**2).sqrt() * noise_pred
            
            # DDIM 更新
            x = alpha_bar_prev.sqrt() * x0_pred + dir_xt
            
            if i > 0 and self.eta > 0:
                x = x + sigma * torch.randn_like(x)
        
        return x
```

## 5. Stable Diffusion

### 5.1 核心思想

在压缩的潜在空间进行扩散，大幅提升效率。

```
像素空间扩散 (DDPM):
    512×512×3 = 786,432 维
    计算量大，内存占用高

潜在空间扩散 (Stable Diffusion):
    64×64×4 = 16,384 维 (压缩 48 倍)
    计算高效，质量不降
```

### 5.2 架构组成

### 5.3 交叉注意力机制

```python
class CrossAttention(nn.Module):
    """
    交叉注意力: 将文本条件注入图像特征
    
    Query: 来自图像特征
    Key, Value: 来自文本嵌入
    """
    def __init__(self, query_dim, context_dim, heads=8, dim_head=64):
        super().__init__()
        inner_dim = dim_head * heads
        
        self.heads = heads
        self.scale = dim_head ** -0.5
        
        self.to_q = nn.Linear(query_dim, inner_dim, bias=False)
        self.to_k = nn.Linear(context_dim, inner_dim, bias=False)
        self.to_v = nn.Linear(context_dim, inner_dim, bias=False)
        self.to_out = nn.Linear(inner_dim, query_dim)
    
    def forward(self, x, context):
        """
        Args:
            x: 图像特征 [B, H*W, C]
            context: 文本嵌入 [B, 77, 768]
        """
        B, N, _ = x.shape
        
        q = self.to_q(x)
        k = self.to_k(context)
        v = self.to_v(context)
        
        # 重塑为多头
        q = q.view(B, N, self.heads, -1).transpose(1, 2)
        k = k.view(B, -1, self.heads, -1).transpose(1, 2)
        v = v.view(B, -1, self.heads, -1).transpose(1, 2)
        
        # 注意力
        attn = torch.matmul(q, k.transpose(-2, -1)) * self.scale
        attn = attn.softmax(dim=-1)
        
        out = torch.matmul(attn, v)
        out = out.transpose(1, 2).reshape(B, N, -1)
        
        return self.to_out(out)
```

### 5.4 Classifier-Free Guidance (CFG)

```
核心思想: 同时训练条件和无条件生成，推理时组合两者

训练时:
- 以概率 p (如 10%) 随机丢弃条件 (用空文本替代)
- 模型学习 ε_θ(xₜ, t, c) 和 ε_θ(xₜ, t, ∅)

推理时:
ε̃ = ε_θ(xₜ, t, ∅) + w · (ε_θ(xₜ, t, c) - ε_θ(xₜ, t, ∅))
  = (1-w) · ε_uncond + w · ε_cond

其中 w 是 guidance scale:
- w = 1: 无引导，等同于条件生成
- w = 7.5: 默认值，平衡质量和多样性
- w > 10: 强引导，更符合提示但可能过饱和
```

```python
def cfg_sample_step(model, x, t, prompt_emb, null_emb, guidance_scale=7.5):
    """Classifier-Free Guidance 采样步骤"""
    # 无条件预测
    noise_uncond = model(x, t, null_emb)
    
    # 有条件预测
    noise_cond = model(x, t, prompt_emb)
    
    # CFG 组合
    noise_pred = noise_uncond + guidance_scale * (noise_cond - noise_uncond)
    
    return noise_pred
```

### 5.5 负面提示 (Negative Prompt)

```python
def cfg_with_negative(model, x, t, pos_emb, neg_emb, guidance_scale=7.5):
    """带负面提示的 CFG"""
    # 用负面提示替代空文本
    noise_neg = model(x, t, neg_emb)
    noise_pos = model(x, t, pos_emb)
    
    # 引导: 远离负面，靠近正面
    noise_pred = noise_neg + guidance_scale * (noise_pos - noise_neg)
    
    return noise_pred
```

## 6. ControlNet 条件控制

### 6.1 核心思想

ControlNet 为 Stable Diffusion 添加精确的空间控制，通过复制 UNet 编码器并使用零卷积连接。

```
问题: SD 只能通过文本控制，无法精确控制空间布局
解决: 添加额外的控制信号 (边缘、深度、姿态等)

关键创新:
1. 零卷积: 训练初期不影响原模型
2. 锁定复制: 保护预训练权重
3. 多种控制: 支持各种条件输入
```

### 6.2 零卷积 (Zero Convolution)

```python
class ZeroConv(nn.Module):
    """
    零初始化卷积层
    
    关键: 权重和偏置都初始化为 0
    效果: 训练初期输出为 0，不影响原模型
    """
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, 1)
        # 零初始化
        nn.init.zeros_(self.conv.weight)
        nn.init.zeros_(self.conv.bias)
    
    def forward(self, x):
        return self.conv(x)

# 验证零卷积
zero_conv = ZeroConv(64, 64)
x = torch.randn(1, 64, 32, 32)
y = zero_conv(x)
print(f"输出均值: {y.abs().mean():.6f}")  # 应该接近 0
```

### 6.5 ControlNet 代码实现

```python
class ControlNet(nn.Module):
    def __init__(self, sd_unet, control_channels=3):
        super().__init__()
        
        # 条件编码
        self.input_hint_block = nn.Sequential(
            nn.Conv2d(control_channels, 16, 3, padding=1),
            nn.SiLU(),
            nn.Conv2d(16, 32, 3, padding=1, stride=2),
            nn.SiLU(),
            nn.Conv2d(32, 64, 3, padding=1, stride=2),
            nn.SiLU(),
            nn.Conv2d(64, 128, 3, padding=1, stride=2),
            nn.SiLU(),
            ZeroConv(128, 320),
        )
        
        # 复制 SD UNet 编码器
        self.control_model = copy.deepcopy(sd_unet.encoder)
        
        # 零卷积输出层
        self.zero_convs = nn.ModuleList([
            ZeroConv(ch, ch) for ch in [320, 320, 320, 320, 640, 640, 640, 1280, 1280]
        ])
    
    def forward(self, x, hint, timesteps, context):
        """
        Args:
            x: 噪声潜在表示
            hint: 控制图像
            timesteps: 时间步
            context: 文本嵌入
        """
        # 编码控制图像
        guided_hint = self.input_hint_block(hint)
        
        # 通过 ControlNet 编码器
        outs = []
        h = x + guided_hint
        for module, zero_conv in zip(self.control_model, self.zero_convs):
            h = module(h, timesteps, context)
            outs.append(zero_conv(h))
        
        return outs
```

### 7.2 ResNet 块

```python
class ResBlock(nn.Module):
    """
    残差块，带时间步条件
    """
    def __init__(self, in_channels, out_channels, time_emb_dim):
        super().__init__()
        self.norm1 = nn.GroupNorm(32, in_channels)
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        
        self.time_mlp = nn.Sequential(
            nn.SiLU(),
            nn.Linear(time_emb_dim, out_channels),
        )
        
        self.norm2 = nn.GroupNorm(32, out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1)
        
        if in_channels != out_channels:
            self.skip = nn.Conv2d(in_channels, out_channels, 1)
        else:
            self.skip = nn.Identity()
    
    def forward(self, x, time_emb):
        h = self.conv1(F.silu(self.norm1(x)))
        h = h + self.time_mlp(time_emb)[:, :, None, None]
        h = self.conv2(F.silu(self.norm2(h)))
        return h + self.skip(x)
```

### 7.3 时间步嵌入

```python
class SinusoidalTimeEmbedding(nn.Module):
    """
    正弦时间步嵌入
    """
    def __init__(self, dim):
        super().__init__()
        self.dim = dim
    
    def forward(self, t):
        device = t.device
        half_dim = self.dim // 2
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim, device=device) * -emb)
        emb = t[:, None] * emb[None, :]
        emb = torch.cat([emb.sin(), emb.cos()], dim=-1)
        return emb

class TimeEmbedding(nn.Module):
    """
    时间步嵌入 + MLP
    """
    def __init__(self, dim, time_emb_dim):
        super().__init__()
        self.sinusoidal = SinusoidalTimeEmbedding(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, time_emb_dim),
            nn.SiLU(),
            nn.Linear(time_emb_dim, time_emb_dim),
        )
    
    def forward(self, t):
        return self.mlp(self.sinusoidal(t))
```

## 8. 噪声调度策略

### 8.1 线性调度

```python
def linear_beta_schedule(timesteps, beta_start=0.0001, beta_end=0.02):
    """
    线性噪声调度
    
    β 从 beta_start 线性增加到 beta_end
    """
    return torch.linspace(beta_start, beta_end, timesteps)
```

### 8.2 余弦调度

```python
def cosine_beta_schedule(timesteps, s=0.008):
    """
    余弦噪声调度 (更平滑)
    
    优势: 在 t 接近 T 时噪声增加更平缓
    """
    steps = timesteps + 1
    x = torch.linspace(0, timesteps, steps)
    alphas_cumprod = torch.cos(((x / timesteps) + s) / (1 + s) * math.pi * 0.5) ** 2
    alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
    betas = 1 - (alphas_cumprod[1:] / alphas_cumprod[:-1])
    return torch.clip(betas, 0.0001, 0.9999)
```

### 9.1 EMA (指数移动平均)

```python
class EMA:
    """
    指数移动平均，用于稳定训练
    """
    def __init__(self, model, decay=0.9999):
        self.model = model
        self.decay = decay
        self.shadow = {}
        self.backup = {}
        
        for name, param in model.named_parameters():
            if param.requires_grad:
                self.shadow[name] = param.data.clone()
    
    def update(self):
        for name, param in self.model.named_parameters():
            if param.requires_grad:
                self.shadow[name] = (
                    self.decay * self.shadow[name] + 
                    (1 - self.decay) * param.data
                )
    
    def apply_shadow(self):
        for name, param in self.model.named_parameters():
            if param.requires_grad:
                self.backup[name] = param.data
                param.data = self.shadow[name]
    
    def restore(self):
        for name, param in self.model.named_parameters():
            if param.requires_grad:
                param.data = self.backup[name]
```

```python
def min_snr_loss_weight(timesteps, snr, gamma=5.0):

    Min-SNR 损失加权
    
    在不同噪声水平下平衡损失贡献
```

### 10.2 FID 计算

```python
def calculate_fid(real_features, fake_features):
    """
    计算 FID (Frechet Inception Distance)
    """
    mu1, sigma1 = real_features.mean(0), np.cov(real_features, rowvar=False)
    mu2, sigma2 = fake_features.mean(0), np.cov(fake_features, rowvar=False)
    
    diff = mu1 - mu2
    covmean = scipy.linalg.sqrtm(sigma1 @ sigma2)
    
    if np.iscomplexobj(covmean):
        covmean = covmean.real
    
    fid = diff @ diff + np.trace(sigma1 + sigma2 - 2 * covmean)
    return fid
```

### 11.1 DPM-Solver

```python
class DPMSolver:
    """
    DPM-Solver: 高阶 ODE 求解器
    
    相比 DDIM，DPM-Solver 使用更高阶的数值方法，
    可以在更少的步数内达到相同质量。
    
    典型配置:
    - DPM-Solver++: 20 步即可获得高质量结果
    - 支持 1阶、2阶、3阶求解器
    """
    def __init__(self, model, scheduler, order=2):
        self.model = model
        self.scheduler = scheduler
        self.order = order
    
    @torch.no_grad()
    def sample(self, shape, num_steps=20):
        x = torch.randn(shape)
        timesteps = self._get_timesteps(num_steps)
        
        # 存储历史预测用于高阶方法
        model_outputs = []
        
        for i, t in enumerate(timesteps):
            # 预测噪声
            noise_pred = self.model(x, t)
            model_outputs.append(noise_pred)
            
            # 根据阶数选择更新方法
            if self.order == 1 or i < self.order - 1:
                x = self._first_order_update(x, t, noise_pred)
            elif self.order == 2:
                x = self._second_order_update(x, t, model_outputs[-2:])
            else:
                x = self._third_order_update(x, t, model_outputs[-3:])
        
        return x
```

### 11.2 Euler 采样器

```python
def euler_sample(model, scheduler, shape, num_steps=50):
    """
    Euler 采样器 - 简单高效
    
    基于 Euler 方法求解 ODE:
    dx = f(x, t) dt
    x_{t-1} = x_t + f(x_t, t) * dt
    """
    x = torch.randn(shape)
    sigmas = scheduler.get_sigmas(num_steps)
    
    for i in range(len(sigmas) - 1):
        sigma = sigmas[i]
        sigma_next = sigmas[i + 1]
        
        # 预测去噪方向
        denoised = model(x, sigma)
        d = (x - denoised) / sigma
        
        # Euler 步进
        dt = sigma_next - sigma
        x = x + d * dt
    
    return x
```

### 11.3 Ancestral 采样

```python
def euler_ancestral_sample(model, scheduler, shape, num_steps=50, eta=1.0):
    """
    Euler Ancestral 采样器
    
    在 Euler 基础上添加随机噪声，增加多样性
    eta=0: 确定性 (等同于 Euler)
    eta=1: 完全随机
    """
    x = torch.randn(shape)
    sigmas = scheduler.get_sigmas(num_steps)
    
    for i in range(len(sigmas) - 1):
        sigma = sigmas[i]
        sigma_next = sigmas[i + 1]
        
        denoised = model(x, sigma)
        
        # 计算噪声量
        sigma_up = min(sigma_next, eta * (sigma_next ** 2 * (sigma ** 2 - sigma_next ** 2) / sigma ** 2) ** 0.5)
        sigma_down = (sigma_next ** 2 - sigma_up ** 2) ** 0.5
        
        # 更新
        d = (x - denoised) / sigma
        x = x + d * (sigma_down - sigma)
        
        # 添加噪声
        if sigma_next > 0:
            x = x + torch.randn_like(x) * sigma_up
    
    return x
```

## 12. 图像编辑技术

### 12.1 Inpainting (图像修复)

```python
class InpaintingPipeline:
    """
    图像修复：根据 mask 重新生成指定区域
    """
    def __init__(self, sd_model):
        self.model = sd_model
    
    @torch.no_grad()
    def inpaint(self, image, mask, prompt, num_steps=50):
        """
        Args:
            image: 原始图像 [B, 3, H, W]
            mask: 修复区域 (1=修复, 0=保留) [B, 1, H, W]
            prompt: 文本提示
        """
        # 编码原始图像
        latents_orig = self.model.encode_image(image)
        
        # 编码文本
        text_emb = self.model.encode_text(prompt)
        
        # 从噪声开始
        latents = torch.randn_like(latents_orig)
        
        # 下采样 mask 到潜在空间
        mask_latent = F.interpolate(mask, size=latents.shape[-2:], mode='nearest')
        
        for t in reversed(range(num_steps)):
            # 预测噪声
            noise_pred = self.model.unet(latents, t, text_emb)
            
            # 去噪步骤
            latents = self.scheduler.step(noise_pred, t, latents)
            
            # 混合：保留原始区域，只修改 mask 区域
            latents = latents * mask_latent + latents_orig * (1 - mask_latent)
        
        return self.model.decode_latents(latents)
```

### 12.2 Image-to-Image (图像变换)

```python
class Img2ImgPipeline:
    """
    图像到图像变换：基于参考图像生成
    """
    def __init__(self, sd_model):
        self.model = sd_model
    
    @torch.no_grad()
    def transform(self, image, prompt, strength=0.75, num_steps=50):
        """
        Args:
            image: 参考图像
            prompt: 目标描述
            strength: 变换强度 (0=不变, 1=完全重新生成)
        """
        # 编码参考图像
        latents = self.model.encode_image(image)
        
        # 计算起始时间步
        start_step = int(num_steps * (1 - strength))
        
        # 添加噪声到起始时间步
        noise = torch.randn_like(latents)
        t_start = self.scheduler.timesteps[start_step]
        latents = self.scheduler.add_noise(latents, noise, t_start)
        
        # 编码文本
        text_emb = self.model.encode_text(prompt)
        
        # 从中间开始去噪
        for t in self.scheduler.timesteps[start_step:]:
            noise_pred = self.model.unet(latents, t, text_emb)
            latents = self.scheduler.step(noise_pred, t, latents)
        
        return self.model.decode_latents(latents)
```

### 12.3 Outpainting (图像扩展)

```python
def outpaint(model, image, direction='right', extend_pixels=256, prompt=''):
    """
    图像扩展：向指定方向扩展图像
    
    Args:
        direction: 扩展方向 ('left', 'right', 'up', 'down')
        extend_pixels: 扩展像素数
    """
    H, W = image.shape[-2:]
    
    # 创建扩展画布
    if direction == 'right':
        canvas = torch.zeros(1, 3, H, W + extend_pixels)
        canvas[:, :, :, :W] = image
        mask = torch.zeros(1, 1, H, W + extend_pixels)
        mask[:, :, :, W:] = 1
    elif direction == 'down':
        canvas = torch.zeros(1, 3, H + extend_pixels, W)
        canvas[:, :, :H, :] = image
        mask = torch.zeros(1, 1, H + extend_pixels, W)
        mask[:, :, H:, :] = 1
    # ... 其他方向类似
    
    # 使用 inpainting 填充扩展区域
    return inpaint(model, canvas, mask, prompt)
```

## 13. 条件控制进阶

### 13.1 多 ControlNet 组合

```python
class MultiControlNet:
    """
    组合多个 ControlNet 实现复杂控制
    
    例如: Canny (轮廓) + Depth (深度) + Pose (姿态)
    """
    def __init__(self, controlnets, weights=None):
        self.controlnets = controlnets
        self.weights = weights or [1.0] * len(controlnets)
    
    def forward(self, x, timesteps, conditions, context):
        """
        Args:
            conditions: 各 ControlNet 的条件图像列表
        """
        all_down_samples = []
        all_mid_samples = []
        
        for controlnet, cond, weight in zip(self.controlnets, conditions, self.weights):
            outputs = controlnet(x, timesteps, cond, context)
            
            # 加权累加
            down_samples = [s * weight for s in outputs['down_block_res_samples']]
            mid_sample = outputs['mid_block_res_sample'] * weight
            
            all_down_samples.append(down_samples)
            all_mid_samples.append(mid_sample)
        
        # 合并所有控制信号
        combined_down = [sum(samples) for samples in zip(*all_down_samples)]
        combined_mid = sum(all_mid_samples)
        
        return {
            'down_block_res_samples': combined_down,
            'mid_block_res_sample': combined_mid
        }
```

### 13.2 IP-Adapter (图像提示)

```python
class IPAdapter:
    """
    IP-Adapter: 使用图像作为提示条件
    
    将参考图像的风格/内容迁移到生成图像
    """
    def __init__(self, image_encoder, projection):
        self.image_encoder = image_encoder  # CLIP 图像编码器
        self.projection = projection  # 投影到文本空间
    
    def get_image_embeds(self, image):
        """
        将图像编码为类似文本嵌入的格式
        """
        # CLIP 图像编码
        image_features = self.image_encoder(image)
        
        # 投影到文本嵌入空间
        image_embeds = self.projection(image_features)
        
        return image_embeds
    
    def forward(self, text_embeds, image_embeds, scale=1.0):
        """
        融合文本和图像条件
        """
        # 简单加权融合
        combined = text_embeds + scale * image_embeds
        return combined
```

## 14. 训练进阶技巧

### 14.1 Noise Offset

```python
def train_step_with_noise_offset(model, images, noise_offset=0.1):
    """
    Noise Offset: 改善暗色/亮色图像生成
    
    问题: 标准训练倾向于生成中等亮度图像
    解决: 在噪声中添加全局偏移
    """
    noise = torch.randn_like(images)
    
    # 添加噪声偏移
    noise_offset_value = torch.randn(images.shape[0], 1, 1, 1, device=images.device)
    noise = noise + noise_offset * noise_offset_value
    
    # 正常训练流程
    timesteps = torch.randint(0, 1000, (images.shape[0],))
    noisy_images = scheduler.add_noise(images, noise, timesteps)
    noise_pred = model(noisy_images, timesteps)
    
    loss = F.mse_loss(noise_pred, noise)
    return loss
```

### 14.2 SNR 加权损失

```python
def snr_weighted_loss(noise_pred, noise, timesteps, scheduler, gamma=5.0):
    """
    SNR (Signal-to-Noise Ratio) 加权损失
    
    在不同噪声水平下平衡损失贡献
    """
    # 计算 SNR
    alphas_cumprod = scheduler.alphas_cumprod[timesteps]
    snr = alphas_cumprod / (1 - alphas_cumprod)
    
    # Min-SNR 加权
    weight = torch.clamp(snr, max=gamma) / snr
    
    # 加权 MSE 损失
    loss = weight * F.mse_loss(noise_pred, noise, reduction='none').mean(dim=[1, 2, 3])
    return loss.mean()
```

### 14.3 渐进式训练

```python
class ProgressiveTraining:
    """
    渐进式训练: 从低分辨率逐步提升到高分辨率
    
    优势:
    1. 训练更稳定
    2. 收敛更快
    3. 最终质量更好
    """
    def __init__(self, resolutions=[64, 128, 256, 512]):
        self.resolutions = resolutions
        self.current_stage = 0
    
    def get_current_resolution(self):
        return self.resolutions[self.current_stage]
    
    def should_advance(self, step, steps_per_stage):
        if step > 0 and step % steps_per_stage == 0:
            if self.current_stage < len(self.resolutions) - 1:
                self.current_stage += 1
                return True
        return False
```

```python
# TensorRT 优化示例
import tensorrt as trt

def optimize_unet_tensorrt(unet, sample_input):
    """
    使用 TensorRT 优化 UNet
    
    加速效果: 2-4x 推理速度提升
    """
    # 导出 ONNX
    torch.onnx.export(
        unet,
        sample_input,
        "unet.onnx",
        opset_version=17,
        input_names=['latent', 'timestep', 'context'],
        output_names=['noise_pred'],
        dynamic_axes={
            'latent': {0: 'batch'},
            'context': {0: 'batch'}
        }
    )
    
    # TensorRT 优化
    logger = trt.Logger(trt.Logger.WARNING)
    builder = trt.Builder(logger)
    network = builder.create_network(
        1 << int(trt.NetworkDefinitionCreationFlag.EXPLICIT_BATCH)
    )
    parser = trt.OnnxParser(network, logger)
    
    with open("unet.onnx", "rb") as f:
        parser.parse(f.read())
    
    config = builder.create_builder_config()
    config.set_flag(trt.BuilderFlag.FP16)  # FP16 加速
    
    engine = builder.build_serialized_network(network, config)
    return engine
```

### 15.3 批处理优化

```python
class BatchedGeneration:
    """
    批处理生成优化
    
    技巧:
    1. 批量编码文本
    2. 批量去噪
    3. 批量解码
    """
    def __init__(self, model, batch_size=4):
        self.model = model
        self.batch_size = batch_size
    
    @torch.no_grad()
    def generate_batch(self, prompts, num_steps=50):
        # 批量编码
        text_embeds = self.model.encode_text(prompts)
        
        # 初始化潜在表示
        latents = torch.randn(len(prompts), 4, 64, 64)
        
        # 批量去噪
        for t in range(num_steps):
            noise_pred = self.model.unet(latents, t, text_embeds)
            latents = self.scheduler.step(noise_pred, t, latents)
        
        # 批量解码
        images = self.model.decode_latents(latents)
        
        return images
```
