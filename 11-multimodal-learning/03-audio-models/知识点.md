## 1. 音频信号基础

### 1.1 什么是数字音频？

**模拟信号 (Analog Signal)** 是连续的声波，而计算机只能处理离散的数字。因此需要将模拟信号转换为 **数字信号 (Digital Signal)**。

```
🎤 麦克风采集 → 模拟信号 → [采样] → [量化] → 数字信号 → 💾 存储
```

**生活类比**：想象你在画一条曲线。模拟信号就是那条平滑的曲线，而数字信号就是你用很多小点来近似这条曲线。点越密集（采样率越高），近似就越精确。

### 1.2 关键参数详解

#### 采样率 (Sample Rate)

**定义**：每秒钟对模拟信号采样的次数，单位是赫兹 (Hz)。

**奈奎斯特定理 (Nyquist Theorem)**：采样率必须至少是信号最高频率的 2 倍，才能完整还原信号。

| 采样率 | 可还原的最高频率 | 典型应用 |
|:-------|:-----------------|:---------|
| 8,000 Hz | 4,000 Hz | 电话语音 |
| 16,000 Hz | 8,000 Hz | 语音识别 (推荐) |
| 22,050 Hz | 11,025 Hz | 低质量音乐 |
| 44,100 Hz | 22,050 Hz | CD 音质 |
| 48,000 Hz | 24,000 Hz | 专业音频 |

**为什么语音识别常用 16kHz？** 人类语音的主要频率成分在 300Hz-3400Hz 之间，16kHz 足以覆盖，同时数据量较小。

#### 位深度 (Bit Depth)

**定义**：每个采样点用多少位二进制数表示，决定了振幅的精度。

| 位深度 | 可表示的级数 | 动态范围 |
|:-------|:-------------|:---------|
| 8-bit | 256 级 | 48 dB |
| 16-bit | 65,536 级 | 96 dB |
| 24-bit | 16,777,216 级 | 144 dB |

**生活类比**：位深度就像画画时颜色的丰富程度。8-bit 像简笔画，16-bit 像照片。

### 1.3 时域与频域

#### 时域 (Time Domain)

**定义**：以时间为横轴，振幅为纵轴的信号表示方式。

```
振幅 ↑
     │    ╱╲      ╱╲
     │   ╱  ╲    ╱  ╲
     │  ╱    ╲  ╱    ╲
     │ ╱      ╲╱      ╲
     └──────────────────→ 时间
```

**你能看到什么**：信号的强弱变化、持续时间、静音段。

**你看不到什么**：信号包含哪些频率成分。

#### 频域 (Frequency Domain)

**定义**：以频率为横轴，幅度/能量为纵轴的信号表示方式。

```
能量 ↑
     │  █
     │  █ █
     │  █ █   █
     │  █ █ █ █
     └──────────────────→ 频率
       100 500 1k 2k Hz
```

**你能看到什么**：信号包含哪些频率成分，各频率的强度。

**你看不到什么**：这些频率成分何时出现。

#### 傅里叶变换 (Fourier Transform)

**定义**：将时域信号转换为频域信号的数学工具。

**核心思想**：任何复杂的信号都可以分解为不同频率的正弦波之和。

$$X(f) = \int_{-\infty}^{\infty} x(t) \cdot e^{-j2\pi ft} dt$$

**生活类比**：就像把一杯混合果汁分解成各种水果的成分比例。

### 1.4 短时傅里叶变换 (STFT)

#### 为什么需要 STFT？

普通傅里叶变换的问题：它告诉你信号包含哪些频率，但不告诉你这些频率**何时**出现。

**例子**：一段音乐先是低音鼓，后是高音笛。普通 FFT 只能告诉你"有低频和高频"，但不知道它们的先后顺序。

#### STFT 的解决方案

将信号分成很多小段（帧），对每一帧分别做 FFT。

```
原始信号: ════════════════════════════════════════
          ↓ 分帧 (加窗)
帧1: [════]
帧2:    [════]
帧3:       [════]
帧4:          [════]
          ↓ 每帧做 FFT
结果: 时间-频率二维图 (频谱图)
```

#### 关键参数

| 参数 | 英文 | 作用 | 典型值 |
|:-----|:-----|:-----|:-------|
| FFT 点数 | n_fft | 决定频率分辨率 | 400, 512, 1024 |
| 帧移 | hop_length | 相邻帧的间隔 | n_fft // 4 |
| 窗长 | win_length | 每帧的长度 | 等于 n_fft |

**权衡**：
- n_fft 越大 → 频率分辨率越高，但时间分辨率越低
- n_fft 越小 → 时间分辨率越高，但频率分辨率越低

```python
def stft(signal, n_fft=400, hop_length=160, win_length=400):
    """
    短时傅里叶变换 (Short-Time Fourier Transform)
    
    Args:
        signal: 输入音频波形，形状 [num_samples]
        n_fft: FFT 点数，决定频率分辨率
        hop_length: 帧移，相邻帧起始点的间隔
        win_length: 窗口长度，每帧包含的采样点数
    
    Returns:
        复数频谱，形状 [n_fft//2+1, num_frames]
    """
    # 第一步：分帧 - 将长信号切成重叠的小段
    frames = frame_signal(signal, win_length, hop_length)
    
    # 第二步：加窗 - 减少频谱泄漏
    # Hann 窗是最常用的窗函数，两端平滑过渡到零
    window = hann_window(win_length)
    windowed_frames = frames * window
    
    # 第三步：FFT - 将每帧从时域转换到频域
    spectrum = fft(windowed_frames, n_fft)
    
    # 只取正频率部分（负频率是对称的）
    return spectrum[:n_fft//2+1]
```

## 2. 音频特征提取

### 2.1 为什么需要特征提取？

原始波形的问题：
1. **维度太高**：1 秒 16kHz 音频 = 16,000 个数值
2. **信息冗余**：相邻采样点高度相关
3. **不符合感知**：人耳对频率的感知是非线性的

**解决方案**：提取更紧凑、更符合人耳感知的特征。

### 2.2 Mel 频谱图 (Mel Spectrogram)

#### Mel 尺度 (Mel Scale)

**问题**：人耳对频率的感知是非线性的。
- 100Hz 和 200Hz 的差异，听起来很明显
- 8000Hz 和 8100Hz 的差异，几乎听不出来

**Mel 尺度**：模拟人耳感知的频率尺度。

$$m = 2595 \cdot \log_{10}(1 + \frac{f}{700})$$

| 频率 (Hz) | Mel 值 | 感知 |
|:----------|:-------|:-----|
| 100 | 150 | 低音 |
| 500 | 607 | 中低音 |
| 1000 | 1000 | 中音 |
| 2000 | 1500 | 中高音 |
| 4000 | 2146 | 高音 |
| 8000 | 2840 | 很高音 |

**观察**：低频区间隔小（分辨率高），高频区间隔大（分辨率低）。

#### Mel 滤波器组 (Mel Filterbank)

**作用**：将线性频率的频谱转换为 Mel 尺度。

```
频率 (Hz):  0    500   1000  2000  4000  8000
            |     |     |     |     |     |
            △     △     △     △     △     △
          滤波器1 滤波器2 滤波器3 ...
          
每个三角滤波器:
     /\
    /  \
   /    \
  /      \
 /________\
```

**特点**：
- 低频区：滤波器窄而密集 → 高分辨率
- 高频区：滤波器宽而稀疏 → 低分辨率

#### 完整计算流程

```
波形 (Waveform)
    ↓ STFT
频谱图 (Spectrogram) - 复数
    ↓ 取模平方
功率谱 (Power Spectrum) - 实数
    ↓ Mel 滤波器组
Mel 频谱 (Mel Spectrum)
    ↓ 取对数
Log-Mel 频谱图 (Log-Mel Spectrogram) ← 最常用的特征！
```

**为什么取对数？** 人耳对响度的感知也是对数的（分贝就是对数单位）。

```python
def mel_spectrogram(waveform, sample_rate=16000, n_fft=400, 
                    hop_length=160, n_mels=80):
    """
    计算 Log-Mel 频谱图
    
    Args:
        waveform: 输入波形 [num_samples]
        sample_rate: 采样率
        n_fft: FFT 点数
        hop_length: 帧移
        n_mels: Mel 滤波器数量（输出维度）
    
    Returns:
        Log-Mel 频谱图 [n_mels, num_frames]
    """
    # 1. STFT: 波形 → 复数频谱
    stft_out = stft(waveform, n_fft, hop_length)
    
    # 2. 功率谱: 复数 → 实数（能量）
    power_spec = np.abs(stft_out) ** 2
    
    # 3. Mel 滤波: 线性频率 → Mel 尺度
    mel_filterbank = create_mel_filterbank(n_fft, n_mels, sample_rate)
    mel_spec = mel_filterbank @ power_spec
    
    # 4. 对数压缩: 符合人耳感知
    # 加小常数防止 log(0)
    log_mel = np.log(mel_spec + 1e-9)
    
    return log_mel
```

### 2.3 MFCC (梅尔频率倒谱系数)

**全称**：Mel-Frequency Cepstral Coefficients

#### 什么是倒谱 (Cepstrum)？

**倒谱** = 频谱的频谱。名字来源于 "spectrum" 的字母倒过来。

**作用**：分离声道特征（说话人特征）和声源特征（语音内容）。

#### 计算流程

```
Log-Mel 频谱图
    ↓ DCT (离散余弦变换)
MFCC (通常取前 13 维)
    ↓ [可选] 计算一阶差分 (Delta)
    ↓ [可选] 计算二阶差分 (Delta-Delta)
最终特征: 39 维 (13 + 13 + 13)
```

#### DCT (离散余弦变换)

**作用**：去相关 + 能量集中。大部分信息集中在前几个系数。

**为什么只取前 13 维？** 
- 前几维：包含语音的主要信息
- 后面的维：主要是噪声和细节

#### Delta 特征

**问题**：静态 MFCC 只描述当前帧，缺少动态信息。

**解决**：计算相邻帧之间的变化率。

$$\Delta c_t = \frac{\sum_{n=1}^{N} n \cdot (c_{t+n} - c_{t-n})}{2\sum_{n=1}^{N} n^2}$$

| 特征 | 维度 | 含义 |
|:-----|:-----|:-----|
| MFCC | 13 | 当前帧的频谱形状 |
| Delta-MFCC | 13 | 频谱的变化速度 |
| Delta-Delta-MFCC | 13 | 频谱的变化加速度 |
| **总计** | **39** | 完整的动态特征 |

### 2.4 SpecAugment 数据增强

**全称**：Spectrogram Augmentation（频谱图增强）

**来源**：Google 2019 年提出，简单有效。

#### 三种增强方式

| 方法 | 英文 | 操作 | 效果 |
|:-----|:-----|:-----|:-----|
| 时间遮蔽 | Time Masking | 随机遮蔽连续的时间帧 | 模拟语音中断 |
| 频率遮蔽 | Frequency Masking | 随机遮蔽连续的频率带 | 模拟频率缺失 |
| 时间扭曲 | Time Warping | 非线性拉伸时间轴 | 模拟语速变化 |

```python
class SpecAugment:
    """
    SpecAugment 数据增强
    
    通过随机遮蔽频谱图的部分区域，提高模型鲁棒性。
    """
    def __init__(self, freq_mask_param=27, time_mask_param=100,
                 n_freq_masks=2, n_time_masks=2):
        """
        Args:
            freq_mask_param: 频率遮蔽的最大宽度
            time_mask_param: 时间遮蔽的最大宽度
            n_freq_masks: 频率遮蔽的次数
            n_time_masks: 时间遮蔽的次数
        """
        self.freq_mask_param = freq_mask_param
        self.time_mask_param = time_mask_param
        self.n_freq_masks = n_freq_masks
        self.n_time_masks = n_time_masks
    
    def __call__(self, spec):
        """
        Args:
            spec: 频谱图 [n_mels, time]
        """
        # 只在训练时增强
        if not self.training:
            return spec
        
        spec = spec.clone()
        n_mels, n_time = spec.shape
        
        # 频率遮蔽：随机选择起点和宽度，将该频带置零
        for _ in range(self.n_freq_masks):
            f = random.randint(0, self.freq_mask_param)
            f0 = random.randint(0, n_mels - f)
            spec[f0:f0+f, :] = 0
        
        # 时间遮蔽：随机选择起点和宽度，将该时间段置零
        for _ in range(self.n_time_masks):
            t = random.randint(0, self.time_mask_param)
            t0 = random.randint(0, n_time - t)
            spec[:, t0:t0+t] = 0
        
        return spec
```

## 3. Whisper 语音识别

### 3.1 什么是 Whisper？

**Whisper** 是 OpenAI 于 2022 年发布的多任务语音识别模型。

**特点**：
- **多语言**：支持 99 种语言
- **多任务**：转录、翻译、语言识别、语音活动检测
- **鲁棒性强**：在噪声环境下表现优秀
- **零样本**：无需针对特定领域微调

### 3.2 模型架构

Whisper 采用经典的 **编码器-解码器 (Encoder-Decoder)** 架构：

```
┌─────────────────────────────────────────────────────────────┐
│                        Whisper 架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  音频输入 (30秒)                                             │
│      ↓                                                       │
│  [Log-Mel 频谱图提取] → 80 维 × 3000 帧                      │
│      ↓                                                       │
│  [2层卷积下采样] → 时间维度减半                              │
│      ↓                                                       │
│  [Transformer 编码器] → 音频的隐藏表示                       │
│      ↓                                                       │
│      ↓ ←── 交叉注意力 (Cross-Attention)                     │
│      ↓                                                       │
│  [Transformer 解码器] ← 已生成的文本 token                   │
│      ↓                                                       │
│  输出文本                                                    │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 编码器 (Encoder)

**作用**：将音频转换为隐藏表示。

```python
class AudioEncoder(nn.Module):
    """
    Whisper 音频编码器
    
    结构: 卷积下采样 + Transformer
    """
    def __init__(self, n_mels=80, d_model=512, n_layers=6, n_heads=8):
        super().__init__()
        # 两层卷积，第二层 stride=2 实现下采样
        self.conv1 = nn.Conv1d(n_mels, d_model, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(d_model, d_model, kernel_size=3, 
                               stride=2, padding=1)  # 时间维度减半
        
        # 正弦位置编码
        self.positional_encoding = SinusoidalPositionalEncoding(d_model)
        
        # Transformer 编码器层
        self.layers = nn.ModuleList([
            TransformerEncoderLayer(d_model, n_heads)
            for _ in range(n_layers)
        ])
    
    def forward(self, mel):
        """
        Args:
            mel: Log-Mel 频谱图 [batch, n_mels, time]
        Returns:
            编码后的表示 [batch, time//2, d_model]
        """
        # 卷积 + GELU 激活
        x = F.gelu(self.conv1(mel))
        x = F.gelu(self.conv2(x))  # 下采样 2 倍
        
        # 转换维度: [batch, d_model, time] → [batch, time, d_model]
        x = x.transpose(1, 2)
        
        # 添加位置编码
        x = self.positional_encoding(x)
        
        # Transformer 层
        for layer in self.layers:
            x = layer(x)
        
        return x
```

#### 解码器 (Decoder)

**作用**：根据音频表示，自回归地生成文本。

**自回归 (Autoregressive)**：每次生成一个 token，将其作为下一步的输入。

```python
class TextDecoder(nn.Module):
    """
    Whisper 文本解码器
    
    结构: Token 嵌入 + 带交叉注意力的 Transformer
    """
    def __init__(self, vocab_size, d_model=512, n_layers=6, n_heads=8):
        super().__init__()
        # Token 嵌入层
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.positional_encoding = SinusoidalPositionalEncoding(d_model)
        
        # Transformer 解码器层（带交叉注意力）
        self.layers = nn.ModuleList([
            TransformerDecoderLayer(d_model, n_heads)
            for _ in range(n_layers)
        ])
        
        # 输出投影
        self.output_proj = nn.Linear(d_model, vocab_size)
    
    def forward(self, tokens, encoder_output):
        """
        Args:
            tokens: 输入 token 序列 [batch, seq_len]
            encoder_output: 编码器输出 [batch, audio_len, d_model]
        Returns:
            词汇表上的 logits [batch, seq_len, vocab_size]
        """
        # Token 嵌入 + 位置编码
        x = self.token_embedding(tokens)
        x = self.positional_encoding(x)
        
        # Transformer 解码器层
        for layer in self.layers:
            x = layer(
                x,
                encoder_output,  # 交叉注意力的 key 和 value
                causal_mask=True  # 因果掩码，防止看到未来
            )
        
        # 输出 logits
        logits = self.output_proj(x)
        return logits
```

### 3.3 多任务能力

Whisper 通过特殊 token 来指定任务：

| Token | 名称 | 功能 |
|:------|:-----|:-----|
| `<\|startoftranscript\|>` | SOT | 序列开始 |
| `<\|en\|>`, `<\|zh\|>` | 语言标签 | 指定语言 |
| `<\|transcribe\|>` | 转录任务 | 语音转文字 |
| `<\|translate\|>` | 翻译任务 | 翻译为英语 |
| `<\|notimestamps\|>` | 无时间戳 | 不输出时间信息 |
| `<\|endoftext\|>` | EOT | 序列结束 |

**示例**：

```
中文转录:
<|startoftranscript|><|zh|><|transcribe|><|notimestamps|> 你好世界 <|endoftext|>

中文翻译为英语:
<|startoftranscript|><|zh|><|translate|><|notimestamps|> Hello world <|endoftext|>
```

### 3.4 训练目标

Whisper 使用标准的 **交叉熵损失 (Cross-Entropy Loss)**：

$$\mathcal{L} = -\sum_{t=1}^{T} \log P(y_t | y_{<t}, x)$$

- $y_t$：第 $t$ 个目标 token
- $y_{<t}$：之前生成的所有 token
- $x$：输入音频

**含义**：最大化在给定音频和已生成文本的条件下，生成正确下一个 token 的概率。

## 4. Wav2Vec2 自监督学习

### 4.1 什么是自监督学习？

**自监督学习 (Self-Supervised Learning)**：从**无标注数据**中学习有用表示的方法。

| 学习方式 | 数据需求 | 成本 | 适用场景 |
|:---------|:---------|:-----|:---------|
| 监督学习 | 大量标注数据 | 高 | 数据充足时 |
| 自监督学习 | 无标注数据 | 低 | 低资源语言、预训练 |

**核心思想**：设计"借口任务"（Pretext Task）从数据本身生成标签。

### 4.2 Wav2Vec2 的核心思想

**借口任务**：遮蔽部分音频，让模型预测被遮蔽的内容（类似完形填空）。

```
原始音频: ████████████████████████████████
              ↓ 特征编码器 (7层CNN)
潜在表示: ○○○○○○○○○○○○○○○○○○○○○○○○○○○○○○○○
              ↓ 随机遮蔽 (约49%的帧)
遮蔽后:   ○○○○██○○○○██████○○○○○██○○○○○○○○○
              ↓ Transformer
上下文表示: ●●●●??●●●●??????●●●●●??●●●●●●●●●
              ↓ 对比学习
目标: 预测 ?? 位置的量化表示
```

### 4.3 关键组件

#### 特征编码器 (Feature Encoder)

将原始波形转换为潜在表示，共7层CNN，总下采样320倍。

| 层 | 卷积核 | 步长 | 累计下采样 |
|:---|:-------|:-----|:-----------|
| 1 | 10 | 5 | 5x |
| 2-5 | 3 | 2 | 80x |
| 6-7 | 2 | 2 | **320x** |

**结果**：16kHz 音频 → 50 帧/秒（每帧 20ms）

#### 量化器 (Quantizer)

**Gumbel-Softmax 向量量化**：将连续特征离散化为码本向量。

```python
class GumbelVectorQuantizer(nn.Module):
    """
    向量量化器 - 将连续特征映射到离散码本
    
    参数:
        num_groups: 码本组数（并行码本）
        num_vars: 每组的码本大小
    """
    def forward(self, x):
        # 计算每个码本向量的选择概率
        logits = self.weight_proj(x)
        
        # Gumbel-Softmax: 可微分的离散采样
        if self.training:
            probs = F.gumbel_softmax(logits, tau=self.temperature, hard=True)
        else:
            probs = F.one_hot(logits.argmax(-1), self.num_vars)
        
        # 从码本选择向量
        quantized = torch.einsum('bgv,gvd->bgd', probs, self.codevectors)
        return quantized
```

### 4.4 对比学习损失

$$\mathcal{L}_c = -\log \frac{\exp(sim(c_t, q_t)/\kappa)}{\sum_{\tilde{q}} \exp(sim(c_t, \tilde{q})/\kappa)}$$

| 符号 | 含义 |
|:-----|:-----|
| $c_t$ | 被遮蔽位置的上下文表示 |
| $q_t$ | 正确的量化目标（正样本） |
| $\tilde{q}$ | 随机采样的负样本 |
| $\kappa$ | 温度参数（通常 0.1） |

### 4.5 下游任务

| 任务 | 添加的组件 | 应用 |
|:-----|:-----------|:-----|
| CTC 语音识别 | 线性层 + CTC 损失 | 语音转文字 |
| 序列分类 | 池化层 + 分类头 | 情感识别、说话人识别 |

## 5. TTS 文本转语音基础

### 5.1 什么是 TTS？

**TTS (Text-to-Speech)**：将文字转换为自然语音的技术。

**应用**：语音助手、有声书、无障碍辅助、导航语音。

### 5.2 系统架构

```
文本 → [文本前端] → 音素序列 → [声学模型] → Mel频谱 → [声码器] → 波形
```

| 组件 | 英文 | 功能 | 示例 |
|:-----|:-----|:-----|:-----|
| 文本前端 | Text Frontend | 分词、注音、韵律 | "你好" → "n i3 h ao3" |
| 声学模型 | Acoustic Model | 文本→Mel频谱 | Tacotron, FastSpeech |
| 声码器 | Vocoder | Mel频谱→波形 | HiFi-GAN, WaveGlow |

### 5.3 声码器：HiFi-GAN

**HiFi-GAN**：高保真神经声码器，实时生成高质量音频。

```
Mel [80, T] → Conv → [上采样+残差块]×4 → Conv → tanh → 波形
```

**关键设计**：
- **转置卷积上采样**：rates = [8, 8, 2, 2]，总上采样 256 倍
- **多尺度残差块 (MRF)**：kernels = [3, 7, 11]
- **多周期判别器 (MPD)**：periods = [2, 3, 5, 7, 11]

## 6. FastSpeech2 非自回归TTS

### 6.1 自回归 vs 非自回归

| 特性 | 自回归 (Tacotron) | 非自回归 (FastSpeech) |
|:-----|:------------------|:----------------------|
| 生成方式 | 逐帧生成 | 并行生成 |
| 速度 | 慢 | 快 10-100 倍 |
| 稳定性 | 可能跳词/重复 | 稳定 |
| 可控性 | 隐式 | 显式控制 |

### 6.2 方差适配器 (Variance Adaptor)

FastSpeech2 的核心创新：显式建模时长、音高、能量。

```
音素表示 → [时长预测器] → 时长
         → [音高预测器] → 音高 → [音高嵌入]
         → [能量预测器] → 能量 → [能量嵌入]
                              ↓
         → [长度调节器] → 帧级表示（融合音高+能量）
```

#### 长度调节器 (Length Regulator)

根据时长将音素级表示扩展到帧级：

```
输入:  [h1,  h2,  h3]     音素表示
时长:  [2,   3,   1]      每个音素的帧数
输出:  [h1, h1, h2, h2, h2, h3]  帧级表示
```

### 6.3 可控合成

```python
# 语速控制
mel = model.synthesize(text, duration_control=1.5)  # 慢速

# 音高控制
mel = model.synthesize(text, pitch_control=1.2)     # 提高音高

# 能量控制
mel = model.synthesize(text, energy_control=1.3)    # 更响亮
```

### 6.4 损失函数

$$\mathcal{L} = \mathcal{L}_{mel} + \mathcal{L}_{duration} + \mathcal{L}_{pitch} + \mathcal{L}_{energy}$$

## 7. VITS 端到端语音合成

### 7.1 什么是 VITS？

**VITS (Variational Inference with adversarial learning for end-to-end Text-to-Speech)**

**核心创新**：结合 VAE + 流模型 + GAN，直接从文本生成波形（无需单独声码器）。

### 7.2 核心概念

| 概念 | 英文 | 作用 |
|:-----|:-----|:-----|
| 变分自编码器 | VAE | 学习潜在空间表示 |
| 流模型 | Flow Model | 学习可逆的分布变换 |
| 对抗训练 | GAN | 提高音频真实感 |
| 潜在空间 | Latent Space | 数据的压缩表示 |

### 7.3 训练 vs 推理

```
训练时:
  文本 → [先验编码器] → μ_p, σ_p (先验分布)
  音频 → [后验编码器] → μ_q, σ_q → z → [解码器] → 重建音频
                      ↓
                [流模型] 学习分布映射

推理时:
  文本 → [先验编码器] → μ_p, σ_p → 采样 z_p → [流模型逆变换] → z → [解码器] → 音频
```

### 7.4 关键组件

| 组件 | 功能 |
|:-----|:-----|
| 先验编码器 (Prior Encoder) | 从文本预测潜在分布参数 |
| 后验编码器 (Posterior Encoder) | 从音频提取潜在表示（训练时） |
| 流模型 (Flow) | 学习可逆变换，对齐先验和后验 |
| 随机时长预测器 | 产生自然的韵律变化 |
| HiFi-GAN 解码器 | 从潜在表示生成波形 |

### 7.5 流模型详解

**流模型 (Normalizing Flow)**：学习可逆变换，将简单分布映射到复杂分布。

```python
class ResidualCouplingBlock(nn.Module):
    """
    残差耦合块 - 可逆变换
    
    正向: 训练时，将后验分布变换到先验分布
    逆向: 推理时，将先验分布变换到后验分布
    """
    def forward(self, x, mask, reverse=False):
        if not reverse:  # 训练: 正向
            for flow in self.flows:
                x = flow(x, mask, reverse=False)
                x = torch.flip(x, dims=[1])  # 交替翻转通道
        else:  # 推理: 逆向
            for flow in reversed(self.flows):
                x = torch.flip(x, dims=[1])
                x = flow(x, mask, reverse=True)
        return x
```

### 7.6 损失函数

| 损失 | 公式 | 作用 |
|:-----|:-----|:-----|
| 重建损失 | L1(mel_fake, mel_real) | 频谱质量 |
| KL 散度 | KL(q(z\|audio) \|\| p(z\|text)) | 分布对齐 |
| 时长损失 | 负对数似然 | 时长准确性 |
| 对抗损失 | GAN 损失 | 音频真实感 |
| 特征匹配 | L1(feat_fake, feat_real) | 稳定训练 |

## 8. 声音克隆

### 8.1 什么是声音克隆？

**声音克隆 (Voice Cloning)**：用少量参考音频，让 TTS 系统模仿特定说话人的声音。

**应用**：个性化语音助手、有声书、语音翻译保留原声、虚拟主播。

### 8.2 核心流程

```
参考音频 (3-10秒) → [说话人编码器] → 说话人嵌入 (256维向量)
                                          ↓
文本 ──────────→ [TTS 模型] ←─────────────┘
                     ↓
                克隆的语音
```

### 8.3 说话人编码器 (Speaker Encoder)

**作用**：从音频中提取说话人身份特征。

```python
class SpeakerEncoder(nn.Module):
    """
    说话人编码器 - 提取说话人身份嵌入
    
    输入: Mel 频谱图
    输出: 256维说话人嵌入向量
    """
    def __init__(self, n_mels=80, hidden_size=256, embedding_size=256):
        super().__init__()
        self.lstm = nn.LSTM(n_mels, hidden_size, num_layers=3, batch_first=True)
        self.linear = nn.Linear(hidden_size, embedding_size)
    
    def forward(self, mel):
        # mel: [batch, time, n_mels]
        _, (h_n, _) = self.lstm(mel)
        embedding = self.linear(h_n[-1])  # 取最后一层隐状态
        return F.normalize(embedding, p=2, dim=-1)  # L2 归一化
```

### 8.4 GE2E 损失

**GE2E (Generalized End-to-End)**：训练说话人编码器的对比损失。

$$\mathcal{L} = -\log \frac{\exp(sim(e_{ij}, c_i))}{\sum_k \exp(sim(e_{ij}, c_k))}$$

| 符号 | 含义 |
|:-----|:-----|
| $e_{ij}$ | 说话人 $i$ 的第 $j$ 条语音嵌入 |
| $c_i$ | 说话人 $i$ 的质心（排除当前语音） |
| $sim$ | 余弦相似度 |

**目标**：同一说话人的嵌入应该接近，不同说话人的嵌入应该远离。

### 8.5 多说话人 TTS

```python
class MultiSpeakerTTS(nn.Module):
    """多说话人 TTS"""
    def __init__(self, tts_model, speaker_encoder):
        super().__init__()
        self.tts = tts_model
        self.speaker_encoder = speaker_encoder
    
    def forward(self, text, reference_audio):
        # 提取说话人嵌入
        speaker_embedding = self.speaker_encoder(reference_audio)
        # 条件生成
        mel = self.tts(text, speaker_embedding=speaker_embedding)
        return mel
```

## 9. 高级主题

### 9.1 CTC (Connectionist Temporal Classification)

**问题**：语音识别中，输入（音频帧）和输出（文字）长度不一致。

**CTC 解决方案**：
- 引入空白符号 (blank)
- 允许多种对齐方式
- 通过动态规划计算所有对齐的概率和

```
输入帧:  [f1, f2, f3, f4, f5, f6, f7, f8]
CTC输出: [-, c, c, -, a, a, t, -]
合并后:  "cat"
```

### 9.2 RNN-Transducer (RNN-T)

**流式语音识别**的主流架构：

```
音频 → [编码器] → h_t ─┐
                       ├→ [联合网络] → P(y|t,u)
文本 → [预测网络] → g_u ┘
```

**优势**：支持实时流式识别。

### 9.3 Conformer

**Conformer = CNN + Transformer**，结合两者优势：

```
FFN(半步) → 多头自注意力 → 卷积模块 → FFN(半步) → LayerNorm
```

- **CNN**：捕捉局部模式
- **Transformer**：捕捉全局依赖

### 9.4 数据增强

| 类型 | 方法 | 效果 |
|:-----|:-----|:-----|
| 时域 | 添加噪声 | 提高噪声鲁棒性 |
| 时域 | 时间拉伸 | 适应不同语速 |
| 时域 | 音高变换 | 适应不同音高 |
| 频域 | SpecAugment | 通用增强 |
