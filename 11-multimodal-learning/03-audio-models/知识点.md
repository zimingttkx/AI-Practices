## 1. 音频信号基础

### 1.1 数字音频表示

音频信号是连续的模拟信号，需要通过采样和量化转换为数字信号：

```
模拟信号 → 采样 (Sampling) → 量化 (Quantization) → 数字信号
```

**关键参数**:
- **采样率 (Sample Rate)**: 每秒采样次数，常见值：16kHz (语音)、44.1kHz (音乐)
- **位深度 (Bit Depth)**: 每个采样点的量化精度，常见值：16-bit、24-bit
- **声道数 (Channels)**: 单声道 (Mono) 或立体声 (Stereo)

### 1.2 时域与频域

音频信号可以在两个域中分析：

```
时域 (Time Domain):
  - 横轴: 时间
  - 纵轴: 振幅
  - 直观显示波形变化

频域 (Frequency Domain):
  - 横轴: 频率
  - 纵轴: 幅度/能量
  - 显示频率成分分布
```

**傅里叶变换**将时域信号转换为频域：

$$X(f) = \int_{-\infty}^{\infty} x(t) e^{-j2\pi ft} dt$$

### 1.3 短时傅里叶变换 (STFT)

由于音频信号是非平稳的，使用**短时傅里叶变换**分析局部频率特性：

```python
def stft(signal, n_fft=400, hop_length=160, win_length=400):
    """
    短时傅里叶变换

    Args:
        signal: 输入信号 [num_samples]
        n_fft: FFT 点数
        hop_length: 帧移 (相邻帧的间隔)
        win_length: 窗长

    Returns:
        STFT 结果 [n_fft//2+1, num_frames]
    """
    # 分帧
    frames = frame_signal(signal, win_length, hop_length)

    # 加窗 (Hann 窗)
    window = hann_window(win_length)
    windowed = frames * window

    # FFT
    spectrum = fft(windowed, n_fft)

    return spectrum[:n_fft//2+1]  # 取正频率部分
```

**参数选择**:
- `n_fft`: 决定频率分辨率，通常为 2 的幂次
- `hop_length`: 决定时间分辨率，通常为 `n_fft // 4`
- `win_length`: 通常等于 `n_fft`

## 2. 音频特征提取

### 2.1 Mel 频谱图

#### 2.1.1 Mel 尺度

人耳对频率的感知是非线性的，低频区分辨率高，高频区分辨率低。**Mel 尺度**模拟这种特性：

$$m = 2595 \cdot \log_{10}(1 + \frac{f}{700})$$

反变换：

$$f = 700 \cdot (10^{m/2595} - 1)$$

#### 2.1.2 Mel 滤波器组

Mel 滤波器组是一组三角滤波器，在 Mel 尺度上均匀分布：

```
频率 (Hz):    0    500   1000  2000  4000  8000
              |     |     |     |     |     |
Mel 尺度:     0    607   1000  1500  2146  2840
              |_____|_____|_____|_____|_____|
              △     △     △     △     △     △
            滤波器1 滤波器2 滤波器3 ...
```

```python
def create_mel_filterbank(n_fft, n_mels, sample_rate, f_min=0, f_max=None):
    """创建 Mel 滤波器组"""
    if f_max is None:
        f_max = sample_rate / 2

    # Mel 尺度边界点
    mel_min = hz_to_mel(f_min)
    mel_max = hz_to_mel(f_max)
    mel_points = np.linspace(mel_min, mel_max, n_mels + 2)
    hz_points = mel_to_hz(mel_points)

    # 转换为 FFT bin 索引
    bins = np.floor((n_fft + 1) * hz_points / sample_rate).astype(int)

    # 创建三角滤波器
    filterbank = np.zeros((n_mels, n_fft // 2 + 1))
    for i in range(n_mels):
        left, center, right = bins[i], bins[i+1], bins[i+2]
        # 上升斜坡
        filterbank[i, left:center] = np.linspace(0, 1, center - left)
        # 下降斜坡
        filterbank[i, center:right] = np.linspace(1, 0, right - center)

    return filterbank
```

#### 2.1.3 Mel 频谱图计算流程

```
波形 → STFT → 功率谱 → Mel 滤波 → 对数压缩 → Mel 频谱图
```

```python
def mel_spectrogram(waveform, n_fft=400, hop_length=160, n_mels=80):
    # 1. STFT
    stft_out = stft(waveform, n_fft, hop_length)

    # 2. 功率谱
    power_spec = np.abs(stft_out) ** 2

    # 3. Mel 滤波
    mel_filterbank = create_mel_filterbank(n_fft, n_mels, sample_rate)
    mel_spec = mel_filterbank @ power_spec

    # 4. 对数压缩
    log_mel = np.log(mel_spec + 1e-9)

    return log_mel
```

### 2.2 MFCC (梅尔频率倒谱系数)

MFCC 是语音识别中最常用的特征，通过对 Mel 频谱做 DCT 得到：

```
Mel 频谱 → 对数 → DCT → MFCC
```

#### 2.2.1 离散余弦变换 (DCT)

$$c_k = \sum_{n=0}^{N-1} s_n \cos\left(\frac{\pi k (2n+1)}{2N}\right)$$

```python
def mfcc(mel_spec, n_mfcc=13):
    # 对数 Mel 频谱
    log_mel = np.log(mel_spec + 1e-9)

    # DCT
    dct_matrix = create_dct_matrix(n_mfcc, n_mels)
    mfcc = dct_matrix @ log_mel

    return mfcc
```

#### 2.2.2 差分特征 (Delta)

为了捕捉动态信息，通常计算一阶和二阶差分：

$$\Delta c_t = \frac{\sum_{n=1}^{N} n(c_{t+n} - c_{t-n})}{2\sum_{n=1}^{N} n^2}$$

最终特征: `[MFCC, Δ-MFCC, ΔΔ-MFCC]` (39 维)

### 2.3 SpecAugment 数据增强

SpecAugment 是一种简单有效的频谱数据增强方法：

```
原始频谱 → 时间遮蔽 → 频率遮蔽 → 增强后频谱
```

**三种增强方式**:

1. **时间遮蔽 (Time Masking)**: 随机遮蔽连续的时间帧
2. **频率遮蔽 (Frequency Masking)**: 随机遮蔽连续的频率 bin
3. **时间扭曲 (Time Warping)**: 对时间轴进行非线性变换

```python
def spec_augment(spec, freq_mask_param=27, time_mask_param=100):
    # 频率遮蔽
    f = random.randint(0, freq_mask_param)
    f0 = random.randint(0, n_freq - f)
    spec[:, f0:f0+f, :] = 0

    # 时间遮蔽
    t = random.randint(0, time_mask_param)
    t0 = random.randint(0, n_time - t)
    spec[:, :, t0:t0+t] = 0

    return spec
```

## 3. Whisper 语音识别

### 3.1 模型架构

Whisper 是 OpenAI 开发的多任务语音识别模型，采用编码器-解码器架构：

```
┌─────────────────────────────────────────────────────────────┐
│                        Whisper                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  音频 ──→ [Log-Mel] ──→ [卷积下采样] ──→ [Transformer 编码器] │
│                                              ↓               │
│                                         音频特征             │
│                                              ↓               │
│  <|sot|> ──→ [Token 嵌入] ──→ [Transformer 解码器] ──→ 文本  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 音频编码器

```python
class AudioEncoder(nn.Module):
    def __init__(self, n_mels=80, d_model=512, n_layers=6):
        # 卷积下采样 (stride=2)
        self.conv1 = nn.Conv1d(n_mels, d_model, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(d_model, d_model, kernel_size=3, stride=2, padding=1)

        # 位置编码
        self.positional_encoding = SinusoidalPositionalEncoding(d_model)

        # Transformer 编码器层
        self.layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_ff) for _ in range(n_layers)
        ])

    def forward(self, mel):
        # mel: [batch, n_mels, time]
        x = F.gelu(self.conv1(mel))
        x = F.gelu(self.conv2(x))  # 下采样 2x
        x = x.transpose(1, 2)  # [batch, time/2, d_model]
        x = self.positional_encoding(x)

        for layer in self.layers:
            x = layer(x)

        return x
```

### 3.3 文本解码器

```python
class TextDecoder(nn.Module):
    def __init__(self, vocab_size, d_model=512, n_layers=6):
        # Token 嵌入
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.positional_encoding = SinusoidalPositionalEncoding(d_model)

        # Transformer 解码器层 (带交叉注意力)
        self.layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_ff) for _ in range(n_layers)
        ])

    def forward(self, tokens, encoder_output):
        # tokens: [batch, seq_len]
        x = self.token_embedding(tokens)
        x = self.positional_encoding(x)

        for layer in self.layers:
            x = layer(x, encoder_output)  # 交叉注意力

        return x
```

### 3.4 多任务能力

Whisper 通过特殊 token 支持多种任务：

```
<|startoftranscript|>  开始转录
<|en|>                 语言标识 (英语)
<|zh|>                 语言标识 (中文)
<|transcribe|>         转录任务
<|translate|>          翻译任务 (翻译为英语)
<|notimestamps|>       不输出时间戳
<|endoftext|>          结束
```

**任务示例**:

```
转录中文:
<|startoftranscript|><|zh|><|transcribe|><|notimestamps|> 你好世界 <|endoftext|>

翻译为英语:
<|startoftranscript|><|zh|><|translate|><|notimestamps|> Hello world <|endoftext|>
```

### 3.5 训练目标

Whisper 使用标准的交叉熵损失：

$$L = -\sum_{t=1}^{T} \log P(y_t | y_{<t}, x)$$

```python
def whisper_loss(logits, targets, ignore_index=-100):
    """
    计算 Whisper 损失

    Args:
        logits: 模型输出 [batch, seq_len, vocab_size]
        targets: 目标 token [batch, seq_len]
    """
    loss = F.cross_entropy(
        logits.view(-1, logits.size(-1)),
        targets.view(-1),
        ignore_index=ignore_index
    )
    return loss
```

## 4. TTS 文本转语音

### 4.1 TTS 系统架构

端到端 TTS 系统通常包含三个主要组件：

```
┌─────────────────────────────────────────────────────────────┐
│                    TTS 系统架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  文本 ──→ [文本编码器] ──→ 文本特征                          │
│                              ↓                               │
│                      [声学模型/解码器]                        │
│                              ↓                               │
│                        Mel 频谱图                            │
│                              ↓                               │
│                         [声码器]                             │
│                              ↓                               │
│                        音频波形                              │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 文本编码器

文本编码器将输入文本转换为隐藏表示：

```python
class TextEncoder(nn.Module):
    def __init__(self, vocab_size, d_model=256, n_layers=4):
        # 字符嵌入
        self.embedding = nn.Embedding(vocab_size, d_model)

        # 卷积层 (提取局部特征)
        self.conv_layers = nn.ModuleList([
            ConvBlock(d_model, d_model, kernel_size=5)
            for _ in range(3)
        ])

        # Transformer 编码器
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model, n_heads, d_ff),
            num_layers=n_layers
        )

    def forward(self, text):
        x = self.embedding(text)

        # 卷积层
        x = x.transpose(1, 2)
        for conv in self.conv_layers:
            x = conv(x)
        x = x.transpose(1, 2)

        # Transformer
        x = self.transformer(x)
        return x
```

### 4.3 声学模型 (Tacotron 风格)

#### 4.3.1 预网络 (Prenet)

预网络对解码器输入进行处理，增加模型的鲁棒性：

```python
class Prenet(nn.Module):
    def __init__(self, in_dim, hidden_dim, out_dim):
        self.layers = nn.Sequential(
            nn.Linear(in_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.5),  # 高 dropout 增加鲁棒性
            nn.Linear(hidden_dim, out_dim),
            nn.ReLU(),
            nn.Dropout(0.5)
        )

    def forward(self, x):
        return self.layers(x)
```

#### 4.3.2 后网络 (Postnet)

后网络对 Mel 频谱进行精修：

```python
class Postnet(nn.Module):
    def __init__(self, n_mels=80, channels=512, kernel_size=5, n_layers=5):
        layers = []
        for i in range(n_layers):
            in_ch = n_mels if i == 0 else channels
            out_ch = n_mels if i == n_layers - 1 else channels
            layers.append(nn.Conv1d(in_ch, out_ch, kernel_size, padding=kernel_size//2))
            if i < n_layers - 1:
                layers.append(nn.BatchNorm1d(out_ch))
                layers.append(nn.Tanh())
        self.layers = nn.Sequential(*layers)

    def forward(self, mel):
        return self.layers(mel)
```

### 4.4 声码器 (HiFi-GAN)

HiFi-GAN 是一种高效的神经声码器，将 Mel 频谱转换为波形。

#### 4.4.1 生成器架构

```
Mel 频谱 → 卷积 → [上采样 + 残差块] × N → 卷积 → tanh → 波形
```

```python
class HiFiGANGenerator(nn.Module):
    def __init__(self, n_mels=80, upsample_rates=[8, 8, 2, 2]):
        self.conv_pre = nn.Conv1d(n_mels, 512, kernel_size=7, padding=3)

        self.ups = nn.ModuleList()
        self.resblocks = nn.ModuleList()

        ch = 512
        for i, u in enumerate(upsample_rates):
            # 转置卷积上采样
            self.ups.append(nn.ConvTranspose1d(
                ch, ch // 2, kernel_size=u*2, stride=u, padding=u//2
            ))
            ch = ch // 2

            # 多尺度残差块
            for k in [3, 7, 11]:
                self.resblocks.append(ResBlock(ch, k, dilations=[1, 3, 5]))

        self.conv_post = nn.Conv1d(ch, 1, kernel_size=7, padding=3)

    def forward(self, mel):
        x = self.conv_pre(mel)

        for i, up in enumerate(self.ups):
            x = F.leaky_relu(x, 0.1)
            x = up(x)

            # 残差块
            xs = sum(self.resblocks[i*3 + j](x) for j in range(3)) / 3
            x = xs

        x = F.leaky_relu(x)
        x = self.conv_post(x)
        x = torch.tanh(x)

        return x
```

#### 4.4.2 多周期判别器 (MPD)

HiFi-GAN 使用多周期判别器来捕捉不同周期的音频模式：

```python
class MultiPeriodDiscriminator(nn.Module):
    def __init__(self, periods=[2, 3, 5, 7, 11]):
        self.discriminators = nn.ModuleList([
            PeriodDiscriminator(p) for p in periods
        ])

    def forward(self, y, y_hat):
        real_outputs = []
        fake_outputs = []

        for d in self.discriminators:
            real_out = d(y)
            fake_out = d(y_hat)
            real_outputs.append(real_out)
            fake_outputs.append(fake_out)

        return real_outputs, fake_outputs
```

### 4.5 TTS 损失函数

TTS 训练使用多种损失的组合：

```python
def tts_loss(mel_output, mel_postnet, mel_target, stop_pred, stop_target):
    # 1. Mel 损失 (L1 或 MSE)
    mel_loss = F.mse_loss(mel_output, mel_target)
    mel_postnet_loss = F.mse_loss(mel_postnet, mel_target)

    # 2. 停止 token 损失 (BCE)
    stop_loss = F.binary_cross_entropy_with_logits(stop_pred, stop_target)

    # 总损失
    total_loss = mel_loss + mel_postnet_loss + stop_loss

    return total_loss
```

**HiFi-GAN 损失**:

```python
def hifigan_loss(real_outputs, fake_outputs, fmap_real, fmap_fake):
    # 1. 对抗损失
    gen_loss = sum((1 - f) ** 2 for f in fake_outputs).mean()
    disc_loss = sum((1 - r) ** 2 + f ** 2 for r, f in zip(real_outputs, fake_outputs)).mean()

    # 2. 特征匹配损失
    fm_loss = sum(F.l1_loss(fr, ff) for fr, ff in zip(fmap_real, fmap_fake))

    # 3. Mel 频谱损失
    mel_loss = F.l1_loss(mel_pred, mel_target)

    return gen_loss, disc_loss, fm_loss, mel_loss
```

## 5. 关键技术对比

### 5.1 音频特征对比

| 特征 | 维度 | 优点 | 缺点 | 应用场景 |
|:-----|:-----|:-----|:-----|:---------|
| 波形 | 1D | 无信息损失 | 维度高 | 端到端模型 |
| STFT | 2D | 时频信息 | 相位信息复杂 | 音频分析 |
| Mel 频谱 | 2D | 符合人耳感知 | 丢失相位 | ASR/TTS |
| MFCC | 1D | 紧凑、去相关 | 丢失细节 | 传统 ASR |

### 5.2 ASR 模型对比

| 模型 | 架构 | 特点 | 优势 |
|:-----|:-----|:-----|:-----|
| Whisper | Encoder-Decoder | 多任务、多语言 | 鲁棒性强 |
| Wav2Vec 2.0 | Encoder-only | 自监督预训练 | 低资源语言 |
| Conformer | Encoder-only | CNN + Transformer | 高精度 |
| RNN-T | Encoder-Decoder | 流式识别 | 实时应用 |

### 5.3 TTS 模型对比

| 模型 | 类型 | 速度 | 质量 |
|:-----|:-----|:-----|:-----|
| Tacotron 2 | 自回归 | 慢 | 高 |
| FastSpeech 2 | 非自回归 | 快 | 高 |
| VITS | 端到端 | 快 | 很高 |
| HiFi-GAN | 声码器 | 实时 | 很高 |

## 6. 高级主题：语音识别进阶

### 6.1 CTC (Connectionist Temporal Classification)

CTC 是一种用于序列到序列任务的损失函数，特别适合语音识别：

```python
class CTCLoss(nn.Module):
    """
    CTC 损失函数
    
    核心思想：
    - 允许输出序列与输入序列长度不同
    - 引入空白符号 (blank) 处理重复字符
    - 通过动态规划计算所有可能对齐的概率和
    """
    def __init__(self, blank_id=0):
        super().__init__()
        self.ctc = nn.CTCLoss(blank=blank_id, reduction='mean', zero_infinity=True)
    
    def forward(self, log_probs, targets, input_lengths, target_lengths):
        """
        Args:
            log_probs: 模型输出 [T, B, C] (时间, 批次, 类别)
            targets: 目标序列 [B, S]
            input_lengths: 输入长度 [B]
            target_lengths: 目标长度 [B]
        """
        return self.ctc(log_probs, targets, input_lengths, target_lengths)

# 使用示例
ctc_loss = CTCLoss()
log_probs = torch.randn(100, 4, 50).log_softmax(dim=-1)  # [T, B, vocab]
targets = torch.randint(1, 50, (4, 20))  # [B, S]
input_lengths = torch.full((4,), 100)
target_lengths = torch.full((4,), 20)
loss = ctc_loss(log_probs, targets, input_lengths, target_lengths)
```

### 6.2 RNN-Transducer (RNN-T)

RNN-T 是流式语音识别的主流架构：

```
┌─────────────────────────────────────────────────────────────┐
│                    RNN-Transducer                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  音频 ──→ [编码器] ──→ 音频特征 h_t                          │
│                              ↓                               │
│  文本 ──→ [预测网络] ──→ 文本特征 g_u                        │
│                              ↓                               │
│                      [联合网络]                              │
│                    z = f(h_t, g_u)                          │
│                              ↓                               │
│                      P(y | t, u)                            │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

```python
class RNNTransducer(nn.Module):
    """RNN-Transducer 模型"""
    def __init__(self, input_dim, hidden_dim, vocab_size):
        super().__init__()
        # 编码器 (处理音频)
        self.encoder = nn.LSTM(input_dim, hidden_dim, num_layers=4, 
                               batch_first=True, bidirectional=True)
        self.encoder_proj = nn.Linear(hidden_dim * 2, hidden_dim)
        
        # 预测网络 (处理文本)
        self.predictor = nn.LSTM(vocab_size, hidden_dim, num_layers=2,
                                 batch_first=True)
        
        # 联合网络
        self.joint = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),
            nn.Tanh(),
            nn.Linear(hidden_dim, vocab_size)
        )
    
    def forward(self, audio, text):
        # 编码音频
        enc_out, _ = self.encoder(audio)
        enc_out = self.encoder_proj(enc_out)  # [B, T, H]
        
        # 编码文本
        pred_out, _ = self.predictor(text)  # [B, U, H]
        
        # 联合网络 (需要扩展维度)
        T, U = enc_out.size(1), pred_out.size(1)
        enc_out = enc_out.unsqueeze(2).expand(-1, -1, U, -1)
        pred_out = pred_out.unsqueeze(1).expand(-1, T, -1, -1)
        
        joint_input = torch.cat([enc_out, pred_out], dim=-1)
        logits = self.joint(joint_input)  # [B, T, U, V]
        
        return logits
```

### 6.3 Conformer 架构

Conformer 结合了 CNN 和 Transformer 的优势：

```python
class ConformerBlock(nn.Module):
    """
    Conformer 块
    
    结构: FFN → MHSA → Conv → FFN
    """
    def __init__(self, dim, num_heads, conv_kernel=31, dropout=0.1):
        super().__init__()
        # 前馈网络 (半步)
        self.ffn1 = FeedForward(dim, dim * 4, dropout)
        
        # 多头自注意力
        self.self_attn = nn.MultiheadAttention(dim, num_heads, dropout, batch_first=True)
        self.attn_norm = nn.LayerNorm(dim)
        
        # 卷积模块
        self.conv = ConvModule(dim, conv_kernel, dropout)
        
        # 前馈网络 (半步)
        self.ffn2 = FeedForward(dim, dim * 4, dropout)
        
        self.final_norm = nn.LayerNorm(dim)
    
    def forward(self, x):
        # FFN (半步)
        x = x + 0.5 * self.ffn1(x)
        
        # 自注意力
        residual = x
        x = self.attn_norm(x)
        x = residual + self.self_attn(x, x, x)[0]
        
        # 卷积
        x = x + self.conv(x)
        
        # FFN (半步)
        x = x + 0.5 * self.ffn2(x)
        
        return self.final_norm(x)

class ConvModule(nn.Module):
    """Conformer 卷积模块"""
    def __init__(self, dim, kernel_size, dropout):
        super().__init__()
        self.layers = nn.Sequential(
            nn.LayerNorm(dim),
            nn.Conv1d(dim, dim * 2, 1),  # 点卷积扩展
            nn.GLU(dim=1),
            nn.Conv1d(dim, dim, kernel_size, padding=kernel_size//2, groups=dim),  # 深度卷积
            nn.BatchNorm1d(dim),
            nn.SiLU(),
            nn.Conv1d(dim, dim, 1),  # 点卷积压缩
            nn.Dropout(dropout)
        )
    
    def forward(self, x):
        x = x.transpose(1, 2)
        x = self.layers(x)
        return x.transpose(1, 2)
```

### 7.1 FastSpeech 2 (非自回归 TTS)

```python
class FastSpeech2(nn.Module):
    """
    FastSpeech 2: 非自回归 TTS
    
    优势:
    - 并行生成，速度快
    - 显式建模时长、音高、能量
    """
    def __init__(self, config):
        super().__init__()
        self.encoder = TransformerEncoder(config)
        
        # 变分适配器
        self.duration_predictor = VariancePredictor(config.hidden_dim)
        self.pitch_predictor = VariancePredictor(config.hidden_dim)
        self.energy_predictor = VariancePredictor(config.hidden_dim)
        
        # 嵌入
        self.pitch_embedding = nn.Conv1d(1, config.hidden_dim, 9, padding=4)
        self.energy_embedding = nn.Conv1d(1, config.hidden_dim, 9, padding=4)
        
        self.decoder = TransformerDecoder(config)
        self.mel_linear = nn.Linear(config.hidden_dim, config.n_mels)
    
    def forward(self, text, duration=None, pitch=None, energy=None):
        # 编码
        enc_out = self.encoder(text)
        
        # 预测/使用真实值
        if duration is None:
            duration = self.duration_predictor(enc_out).exp()
        if pitch is None:
            pitch = self.pitch_predictor(enc_out)
        if energy is None:
            energy = self.energy_predictor(enc_out)
        
        # 添加变分信息
        enc_out = enc_out + self.pitch_embedding(pitch.unsqueeze(1)).transpose(1, 2)
        enc_out = enc_out + self.energy_embedding(energy.unsqueeze(1)).transpose(1, 2)
        
        # 长度调节
        enc_out = self.length_regulator(enc_out, duration)
        
        # 解码
        dec_out = self.decoder(enc_out)
        mel = self.mel_linear(dec_out)
        
        return mel

class VariancePredictor(nn.Module):
    """变分预测器 (时长/音高/能量)"""
    def __init__(self, hidden_dim, kernel_size=3, dropout=0.5):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Conv1d(hidden_dim, hidden_dim, kernel_size, padding=kernel_size//2),
            nn.ReLU(),
            nn.LayerNorm(hidden_dim),
            nn.Dropout(dropout),
            nn.Conv1d(hidden_dim, hidden_dim, kernel_size, padding=kernel_size//2),
            nn.ReLU(),
            nn.LayerNorm(hidden_dim),
            nn.Dropout(dropout),
        )
        self.linear = nn.Linear(hidden_dim, 1)
    
    def forward(self, x):
        x = x.transpose(1, 2)
        x = self.layers(x)
        x = x.transpose(1, 2)
        return self.linear(x).squeeze(-1)
```

```python
class VITS(nn.Module):
    """
    VITS: 端到端 TTS
    
    特点:
    - 变分自编码器 + 流模型
    - 直接生成波形
    - 高质量、快速
    """
    def __init__(self, config):
        super().__init__()
        # 文本编码器
        self.text_encoder = TextEncoder(config)
        
        # 后验编码器 (训练时从音频提取潜在表示)
        self.posterior_encoder = PosteriorEncoder(config)
        
        # 流模型 (学习先验分布)
        self.flow = ResidualCouplingBlock(config)
        
        # 时长预测器
        self.duration_predictor = StochasticDurationPredictor(config)
        
        # 解码器 (HiFi-GAN)
        self.decoder = HiFiGANGenerator(config)
    
    def forward(self, text, text_lengths, spec, spec_lengths):
        # 文本编码
        text_enc, text_mask = self.text_encoder(text, text_lengths)
        
        # 后验编码 (从频谱)
        z, m_q, logs_q = self.posterior_encoder(spec, spec_lengths)
        
        # 流模型
        z_p = self.flow(z, spec_mask)
        
        # 时长预测
        duration = self.duration_predictor(text_enc, text_mask)
        
        # 解码
        audio = self.decoder(z)
        
        return audio, duration, (m_q, logs_q, z_p)
    
    @torch.no_grad()
    def infer(self, text, text_lengths, noise_scale=0.667):
        # 文本编码
        text_enc, text_mask = self.text_encoder(text, text_lengths)
        
        # 预测时长
        duration = self.duration_predictor.infer(text_enc, text_mask)
        
        # 扩展到帧级别
        z_p = self.expand_by_duration(text_enc, duration)
        
        # 逆流变换
        z = self.flow.reverse(z_p)
        
        # 添加噪声
        z = z + torch.randn_like(z) * noise_scale
        
        # 解码
        audio = self.decoder(z)
        
        return audio
```

```python
class SpecAugment(nn.Module):
    """SpecAugment 数据增强"""
    def __init__(self, freq_mask_param=27, time_mask_param=100, 
                 n_freq_masks=2, n_time_masks=2):
        super().__init__()
        self.freq_mask_param = freq_mask_param
        self.time_mask_param = time_mask_param
        self.n_freq_masks = n_freq_masks
        self.n_time_masks = n_time_masks
    
    def forward(self, spec):
        """
        Args:
            spec: 频谱图 [B, F, T]
        """
        if not self.training:
            return spec
        
        spec = spec.clone()
        _, n_freq, n_time = spec.shape
        
        # 频率遮蔽
        for _ in range(self.n_freq_masks):
            f = torch.randint(0, self.freq_mask_param, (1,)).item()
            f0 = torch.randint(0, max(1, n_freq - f), (1,)).item()
            spec[:, f0:f0+f, :] = 0
        
        # 时间遮蔽
        for _ in range(self.n_time_masks):
            t = torch.randint(0, min(self.time_mask_param, n_time), (1,)).item()
            t0 = torch.randint(0, max(1, n_time - t), (1,)).item()
            spec[:, :, t0:t0+t] = 0
        
        return spec
```

## 9. 评估指标

### 9.1 语音识别指标

```python
def word_error_rate(reference, hypothesis):
    """
    词错误率 (WER)
    
    WER = (S + D + I) / N
    S: 替换数, D: 删除数, I: 插入数, N: 参考词数
    """
    ref_words = reference.split()
    hyp_words = hypothesis.split()
    
    # 动态规划计算编辑距离
    d = [[0] * (len(hyp_words) + 1) for _ in range(len(ref_words) + 1)]
    
    for i in range(len(ref_words) + 1):
        d[i][0] = i
    for j in range(len(hyp_words) + 1):
        d[0][j] = j
    
    for i in range(1, len(ref_words) + 1):
        for j in range(1, len(hyp_words) + 1):
            if ref_words[i-1] == hyp_words[j-1]:
                d[i][j] = d[i-1][j-1]
            else:
                d[i][j] = min(
                    d[i-1][j] + 1,    # 删除
                    d[i][j-1] + 1,    # 插入
                    d[i-1][j-1] + 1   # 替换
                )
    
    return d[len(ref_words)][len(hyp_words)] / len(ref_words)

def character_error_rate(reference, hypothesis):
    """字符错误率 (CER)"""
    return word_error_rate(list(reference), list(hypothesis))
```

```python
def mel_cepstral_distortion(ref_mel, syn_mel):
    """
    梅尔倒谱失真 (MCD)
    
    MCD 越低越好，通常 < 6 dB 表示高质量
```

```python
class StreamingASR:
    """流式语音识别"""
    def __init__(self, model, chunk_size=16000, overlap=4000):
        self.model = model
        self.chunk_size = chunk_size
        self.overlap = overlap
        self.buffer = []
    
    def process_chunk(self, audio_chunk):
        """处理音频块"""
        self.buffer.append(audio_chunk)
        
        # 累积足够的音频
        audio = torch.cat(self.buffer, dim=-1)
        
        if audio.size(-1) >= self.chunk_size:
            # 提取特征
            mel = self.extract_mel(audio[:, :self.chunk_size])
            
            # 识别
            with torch.no_grad():
                text = self.model.transcribe(mel)
            
            # 保留重叠部分
            self.buffer = [audio[:, self.chunk_size - self.overlap:]]
            
            return text
        
        return None
```
