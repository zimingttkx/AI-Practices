## 1. 多模态统一模型概述

### 1.1 什么是多模态统一模型？

**多模态统一模型** 是指用单一架构同时处理多种模态（文本、图像、音频、视频）和多种任务（分类、检索、生成）的深度学习模型。

**传统方法 vs 统一方法**

```
传统方法：每个模态/任务一个模型
┌─────────┐   ┌─────────┐   ┌─────────┐
│ 文本模型 │   │ 图像模型 │   │ 音频模型 │
└─────────┘   └─────────┘   └─────────┘
     ↓             ↓             ↓
  文本任务      图像任务      音频任务

统一方法：一个模型处理所有
┌─────────────────────────────────────┐
│         统一多模态模型              │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐  │
│  │文本 │ │图像 │ │音频 │ │视频 │  │
│  └──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘  │
│     └───────┴───────┴───────┘      │
│              ↓                      │
│        统一表示空间                 │
│              ↓                      │
│     分类 / 检索 / 生成              │
└─────────────────────────────────────┘
```

### 1.2 为什么需要统一模型？

| 优势 | 说明 |
|:-----|:-----|
| **参数共享** | 不同模态共享参数，减少总参数量 |
| **知识迁移** | 一个模态学到的知识可迁移到其他模态 |
| **简化部署** | 只需部署一个模型而非多个 |
| **跨模态理解** | 天然支持跨模态任务（如图文检索）|
| **零样本能力** | 通过语言描述执行新任务 |

### 1.3 核心挑战

1. **模态异构性**：不同模态的数据结构差异大
2. **对齐问题**：如何让不同模态的表示可比较
3. **任务多样性**：分类、检索、生成需要不同的输出形式
4. **计算效率**：处理多模态数据计算量大

## 2. Unified-IO 架构详解

### 2.1 核心思想

Unified-IO 将所有模态统一为 **token 序列**，用同一个 Transformer 处理：

```
输入模态          Tokenization           统一处理
─────────────────────────────────────────────────────
文本    ──→  [词表映射]     ──→  Token 序列
图像    ──→  [Patch 切分]   ──→  Token 序列   ──→  Transformer
音频    ──→  [帧切分]       ──→  Token 序列       Encoder
视频    ──→  [时空 Patch]   ──→  Token 序列
```

### 2.2 模态编码器

#### 文本编码

```python
class TextEmbedding(nn.Module):
    def __init__(self, vocab_size, hidden_size, max_length):
        self.token_embedding = nn.Embedding(vocab_size, hidden_size)
        self.position_embedding = nn.Embedding(max_length, hidden_size)
    
    def forward(self, input_ids):
        # input_ids: [B, L]
        positions = torch.arange(input_ids.shape[1])
        x = self.token_embedding(input_ids) + self.position_embedding(positions)
        return x  # [B, L, D]
```

#### 图像 Patch 编码

将图像分割为不重叠的小块，每块映射为一个 token：

```
224×224 图像，patch_size=16
→ (224/16) × (224/16) = 14 × 14 = 196 个 token

数学表示：
x ∈ R^(H×W×C) → x_p ∈ R^(N×P²C)
其中 N = HW/P², P 为 patch 大小
```

```python
class PatchEmbed2D(nn.Module):
    def __init__(self, in_channels, hidden_size, patch_size):
        self.proj = nn.Conv2d(
            in_channels, hidden_size,
            kernel_size=patch_size, stride=patch_size
        )
    
    def forward(self, x):
        # x: [B, C, H, W]
        x = self.proj(x)           # [B, D, H/P, W/P]
        x = x.flatten(2)           # [B, D, N]
        x = x.transpose(1, 2)      # [B, N, D]
        return x
```

#### 音频帧编码

```python
class PatchEmbed1D(nn.Module):
    def __init__(self, hidden_size, patch_size):
        self.proj = nn.Conv1d(1, hidden_size, kernel_size=patch_size, stride=patch_size)
    
    def forward(self, x):
        # x: [B, T] 原始波形
        x = x.unsqueeze(1)         # [B, 1, T]
        x = self.proj(x)           # [B, D, T/P]
        x = x.transpose(1, 2)      # [B, N, D]
        return x
```

#### 视频时空编码

```python
class PatchEmbed3D(nn.Module):
    def __init__(self, in_channels, hidden_size, patch_size):
        self.proj = nn.Conv3d(
            in_channels, hidden_size,
            kernel_size=(1, patch_size, patch_size),
            stride=(1, patch_size, patch_size)
        )
    
    def forward(self, x):
        # x: [B, C, T, H, W]
        x = self.proj(x)                    # [B, D, T, H/P, W/P]
        B, D, T, Hp, Wp = x.shape
        x = x.permute(0, 2, 3, 4, 1)        # [B, T, H/P, W/P, D]
        x = x.reshape(B, T * Hp * Wp, D)    # [B, T*N, D]
        return x
```

### 2.3 模态嵌入

为了让模型区分不同模态的 token，添加模态类型嵌入：

```python
class ModalityEmbedding(nn.Module):
    def __init__(self, hidden_size, num_modalities=4):
        self.embedding = nn.Embedding(num_modalities, hidden_size)
    
    def forward(self, modality_id, length, batch_size):
        emb = self.embedding.weight[modality_id]  # [D]
        return emb.view(1, 1, -1).expand(batch_size, length, -1)
```

### 2.4 统一编码器

```python
class UnifiedEncoder(nn.Module):
    def __init__(self, config):
        # 各模态编码器
        self.text_embed = TextEmbedding(...)
        self.image_embed = PatchEmbed2D(...)
        self.audio_embed = PatchEmbed1D(...)
        self.video_embed = PatchEmbed3D(...)
        self.modality_embed = ModalityEmbedding(...)
        
        # CLS token
        self.cls_token = nn.Parameter(torch.zeros(1, 1, hidden_size))
        
        # Transformer
        self.encoder = nn.TransformerEncoder(...)
    
    def forward(self, batch):
        tokens = [self.cls_token]
        
        if batch.text is not None:
            text_tokens = self.text_embed(batch.text)
            text_tokens += self.modality_embed(TEXT, ...)
            tokens.append(text_tokens)
        
        if batch.images is not None:
            image_tokens = self.image_embed(batch.images)
            image_tokens += self.modality_embed(IMAGE, ...)
            tokens.append(image_tokens)
        
        # ... 音频、视频类似
        
        tokens = torch.cat(tokens, dim=1)
        hidden = self.encoder(tokens)
        return hidden
```

## 3. 统一分词与表示

### 3.1 统一词表设计

Unified-IO 2 使用统一词表处理所有模态：

```
统一词表结构：
┌─────────────────────────────────────────┐
│ [0, 32000)      文本 token              │
│ [32000, 40000)  图像离散码              │
│ [40000, 48000)  音频离散码              │
│ [48000, 56000)  视频离散码              │
│ [56000, ...)    特殊 token              │
└─────────────────────────────────────────┘
```

### 3.2 连续 vs 离散表示

**连续表示**：直接使用 patch embedding 输出的向量

```
优点：保留完整信息
缺点：无法用于自回归生成
```

**离散表示**：通过 VQ-VAE 将连续特征量化为离散码

```
优点：可用于自回归生成
缺点：量化损失信息
```

### 3.3 位置编码

不同模态需要不同的位置编码：

| 模态 | 位置编码类型 | 维度 |
|:-----|:-------------|:-----|
| 文本 | 1D 绝对位置 | 序列位置 |
| 图像 | 2D 位置 | 行 + 列 |
| 音频 | 1D 绝对位置 | 时间位置 |
| 视频 | 3D 位置 | 时间 + 行 + 列 |

## 4. 跨模态注意力机制

### 4.1 自注意力回顾

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V

其中：
- Q: 查询矩阵 [B, N, D]
- K: 键矩阵 [B, N, D]
- V: 值矩阵 [B, N, D]
- d_k: 键的维度
```

### 4.2 跨模态注意力

在统一模型中，不同模态的 token 可以相互注意：

```
Token 序列: [CLS] [文本tokens] [图像tokens] [音频tokens]

注意力矩阵：
           CLS  文本  图像  音频
    CLS    ✓    ✓     ✓     ✓
    文本   ✓    ✓     ✓     ✓
    图像   ✓    ✓     ✓     ✓
    音频   ✓    ✓     ✓     ✓

所有 token 可以关注所有其他 token
```

### 4.3 注意力掩码策略

```python
def create_attention_mask(text_len, image_len, audio_len):
    total_len = 1 + text_len + image_len + audio_len  # +1 for CLS
    
    # 全连接：所有 token 互相可见
    mask = torch.zeros(total_len, total_len)
    
    # 或者：因果掩码（用于生成）
    mask = torch.triu(torch.ones(total_len, total_len), diagonal=1)
    
    return mask
```

## 5. 统一任务接口

### 5.1 分类任务

使用 CLS token 或平均池化进行分类：

```python
def classification(hidden_states, attention_mask, num_labels):
    # 方法1: CLS token
    cls_output = hidden_states[:, 0]  # [B, D]
    
    # 方法2: 平均池化
    mask = attention_mask.unsqueeze(-1)
    pooled = (hidden_states * mask).sum(1) / mask.sum(1)
    
    logits = classifier(pooled)  # [B, num_labels]
    return logits
```

### 5.2 检索任务

输出归一化的嵌入向量用于相似度计算：

```python
def retrieval(hidden_states, attention_mask):
    pooled = mean_pooling(hidden_states, attention_mask)
    embeddings = F.normalize(pooled, dim=-1)  # L2 归一化
    return embeddings

# 相似度计算
similarity = torch.matmul(query_emb, key_emb.T)  # 余弦相似度
```

### 5.3 生成任务

使用自回归解码器生成文本：

```python
def generate(encoder_hidden, prefix_ids, max_length):
    input_ids = prefix_ids
    
    for _ in range(max_length):
        logits = decoder(input_ids, encoder_hidden)
        next_token = logits[:, -1].argmax(dim=-1)
        input_ids = torch.cat([input_ids, next_token.unsqueeze(1)], dim=1)
        
        if next_token == EOS_TOKEN:
            break
    
    return input_ids
```

## 6. ImageBind 绑定多模态

### 6.1 核心思想

ImageBind 使用图像作为"锚点"，将其他模态对齐到图像空间：

```
        图像 (锚点)
       ╱    │    ╲
      ╱     │     ╲
   文本   音频   深度
     ╲     │     ╱
      ╲    │    ╱
       热力图  IMU

所有模态都与图像对齐
→ 间接实现所有模态之间的对齐
```

### 6.2 对比学习目标

```python
def imagebind_loss(image_emb, text_emb, audio_emb, temperature=0.07):
    # 图像-文本对比
    logits_it = torch.matmul(image_emb, text_emb.T) / temperature
    labels = torch.arange(len(image_emb))
    loss_it = F.cross_entropy(logits_it, labels)
    
    # 图像-音频对比
    logits_ia = torch.matmul(image_emb, audio_emb.T) / temperature
    loss_ia = F.cross_entropy(logits_ia, labels)
    
    return loss_it + loss_ia
```

### 6.3 涌现的跨模态能力

由于所有模态都与图像对齐，模型获得了未直接训练的跨模态能力：

```
训练时：图像↔文本, 图像↔音频
涌现能力：文本↔音频 (通过图像空间传递)

示例：
- 输入"狗叫声"的音频
- 可以检索到狗的图片
- 也可以检索到"狗"相关的文本
```

### 6.4 ImageBind 架构详解

#### 6.4.1 支持的 6 种模态

| 模态 | 输入格式 | 编码器 | 特点 |
|:-----|:---------|:-------|:-----|
| 图像 | [B, 3, H, W] | ViT | Patch 嵌入 + CLS token |
| 文本 | [B, L] | Transformer | 因果注意力 + 最后 token |
| 音频 | [B, mel, time] | ViT-like | 2D Patch 处理频谱图 |
| 深度 | [B, 1, H, W] | ViT | 单通道图像编码 |
| 热力图 | [B, 1, H, W] | ViT | 单通道图像编码 |
| IMU | [B, T, 6] | 1D Transformer | 加速度+陀螺仪 |

#### 6.4.2 模态编码器实现

**图像编码器 (ViT)**

```python
class ImageEncoder(nn.Module):
    def __init__(self, config):
        self.patch_embed = PatchEmbedding(3, embed_dim, patch_size)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, num_patches+1, embed_dim))
        self.blocks = nn.ModuleList([TransformerBlock(...) for _ in range(layers)])
        self.norm = nn.LayerNorm(embed_dim)
    
    def forward(self, x):
        x = self.patch_embed(x)                    # [B, N, D]
        x = torch.cat([self.cls_token, x], dim=1)  # [B, N+1, D]
        x = x + self.pos_embed
        for block in self.blocks:
            x = block(x)
        return self.norm(x[:, 0])                  # CLS token
```

#### 6.4.3 模态投影器

将各模态编码器输出投影到统一嵌入空间：

```python
class ModalityProjector(nn.Module):
    def __init__(self, input_dim, output_dim):
        self.proj = nn.Sequential(
            nn.Linear(input_dim, output_dim),
            nn.GELU(),
            nn.Linear(output_dim, output_dim),
        )
        self.norm = nn.LayerNorm(output_dim)
    
    def forward(self, x):
        return self.norm(self.proj(x))
```

#### 6.4.4 InfoNCE 对比损失

```python
class ImageBindLoss(nn.Module):
    def __init__(self, temperature=0.07, learnable=True):
        if learnable:
            self.log_temp = nn.Parameter(torch.log(torch.tensor(1/temperature)))
        else:
            self.register_buffer('log_temp', torch.log(torch.tensor(1/temperature)))
    
    @property
    def temperature(self):
        return torch.exp(-self.log_temp)
    
    def forward(self, anchor, positive):
        # L2 归一化
        anchor = F.normalize(anchor, dim=-1)
        positive = F.normalize(positive, dim=-1)
        
        # 计算相似度矩阵
        logits = anchor @ positive.T / self.temperature
        labels = torch.arange(logits.shape[0], device=logits.device)
        
        # 双向对称损失
        loss_a2p = F.cross_entropy(logits, labels)
        loss_p2a = F.cross_entropy(logits.T, labels)
        
        return (loss_a2p + loss_p2a) / 2
```

### 6.5 ImageBind 与 CLIP 对比

| 特性 | CLIP | ImageBind |
|:-----|:-----|:----------|
| 模态数量 | 2 (图像+文本) | 6 (图像+文本+音频+深度+热力图+IMU) |
| 对齐方式 | 直接对齐 | 以图像为锚点 |
| 训练数据 | 图文对 | 图像-X 配对 |
| 涌现能力 | 无 | 跨模态传递 |
| 零样本能力 | 图像分类 | 多模态分类/检索 |

### 6.6 应用场景

1. **跨模态检索**
   - 用文本检索音频
   - 用音频检索图像
   - 用深度图检索 RGB 图像

2. **零样本分类**
   - 音频事件分类
   - 深度图场景分类
   - IMU 动作识别

3. **多模态融合**
   - 将多种模态嵌入相加/拼接
   - 增强单模态表示

## 7. 训练策略与损失函数

### 7.1 多任务训练

```python
def multi_task_loss(model, batch, task_weights):
    total_loss = 0
    
    if batch.classification_labels is not None:
        cls_loss = classification_loss(model, batch)
        total_loss += task_weights['cls'] * cls_loss
    
    if batch.retrieval_pairs is not None:
        ret_loss = contrastive_loss(model, batch)
        total_loss += task_weights['ret'] * ret_loss
    
    if batch.generation_targets is not None:
        gen_loss = generation_loss(model, batch)
        total_loss += task_weights['gen'] * gen_loss
    
    return total_loss
```

### 7.2 对比损失 (InfoNCE)

```python
def info_nce_loss(query, positive, negatives, temperature=0.07):
    """
    L = -log(exp(q·k+/τ) / Σexp(q·ki/τ))
    """
    pos_sim = torch.sum(query * positive, dim=-1) / temperature
    neg_sim = torch.matmul(query, negatives.T) / temperature
    
    logits = torch.cat([pos_sim.unsqueeze(1), neg_sim], dim=1)
    labels = torch.zeros(len(query), dtype=torch.long)
    
    return F.cross_entropy(logits, labels)
```

### 7.3 生成损失

```python
def generation_loss(logits, targets, pad_token_id):
    """
    L = -Σ log P(y_t | y_<t, x)
    """
    loss = F.cross_entropy(
        logits.view(-1, logits.size(-1)),
        targets.view(-1),
        ignore_index=pad_token_id
    )
    return loss
```

## 8. 评估指标与基准

### 8.1 分类指标

| 指标 | 公式 | 说明 |
|:-----|:-----|:-----|
| Accuracy | TP+TN / Total | 整体正确率 |
| Top-5 Acc | 前5预测含正确答案的比例 | 多类别评估 |
| F1 Score | 2×P×R / (P+R) | 精确率与召回率的调和平均 |

### 8.2 检索指标

| 指标 | 说明 |
|:-----|:-----|
| Recall@K | 前K个结果中包含正确答案的比例 |
| MRR | 正确答案排名的倒数的平均值 |
| mAP | 平均精度均值 |

### 8.3 生成指标

| 指标 | 说明 |
|:-----|:-----|
| BLEU | N-gram 重叠度 |
| ROUGE | 召回导向的摘要评估 |
| CIDEr | 图像描述专用指标 |
| Perplexity | 语言模型困惑度 |

## 9. 前沿进展

### 9.1 Unified-IO 2 (2023)

- 支持 7 种模态输入输出
- 统一离散词表
- 单模型处理 220+ 任务

### 9.2 4M (2024)

- 任意到任意的多模态模型
- 支持更多模态（深度、法线、语义分割等）
- 高效的 token 化方案

### 9.3 Video-LLaVA (2024)

- 统一图像和视频理解
- 视觉-语言对齐
- 支持长视频理解

### 9.4 发展趋势

1. **更多模态**：3D、触觉、机器人动作
2. **更大规模**：参数量和训练数据持续增长
3. **更高效率**：稀疏注意力、MoE 架构
4. **更强泛化**：零样本、少样本能力提升
