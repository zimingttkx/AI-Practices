# 统一多模态模型 知识点

## 概述

统一多模态模型旨在用单一架构处理多种模态（图像、文本、音频、深度图等），实现任意模态到任意模态的转换。

---

## 4M: Massively Multimodal Masked Modeling

### 论文信息
- **论文**: 4M: Massively Multimodal Masked Modeling
- **会议**: NeurIPS 2023
- **链接**: https://arxiv.org/abs/2312.06647

### 核心思想

4M 的核心创新是将所有模态统一为离散 token，通过 masked modeling 实现多模态理解和生成。

```
┌─────────────────────────────────────────────────────────────────┐
│                           4M 架构                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  RGB ──→ [VQ-VAE] ──→ Token ──┐                                │
│                                │                                │
│  Depth ──→ [VQ-VAE] ──→ Token ──┼──→ [Transformer] ──→ Output  │
│                                │      Encoder-Decoder           │
│  Normal ──→ [VQ-VAE] ──→ Token ──┘                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 关键组件

#### 1. 向量量化 (Vector Quantization)

VQ-VAE 将连续特征映射到离散 codebook：

$$z_q = \arg\min_{e_k \in \mathcal{E}} ||z - e_k||_2$$

**VQ 损失函数**:
$$L_{VQ} = ||z - sg[z_q]||_2^2 + \beta ||sg[z] - z_q||_2^2$$

其中 $sg[\cdot]$ 表示 stop-gradient，$\beta$ 是 commitment cost。

**EMA 更新**:
- 使用指数移动平均更新 codebook
- 避免 codebook collapse
- 更稳定的训练

#### 2. 模态 Tokenizer

为每种模态维护独立的 VQ-VAE：

| 模态 | 输入通道 | 描述 |
|:-----|:---------|:-----|
| RGB | 3 | 彩色图像 |
| Depth | 1 | 深度图 |
| Normal | 3 | 表面法线 |
| Semantic | N | 语义分割 (N 类) |

#### 3. Transformer 编码器

- 处理 masked 多模态 token 序列
- 添加模态 embedding 区分不同模态
- 位置 embedding 编码空间位置
- Mask token 替换被遮蔽的位置

#### 4. Transformer 解码器

- 自回归生成目标模态
- 交叉注意力连接编码器输出
- 因果注意力确保自回归性质

### 训练策略

**Masked Modeling**:
1. 随机 mask 一定比例的 token (如 75%)
2. 编码器处理 masked 序列
3. 解码器预测被 mask 的 token
4. 计算交叉熵损失

**损失函数**:
$$L = L_{recon} + L_{VQ}$$

其中:
- $L_{recon}$: 重建损失 (交叉熵)
- $L_{VQ}$: 向量量化损失

### 推理能力

4M 支持多种推理模式：

1. **模态补全**: 给定部分模态，生成缺失模态
2. **模态转换**: RGB → Depth, Depth → Normal 等
3. **条件生成**: 基于多模态条件生成目标模态

### 模型规模

| 规模 | d_model | layers | heads | 参数量 |
|:-----|:--------|:-------|:------|:-------|
| Tiny | 256 | 4+4 | 4 | ~10M |
| Small | 512 | 6+6 | 8 | ~50M |
| Base | 768 | 12+12 | 12 | ~200M |

### 主要类

| 类名 | 描述 |
|:-----|:-----|
| `FourMConfig` | 模型配置 |
| `VectorQuantizer` | 向量量化器 (EMA) |
| `VQVAEEncoder` | VQ-VAE 编码器 |
| `VQVAEDecoder` | VQ-VAE 解码器 |
| `ModalityTokenizer` | 多模态分词器 |
| `FourMEncoder` | Transformer 编码器 |
| `FourMDecoder` | Transformer 解码器 |
| `FourMLoss` | 损失函数 |
| `FourM` | 完整模型 |

### 使用示例

```python
from fourm import create_fourm_model

# 创建模型
model = create_fourm_model("tiny")

# 准备输入
inputs = {
    "rgb": torch.randn(2, 3, 64, 64),
    "depth": torch.randn(2, 1, 64, 64)
}

# 训练
loss, loss_dict = model(inputs, target_modality="rgb")

# 生成
output = model.generate(inputs, target_modality="depth")
```
