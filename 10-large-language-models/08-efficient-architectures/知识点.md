# Mamba 状态空间模型知识点

## 1. 概述

### 1.1 背景与动机

Transformer 架构虽然在序列建模中取得了巨大成功，但存在两个核心问题：

1. **二次复杂度**: 自注意力机制的时间和空间复杂度为 O(L²)，限制了长序列处理能力
2. **推理效率低**: 自回归生成时需要缓存所有历史 KV，内存占用随序列长度线性增长

Mamba 通过**选择性状态空间模型 (Selective SSM)** 解决这些问题：
- 时间复杂度: O(L) - 线性于序列长度
- 推理时状态大小固定，不随序列长度增长
- 在语言建模任务上达到与 Transformer 相当的性能

### 1.2 核心创新

```
┌─────────────────────────────────────────────────────────────┐
│                    Mamba 核心创新                            │
├─────────────────────────────────────────────────────────────┤
│  1. 选择性机制: Δ, B, C 参数依赖于输入                        │
│     - 实现内容感知的信息过滤                                  │
│     - 类似注意力的动态权重                                    │
│                                                             │

└─────────────────────────────────────────────────────────────┘
```

## 2. 理论基础

### 2.1 状态空间模型 (SSM)

连续时间状态空间模型定义为：

$$
\begin{aligned}
h'(t) &= A h(t) + B x(t) \\
y(t) &= C h(t) + D x(t)
\end{aligned}
$$

其中：
- $x(t) \in \mathbb{R}$ : 输入信号
- $h(t) \in \mathbb{R}^N$ : 隐藏状态 (N 维)
- $y(t) \in \mathbb{R}$ : 输出信号
- $A \in \mathbb{R}^{N \times N}$ : 状态转移矩阵
- $B \in \mathbb{R}^{N \times 1}$ : 输入矩阵
- $C \in \mathbb{R}^{1 \times N}$ : 输出矩阵
- $D \in \mathbb{R}$ : 跳跃连接 (feedthrough)

### 2.2 离散化

将连续时间 SSM 离散化为离散时间形式，使用 Zero-Order Hold (ZOH)：

$$
\begin{aligned}
\bar{A} &= \exp(\Delta A) \\
\bar{B} &= (\Delta A)^{-1}(\exp(\Delta A) - I) \cdot \Delta B \approx \Delta B
\end{aligned}
$$

离散时间递推：

$$
\begin{aligned}
h_k &= \bar{A} h_{k-1} + \bar{B} x_k \\
y_k &= C h_k + D x_k
\end{aligned}
$$

### 2.3 选择性机制 (Mamba 核心)

传统 SSM 的参数 (A, B, C, Δ) 是固定的，无法根据输入内容调整。

**Mamba 的选择性机制**使这些参数依赖于输入：

$$
\begin{aligned}
\Delta &= \text{softplus}(W_\Delta x + b_\Delta) \\
B &= W_B x \\
C &= W_C x
\end{aligned}
$$

这使得模型能够：
1. **选择性记忆**: 根据内容决定保留或遗忘信息
2. **动态时间尺度**: 通过 Δ 调整信息传播速度
3. **上下文感知**: 类似注意力机制的内容依赖权重

```
输入依赖参数化:
                    ┌─────────┐
         x ────────►│ Linear  │────► Δ (时间步长)
                    └─────────┘
                    ┌─────────┐
         x ────────►│ Linear  │────► B (输入投影)
                    └─────────┘
                    ┌─────────┐
         x ────────►│ Linear  │────► C (输出投影)
                    └─────────┘
```

### 2.4 HiPPO 初始化

A 矩阵使用 HiPPO (High-order Polynomial Projection Operators) 初始化：

$$
A_{nk} = -\begin{cases}
(2n+1)^{1/2}(2k+1)^{1/2} & \text{if } n > k \\
n+1 & \text{if } n = k \\
0 & \text{if } n < k
\end{cases}
$$

简化版本 (对角矩阵):
$$
A = -\text{diag}(1, 2, 3, ..., N)
$$

### 3.2 选择性扫描算法

```python
def selective_scan(x, delta, A, B, C, D):
    """
    选择性扫描 - Mamba 核心算法
    
    Args:
        x: [B, L, D] 输入
        delta: [B, L, D] 时间步长
        A: [D, N] 状态矩阵
        B: [B, L, N] 输入矩阵
        C: [B, L, N] 输出矩阵
        D: [D] 跳跃连接
    """
    # 离散化
    A_bar = exp(delta * A)  # [B, L, D, N]
    B_bar = delta * B       # [B, L, D, N]
    
    # 初始化状态
    h = zeros(B, D, N)
    y = zeros(B, L, D)
    
    # 顺序扫描 (可并行化)
    for k in range(L):
        h = A_bar[:, k] * h + B_bar[:, k] * x[:, k, :, None]
        y[:, k] = einsum("bdn,bn->bd", h, C[:, k])
    
    # 跳跃连接
    y = y + x * D
    
    return y
```

### 3.3 并行扫描优化

顺序扫描的复杂度为 O(L)，但无法并行。使用**并行扫描 (Parallel Scan)** 可以在 O(log L) 步内完成：

```
并行扫描示意图 (L=8):

Step 0: [h0] [h1] [h2] [h3] [h4] [h5] [h6] [h7]
           ↘   ↙     ↘   ↙     ↘   ↙     ↘   ↙
Step 1:    [h01]     [h23]     [h45]     [h67]
               ↘       ↙           ↘       ↙
Step 2:        [h0123]             [h4567]
                   ↘                   ↙
Step 3:            [h01234567]

总步数: O(log L) = 3 步
```

## 5. Mamba-2 改进

### 5.1 State Space Duality (SSD)

Mamba-2 发现 SSM 与线性注意力存在对偶关系：

$$
\text{SSM}: y = C \cdot (\bar{A} \odot h + \bar{B} \odot x)
$$

$$
\text{Linear Attention}: y = \frac{Q(K^T V)}{\text{norm}}
$$

通过适当的参数化，两者可以统一：
- $Q \leftrightarrow C$
- $K \leftrightarrow B$
- $V \leftrightarrow x$
- $\bar{A} \leftrightarrow$ 衰减因子

### 5.2 架构改进

```
Mamba-2 改进:
┌─────────────────────────────────────────┐
│ 1. 多头结构: 类似多头注意力              │
│    - nheads 个独立的 SSM                │
│    - 每个头有独立的 A 参数               │
│                                         │
│ 2. 分组参数: 减少参数量                  │
│    - B, C 在组间共享                    │
│    - 类似 GQA (Grouped Query Attention) │
```

## 6. 复杂度分析

### 6.1 时间复杂度

| 操作 | Transformer | Mamba |
|:-----|:------------|:------|
| 训练 (前向) | O(L² · D) | O(L · D · N) |
| 训练 (反向) | O(L² · D) | O(L · D · N) |
| 推理 (单步) | O(L · D) | O(D · N) |
| 推理 (全序列) | O(L² · D) | O(L · D · N) |

其中 L=序列长度, D=模型维度, N=状态维度 (通常 N << L)

### 6.2 空间复杂度

| 存储 | Transformer | Mamba |
|:-----|:------------|:------|
| KV Cache | O(L · D) | O(D · N) |
| 激活值 | O(L · D) | O(L · D) |

**关键优势**: Mamba 的推理状态大小固定 (O(D·N))，不随序列长度增长。

### 7.3 常见问题

**Q: Mamba 适合什么任务？**
A: 语言建模、长序列任务、实时推理场景。对于需要精确检索的任务 (如 RAG)，Transformer 可能更优。

**Q: 如何选择 d_state？**
A: 通常 16 足够。增大 d_state 可以提升长程依赖建模能力，但会增加计算量。

**Q: Mamba 能否与注意力混合使用？**
A: 可以。Jamba 等模型证明了混合架构的有效性。

# Mixture of Experts (MoE) 知识点

## 1. 概述

### 1.1 背景与动机

传统 Dense 模型的问题：
- 每个 token 激活所有参数，计算量与参数量成正比
- 扩展模型容量必然增加计算成本

MoE 的解决方案：**稀疏激活**
- 每个 token 只激活部分专家 (如 8 选 2)
- 模型容量可以大幅增加，而计算量保持不变

### 1.2 核心优势

| 特性 | Dense Model | MoE Model |
|:-----|:------------|:----------|
| 参数量 | N | N × E (E=专家数) |
| 计算量 | O(N) | O(N × K/E) |
| 内存 | N | N × E |
| 扩展性 | 线性 | 亚线性 |

## 2. 理论基础

### 2.1 门控机制

路由器 (Router) 决定每个 token 分配给哪些专家：

$$G(x) = \text{Softmax}(W_g \cdot x)$$

Top-K 选择：
$$\text{TopK}(G(x)) = \{(i, g_i) | g_i \text{ 在前 K 大}\}$$

输出计算：
$$y = \sum_{i \in \text{TopK}} g_i \cdot E_i(x)$$

### 2.2 负载均衡损失

防止所有 token 都路由到少数专家：

$$L_{aux} = \alpha \cdot N \cdot \sum_i f_i \cdot P_i$$

其中：
- $f_i$ = 分配给专家 i 的 token 比例
- $P_i$ = 路由到专家 i 的平均概率
- $N$ = 专家数量

### 2.3 路由策略对比

| 策略 | 描述 | 优点 | 缺点 |
|:-----|:-----|:-----|:-----|
| Top-K | 每个 token 选 K 个专家 | 表达能力强 | 计算量较大 |
| Switch (Top-1) | 每个 token 选 1 个专家 | 高效 | 可能损失精度 |
| Expert Choice | 专家选择 token | 完美负载均衡 | 实现复杂 |
