## 1. Chain of Thought (CoT) 思维链

### 1.1 核心思想

Chain of Thought (CoT) 是一种提示工程技术，通过引导 LLM 生成中间推理步骤来解决复杂问题。

**传统提示 vs CoT 提示**:

```
传统提示:
Q: Roger有5个网球，他又买了2罐网球，每罐3个。他现在有多少网球？
A: 11

CoT提示:
Q: Roger有5个网球，他又买了2罐网球，每罐3个。他现在有多少网球？
A: Roger开始有5个网球。他买了2罐，每罐3个，所以买了2×3=6个。
   总共有5+6=11个网球。答案是11。
```

### 1.2 数学原理

传统提示建模为:
$$P(answer | question) = P(a | q)$$

CoT 引入中间推理步骤 $r_1, r_2, ..., r_n$:
$$P(answer | question) = \sum_{r} P(a | r, q) \cdot P(r | q)$$

**关键洞察**: 显式生成推理链 $r$ 使模型能够:
1. 将复杂计算分解为简单子问题
2. 通过生成的文本维护工作记忆
3. 将学到的推理模式应用于新问题

### 1.3 CoT 变体

| 变体 | 描述 | 适用场景 |
|------|------|----------|
| Zero-shot CoT | 添加"让我们一步步思考" | 快速、无需示例 |
| Few-shot CoT | 提供带推理链的示例 | 最佳准确率 |
| Auto-CoT | 自动生成多样化示例 | 可扩展、多样性 |
| Program-of-Thought | 生成可执行代码 | 数学密集型任务 |

### 1.4 Zero-shot CoT

最简单的 CoT 变体，只需添加触发短语:

```python
from src.chain_of_thought import ZeroShotCoT

cot = ZeroShotCoT(trigger="standard")
prompt = cot.get_prompt("15%的80是多少？")
# 输出:
# Q: 15%的80是多少？
# A: Let's think step by step.
```

**常用触发短语**:
- `"Let's think step by step."` (标准)
- `"Let's work through this step by step, showing all calculations."` (详细)
- `"Let's break this down into steps."` (分解)

### 1.5 Few-shot CoT

提供示例来引导推理模式:

```python
from src.chain_of_thought import FewShotCoT, CoTExample

examples = [
    CoTExample(
        question="一个商店有20个苹果，卖出8个后又进货15个，现在有多少？",
        reasoning="商店开始有20个苹果。卖出8个后剩20-8=12个。进货15个后有12+15=27个。",
        answer="27个苹果"
    ),
    CoTExample(
        question="小明有3本书，小红的书是小明的2倍，两人共有多少本书？",
        reasoning="小明有3本书。小红有3×2=6本书。两人共有3+6=9本书。",
        answer="9本书"
    ),
]

cot = FewShotCoT(examples=examples)
result = cot.reason("一个班有25人，转走3人后又转来7人，现在有多少人？")
```

### 1.6 Auto-CoT

自动生成多样化示例，减少人工工作:

```python
from src.chain_of_thought import AutoCoT

# 问题池
questions = [
    "5+3等于多少？",
    "一打鸡蛋有多少个？",
    "一周有多少天？",
    # ...更多问题
]

auto_cot = AutoCoT(question_pool=questions, n_demonstrations=5)
auto_cot.generate_demonstrations(diversity_method="length")
result = auto_cot.reason("新问题")
```

**多样性选择方法**:
- `"length"`: 按问题长度选择，确保长短问题都有
- `"random"`: 随机选择
- `"first"`: 选择前 n 个

### 1.7 最佳实践

1. **示例数量**: 3-8 个示例效果最佳
2. **示例质量**: 确保推理步骤清晰、正确
3. **示例多样性**: 覆盖不同推理模式
4. **复杂度匹配**: 示例复杂度应与目标问题相近
5. **顺序安排**: 从简单到复杂排列示例

## 2. ReAct 推理与行动

### 2.1 核心思想

ReAct (Reasoning + Acting) 交替进行推理和行动，让 LLM 能够与外部环境交互。

**ReAct 循环**:
```
Thought: 我需要查找东京的人口
Action: search
Action Input: 东京人口2024
Observation: 东京人口约1400万
Thought: 我现在知道答案了
Final Answer: 东京人口约1400万
```

### 2.2 与其他方法对比

| 方法 | 推理 | 行动 | 接地 | 可解释性 |
|------|------|------|------|----------|
| 标准提示 | ✗ | ✗ | ✗ | 低 |
| CoT | ✓ | ✗ | ✗ | 高 |
| 工具调用 | ✗ | ✓ | ✓ | 低 |
| **ReAct** | **✓** | **✓** | **✓** | **高** |

### 2.3 核心组件

```python
from src.react import (
    Thought,      # 推理步骤
    Action,       # 行动步骤
    Observation,  # 观察结果
    ReActStep,    # 完整的TAO三元组
    ReActAgent,   # ReAct代理
)
```

**Thought (思考)**:
```python
thought = Thought(
    content="用户想知道天气，我需要调用天气API",
    step_number=1
)
```

**Action (行动)**:
```python
action = Action(
    name="get_weather",
    input={"city": "北京"},
    step_number=1
)
```

**Observation (观察)**:
```python
observation = Observation(
    content="北京: 晴, 25°C",
    step_number=1,
    success=True
)
```

### 2.4 ReAct Agent

```python
from src.react import ReActAgent, SimpleTool

# 定义工具
search_tool = SimpleTool(
    name="search",
    description="搜索互联网信息",
    func=lambda q: f"搜索结果: {q}"
)

calc_tool = SimpleTool(
    name="calculator",
    description="计算数学表达式",
    func=lambda e: str(eval(e))
)

# 创建Agent
agent = ReActAgent(
    tools=[search_tool, calc_tool],
    max_iterations=10
)

# 运行
result = agent.run("2的10次方是多少？")
print(result.final_answer)
```

### 2.5 ReAct 提示模板

```
Answer the following questions as best you can. You have access to the following tools:

search: 搜索互联网信息
calculator: 计算数学表达式

Use the following format:

Question: the input question you must answer
Thought: you should always think about what to do
Action: the action to take, should be one of [search, calculator]
Action Input: the input to the action
Observation: the result of the action
... (this Thought/Action/Action Input/Observation can repeat N times)
Thought: I now know the final answer
Final Answer: the final answer to the original input question

Begin!

Question: {question}
```

### 2.6 错误处理

ReAct 的优势之一是能够从错误中恢复:

```
Thought: 我需要计算这个表达式
Action: calculator
Action Input: 1/0
Observation: Error: division by zero
Thought: 除以零会出错，我需要检查输入
Action: calculator
Action Input: 1/1
Observation: 1.0
Thought: 现在我得到了正确结果
Final Answer: 1.0
```

## 3. Tree of Thoughts (ToT) 思维树

### 3.1 核心思想

Tree of Thoughts 将推理建模为树搜索问题，探索多条推理路径并选择最优解。

**CoT vs ToT**:
- CoT: 单条推理路径，无法回溯
- ToT: 多条路径，可以回溯和剪枝

```
        [问题]
       /  |  \
    [思考1][思考2][思考3]
     /  \    |      \
  [...]  [...] [...]  [...]
```

### 3.2 数学建模

ToT 将推理建模为树搜索:
$$T = (V, E)$$

其中:
- $V$ 是思考节点集合（部分解）
- $E$ 是边集合（思考转换）

每个节点 $v$ 有价值函数:
$$V(v) = f(s_v, g)$$

搜索目标:
$$v^* = \arg\max_{v \in \text{leaves}(T)} V(v)$$

### 3.3 核心组件

```python
from src.tree_of_thoughts import (
    ThoughtNode,           # 思考节点
    ThoughtGenerator,      # 思考生成器
    ThoughtEvaluator,      # 思考评估器
    SearchStrategy,        # 搜索策略
    BFSSearch,            # 广度优先搜索
    DFSSearch,            # 深度优先搜索
    BeamSearch,           # 束搜索
    TreeOfThoughts,       # ToT主类
)
```

### 3.4 搜索策略对比

| 策略 | 探索方式 | 内存复杂度 | 适用场景 |
|------|----------|------------|----------|
| BFS | 广度优先 | O(b^d) | 浅层解 |
| DFS | 深度优先 | O(d) | 深层解 |
| Beam | 保留top-k | O(k*d) | 平衡探索/内存 |

### 3.5 使用示例

```python
from src.tree_of_thoughts import TreeOfThoughts, BFSSearch, BeamSearch

# 使用BFS
tot_bfs = TreeOfThoughts(search_strategy=BFSSearch())
result = tot_bfs.solve(
    problem="用1,2,3,4四个数通过加减乘除得到24",
    max_iterations=100
)

# 使用Beam Search
tot_beam = TreeOfThoughts(search_strategy=BeamSearch(beam_width=5))
result = tot_beam.solve(problem="...")
```

### 3.6 思考节点

```python
from src.tree_of_thoughts import ThoughtNode

# 创建根节点
root = ThoughtNode(thought="分析问题：用1,2,3,4得到24")

# 添加子节点
child1 = ThoughtNode(thought="尝试 (1+2) * 3 * 4")
child2 = ThoughtNode(thought="尝试 1 * 2 * 3 * 4")
root.add_child(child1)
root.add_child(child2)

# 获取路径
path = child1.get_path_thoughts()
# ['分析问题：用1,2,3,4得到24', '尝试 (1+2) * 3 * 4']
```

## 4. Self-Consistency 自一致性

### 4.1 核心思想

Self-Consistency 通过多次采样推理路径，选择最一致的答案。

**直觉**: 正确的推理路径更可能收敛到相同答案。

### 4.2 数学原理

给定问题 q，采样 n 条推理路径:
$$\{(r_1, a_1), (r_2, a_2), ..., (r_n, a_n)\}$$

多数投票选择最终答案:
$$a^* = \arg\max_a \sum_{i=1}^{n} \mathbb{1}[a_i = a]$$

加权投票（带置信度 $c_i$）:
$$a^* = \arg\max_a \sum_{i=1}^{n} c_i \cdot \mathbb{1}[a_i = a]$$

### 4.3 使用示例

```python
from src.self_consistency import SelfConsistency, MajorityVoting, WeightedVoting

# 多数投票
sc = SelfConsistency(
    n_samples=5,
    voting_strategy=MajorityVoting(),
    temperature=0.7  # 较高温度增加多样性
)

result = sc.reason("15%的80是多少？")
print(f"答案: {result.final_answer}")
print(f"置信度: {result.confidence:.2%}")
print(f"投票分布: {result.vote_counts}")
```

### 4.4 投票策略

**多数投票 (MajorityVoting)**:
```python
# 简单计数，最多票数的答案获胜
votes = {"12": 3, "11": 1, "13": 1}
winner = "12"  # 3票
confidence = 3/5 = 0.6
```

**加权投票 (WeightedVoting)**:
```python
# 考虑每条路径的置信度
paths = [
    SampledPath(answer="12", confidence=0.9),
    SampledPath(answer="12", confidence=0.8),
    SampledPath(answer="11", confidence=0.3),
]
# "12" 的加权分数: 0.9 + 0.8 = 1.7
# "11" 的加权分数: 0.3
```

### 4.5 最佳实践

1. **采样数量**: 5-20 次采样通常足够
2. **温度设置**: 0.5-0.8 平衡多样性和质量
3. **答案归一化**: 统一答案格式（如去除空格、统一大小写）
4. **一致性阈值**: 如果一致性太低，可能需要重新表述问题

## 5. Reflection 反思机制

### 5.1 核心思想

Reflection 让 LLM 评估自己的输出，检测错误并迭代改进。

**反思循环**:
```
生成响应 → 自我评估 → 生成反馈 → 改进响应 → 重复
```

### 5.2 数学建模

反思建模为迭代优化:
$$r_{t+1} = f(r_t, e(r_t, g))$$

其中:
- $r_t$ 是第 $t$ 次迭代的响应
- $e(r_t, g)$ 是评估函数
- $f$ 是改进函数

### 5.3 核心组件

```python
from src.reflection import (
    Reflection,           # 反思主类
    ReflectionStep,       # 反思步骤
    SelfEvaluator,        # 自我评估器
    ErrorDetector,        # 错误检测器
    CorrectionStrategy,   # 纠正策略
)
```

### 5.4 使用示例

```python
from src.reflection import Reflection

reflector = Reflection(
    max_iterations=3,
    target_score=0.8
)

result = reflector.reflect(
    question="解释什么是机器学习",
    initial_response="机器学习是一种AI技术"
)

print(f"初始响应: {result.initial_response}")
print(f"最终响应: {result.final_response}")
print(f"迭代次数: {result.total_iterations}")
print(f"是否改进: {result.improved}")
```

### 5.5 评估结果类型

```python

EvaluationResult.PARTIALLY_CORRECT # 部分正确
```

### 5.6 错误检测

## 6. 策略对比与选择

### 6.1 策略对比表

| 策略 | 复杂度 | 准确率提升 | 延迟 | 适用场景 |
|------|--------|------------|------|----------|
| Zero-shot CoT | 低 | 10-20% | 1.5x | 快速推理 |
| Few-shot CoT | 中 | 20-40% | 2x | 高准确率 |
| ReAct | 中 | 变化大 | 3-5x | 需要外部信息 |
| ToT | 高 | 30-50% | 5-10x | 复杂问题 |
| Self-Consistency | 中 | 15-25% | nx | 提高可靠性 |
| Reflection | 中 | 10-30% | 2-4x | 质量改进 |

### 6.2 选择指南

```
问题类型判断:
├── 简单推理 → Zero-shot CoT
├── 复杂推理 → Few-shot CoT
├── 需要外部信息 → ReAct
├── 需要探索多种方案 → ToT
├── 需要高可靠性 → Self-Consistency
└── 需要质量保证 → Reflection
```

### 6.3 组合使用

策略可以组合使用:

```python
# CoT + Self-Consistency
# 多次采样CoT推理，投票选择答案

# ReAct + Reflection
# ReAct执行后，反思结果并改进

# ToT + Self-Consistency
# 多条ToT路径，投票选择最佳
```

### 6.4 性能优化建议

1. **缓存**: 缓存相似问题的推理结果
2. **并行**: Self-Consistency 的多次采样可并行
3. **早停**: ToT 找到足够好的解就停止
4. **剪枝**: ToT 中剪掉低分支
5. **批处理**: 批量处理多个问题
