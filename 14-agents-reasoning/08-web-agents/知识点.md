# 08-web-agents 知识点

## 1. 概述

本模块实现了 Web 交互智能体，包括：
- **BrowserAgent**: 网页导航、表单填写、信息提取
- **APIAgent**: API 发现、请求构建、链式调用

### 核心能力

| 组件 | 功能 | 核心技术 |
|------|------|----------|
| BrowserAgent | 网页自动化 | DOM解析、动作规划 |
| APIAgent | API交互 | OpenAPI、请求链 |

## 2. Browser Agent 架构

### 2.1 系统架构

```
HTML → PageAnalyzer → PageState
            ↓
Goal → NavigationPlanner → Actions
            ↓
Actions → BrowserController → Results
```

### 2.2 核心数据结构

#### DOMElement - DOM元素

```python
@dataclass
class DOMElement:
    element_id: str
    element_type: ElementType  # LINK, BUTTON, INPUT, etc.
    tag_name: str
    text: str
    attributes: dict[str, str]  # id, class, href, etc.
    xpath: str
    css_selector: str
    is_visible: bool
    is_enabled: bool
```

#### PageState - 页面状态

```python
@dataclass
class PageState:
    url: str
    title: str
    elements: list[DOMElement]
    html: str
    screenshot: str | None
    load_time: float
    cookies: dict[str, str]
    
    def find_element_by_text(self, text: str) -> DOMElement | None: ...
    def get_links(self) -> list[DOMElement]: ...
    def get_forms(self) -> list[DOMElement]: ...
```

### 2.3 浏览器动作

| 动作类型 | 描述 | 参数 |
|----------|------|------|
| NavigationAction | 导航到URL | url, wait_for |
| ClickAction | 点击元素 | selector, text |
| FormAction | 填写表单 | selector, value |
| ScrollAction | 滚动页面 | direction, amount |
| WaitAction | 等待条件 | condition, value |

### 2.4 使用示例

```python
from browser_agent import create_browser_agent

# 创建智能体
agent = create_browser_agent(
    name="WebCrawler",
    simulate=True,
)

# 执行任务
result = await agent.execute_task(
    "Search for Python tutorials",
    start_url="https://www.google.com",
)

# 辅助方法
await agent.navigate("https://example.com")
await agent.click(text="Submit")
await agent.fill("#email", "user@example.com")
await agent.search("Python tutorials")

# 信息提取
links = await agent.extract_links()
text = await agent.extract_text()
```

## 3. API Agent 架构

### 3.1 系统架构

```
OpenAPI Spec → APIDiscovery → APISchema
                    ↓
Request → RequestBuilder → APIRequest
                    ↓
Response → ResponseParser → Extracted Data
                    ↓
Chain → APIChainExecutor → Results
```

### 3.2 核心数据结构

#### APIEndpoint - API端点

```python
@dataclass
class APIEndpoint:
    path: str  # /users/{id}
    method: HTTPMethod
    description: str
    parameters: dict[str, dict]
    request_body: dict | None
    response_schema: dict | None
    requires_auth: bool
    tags: list[str]
    
    @property
    def path_params(self) -> list[str]:
        return re.findall(r'\{(\w+)\}', self.path)
```

#### APIRequest / APIResponse

```python
@dataclass
class APIRequest:
    url: str
    method: HTTPMethod
    headers: dict[str, str]
    query_params: dict[str, str]
    body: dict | str | None
    timeout: float

@dataclass
class APIResponse:
    status_code: int
    headers: dict[str, str]
    body: Any
    elapsed_time: float
    error: str | None
    
    @property
    def is_success(self) -> bool:
        return 200 <= self.status_code < 300
```

### 3.3 API链式调用

```python
# 定义链式调用
executor = APIChainExecutor()

# 步骤1: 登录获取token
step1 = executor.add_step(
    "/auth/login",
    body={"username": "user", "password": "pass"},
    extract_paths={"token": "data.access_token"},
)

# 步骤2: 使用token获取用户信息（依赖步骤1）
step2 = executor.add_step(
    "/users/me",
    headers={"Authorization": "Bearer ${step1.token}"},
    depends_on=[step1],
)

# 执行链
results = await executor.execute()
```

### 3.4 使用示例

```python
from api_agent import create_api_agent

# 创建智能体
agent = create_api_agent(
    name="APIClient",
    base_url="https://api.example.com",
    auth_token="your-token",
)

# 设置API Schema
agent.set_schema({
    "openapi": "3.0.0",
    "info": {"title": "Example API", "version": "1.0.0"},
    "paths": {
        "/users": {"get": {"summary": "List users"}},
        "/users/{id}": {"get": {"summary": "Get user by ID"}},
    }
})

# 发送请求
response = await agent.get("/users")
response = await agent.post("/users", body={"name": "John"})

# 提取数据
users = agent.extract(response, "data.users")

# 链式调用
steps = [
    {"endpoint": "/auth/login", "body": {"user": "admin"}},
    {"endpoint": "/users/me"},
]
results = await agent.execute_chain(steps)
```

## 4. 数学基础

### 4.1 网页导航 MDP

网页导航可建模为马尔可夫决策过程 (MDP)：

- **状态空间** $S$: 页面状态（URL, DOM）
- **动作空间** $A$: 动作（click, type, scroll, navigate）
- **转移函数** $T$: 页面转换
- **奖励函数** $R$: 任务完成奖励

最优导航策略：

$$\pi^*(s) = \arg\max_a \sum_{s'} P(s'|s,a) \cdot [R(s,a,s') + \gamma V^*(s')]$$

### 4.2 API 链式执行

API 链作为有向无环图 (DAG)：

$$G = (V, E)$$

其中 $V$ 是端点集合，$E$ 是数据依赖关系。

最优执行顺序通过拓扑排序获得：

$$\text{order} = \text{TopologicalSort}(G)$$

### 4.3 重试策略

指数退避重试：

$$\text{delay}(n) = \min(\text{base} \cdot 2^n + \text{jitter}, \text{max\_delay})$$

$k$ 次重试后成功概率：

$$P(\text{success}_k) = 1 - (1 - p)^k$$

## 6. OpenAPI 集成

### 6.1 从 OpenAPI 发现 API

```python
discovery = APIDiscovery()
schema = discovery.from_openapi({
    "openapi": "3.0.0",
    "info": {"title": "My API", "version": "1.0.0"},
    "servers": [{"url": "https://api.example.com"}],
    "paths": {
        "/users": {
            "get": {"summary": "List users", "tags": ["users"]},
            "post": {"summary": "Create user", "tags": ["users"]},
        },
    },
})

# 查找端点
endpoints = schema.find_endpoint(tag="users")
user_endpoint = schema.get_endpoint_by_path("/users/{id}", HTTPMethod.GET)
```

### 6.2 数据提取

```python
parser = ResponseParser()

# JSONPath-like 提取
name = parser.extract(response, "data.user.name")
users = parser.extract(response, "data.users[*].name")
first = parser.extract(response, "data.users[0]")

# 批量提取
result = parser.extract_all(response, {
    "id": "data.id",
    "name": "data.name",
    "email": "data.email",
})
```
