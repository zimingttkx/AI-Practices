## 一、概述：为什么需要工具调用

### 1.1 LLM 的根本局限性

大语言模型（LLM）本质上是一个**文本生成器**，它只能基于训练数据生成文本，无法：

| 局限性 | 具体表现 | 示例 |
|--------|----------|------|
| **无法获取实时信息** | 训练数据有截止日期 | "今天北京天气如何？" → 无法回答 |
| **无法精确计算** | 数学运算靠"猜测" | "123456 × 789012 = ?" → 可能算错 |
| **无法操作外部系统** | 只能生成文本 | "帮我发一封邮件" → 无法执行 |
| **无法访问私有数据** | 不知道你的数据库内容 | "查询订单状态" → 无法访问 |

### 1.2 Tool Use 的解决方案

**Tool Use（工具调用）** 让 LLM 输出结构化的"调用意图"，由外部程序执行后返回结果：

## 二、Function Calling 函数调用

### 2.1 核心概念

**Function Calling** 是让 LLM 以结构化方式调用外部函数的机制。它包含两个方向：

1. **定义阶段**：告诉 LLM "有哪些函数可以调用，每个函数需要什么参数"
2. **调用阶段**：解析 LLM 输出的 "我想调用哪个函数，传什么参数"

```python
# 定义阶段：创建函数的"说明书"
get_weather = FunctionDefinition(
    name="get_weather",
    description="获取指定城市的实时天气信息",
    parameters=[
        FunctionParameter(name="city", type=ParameterType.STRING, description="城市名称"),
    ],
)

# 调用阶段：解析 LLM 的输出
parser = FunctionCallParser([get_weather])
calls = parser.parse('{"name": "get_weather", "arguments": {"city": "北京"}}')
```

### 2.2 参数类型系统

Function Calling 使用 JSON Schema 描述参数类型：

| ParameterType | JSON Schema | Python 类型 | 示例值 |
|---------------|-------------|-------------|--------|
| `STRING` | `"string"` | `str` | `"hello"` |
| `INTEGER` | `"integer"` | `int` | `42` |
| `NUMBER` | `"number"` | `float` | `3.14` |
| `BOOLEAN` | `"boolean"` | `bool` | `true` / `false` |
| `ARRAY` | `"array"` | `list` | `[1, 2, 3]` |
| `OBJECT` | `"object"` | `dict` | `{"key": "value"}` |

### 2.3 FunctionParameter 参数定义

`FunctionParameter` 定义单个参数的完整规格：

```python
from src.function_calling import FunctionParameter, ParameterType

# 必需参数
city_param = FunctionParameter(
    name="city",                      # 参数名（必需）
    type=ParameterType.STRING,        # 参数类型（必需）
    description="城市名称，如'北京'",  # 描述（必需，帮助 LLM 理解）
    required=True,                    # 是否必需（默认 True）
)

# 可选参数 + 默认值
limit_param = FunctionParameter(
    name="limit",
    type=ParameterType.INTEGER,
    description="返回结果数量上限",
    required=False,                   # 可选参数
    default=10,                       # 默认值
)

# 枚举参数（限定取值范围）
unit_param = FunctionParameter(
    name="unit",
    type=ParameterType.STRING,
    description="温度单位",
    required=False,
    enum=["celsius", "fahrenheit"],   # 只能是这两个值之一
    default="celsius",
)

# 数组参数
tags_param = FunctionParameter(
    name="tags",
    type=ParameterType.ARRAY,
    description="标签列表",
    items={"type": "string"},         # 数组元素类型
)
```

**参数验证规则**：

```python
# 验证参数值是否符合类型
error = city_param.validate_value("北京")    # None（验证通过）
error = city_param.validate_value(123)       # "Expected string, got int"
error = unit_param.validate_value("kelvin")  # "Value must be one of ['celsius', 'fahrenheit']"
```

### 2.4 FunctionDefinition 函数定义

`FunctionDefinition` 组合多个参数，形成完整的函数"说明书"：

```python
from src.function_calling import FunctionDefinition, FunctionParameter, ParameterType

# 定义完整的函数
search_function = FunctionDefinition(
    name="web_search",                           # 函数名（LLM 调用时使用）
    description="在互联网上搜索信息，返回相关结果",  # 功能描述（越清晰越好！）
    parameters=[
        FunctionParameter(
            name="query",
            type=ParameterType.STRING,
            description="搜索关键词",
            required=True,
        ),
        FunctionParameter(
            name="max_results",
            type=ParameterType.INTEGER,
            description="最大返回结果数",
            required=False,
            default=10,
        ),
        FunctionParameter(
            name="language",
            type=ParameterType.STRING,
            description="搜索语言",
            required=False,
            enum=["zh", "en", "ja"],
            default="zh",
        ),
    ],
    returns="搜索结果列表，每个结果包含标题、链接和摘要",  # 返回值描述（可选）
)
```

**关键点**：`description` 是 LLM 决定是否调用该函数的主要依据，务必写清楚！

### 2.5 自动生成函数定义

手动定义参数很繁琐，`create_function_schema` 可以从 Python 函数自动生成：

```python
from src.function_calling import create_function_schema

def calculate(expression: str, precision: int = 2) -> float:
    """计算数学表达式并返回结果。

    Args:
        expression: 数学表达式，如 "2 + 3 * 4"
        precision: 小数精度，默认保留2位

    Returns:
        计算结果
    """
    return round(eval(expression), precision)

# 自动从函数签名和 docstring 生成定义
calc_def = create_function_schema(calculate)

print(calc_def.name)         # "calculate"
print(calc_def.description)  # "计算数学表达式并返回结果。"
print(len(calc_def.parameters))  # 2
```

**类型映射规则**：

| Python 类型注解 | 生成的 ParameterType |
|----------------|---------------------|
| `str` | `STRING` |
| `int` | `INTEGER` |
| `float` | `NUMBER` |
| `bool` | `BOOLEAN` |
| `list` / `List[T]` | `ARRAY` |
| `dict` / `Dict[K, V]` | `OBJECT` |
| `Optional[T]` | 提取内部类型，`required=False` |

### 2.6 OpenAI vs Anthropic 格式

不同 LLM 厂商的 API 格式略有差异：

**OpenAI 格式**（外层包裹 `type: function`）：

```json
{
  "type": "function",
  "function": {
    "name": "get_weather",
    "description": "获取天气信息",
    "parameters": {
      "type": "object",
      "properties": {
        "city": {
          "type": "string",
          "description": "城市名称"
        }
      },
      "required": ["city"]
    }
  }
}
```

**Anthropic 格式**（使用 `input_schema`）：

```json
{
  "name": "get_weather",
  "description": "获取天气信息",
  "input_schema": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "城市名称"
      }
    },
    "required": ["city"]
  }
}
```

**转换方法**：

```python
# 转换为 OpenAI 格式
openai_schema = search_function.to_openai_schema()

# 转换为 Anthropic 格式
anthropic_schema = search_function.to_anthropic_schema()
```

### 2.7 FunctionCallParser 解析器

`FunctionCallParser` 从 LLM 输出中提取函数调用：

```python
from src.function_calling import FunctionCallParser, FunctionCall

# 创建解析器，传入可用的函数定义
parser = FunctionCallParser([get_weather, search_function])

# 支持多种输入格式
```

**支持的输入格式**：

| 格式 | 示例 |
|------|------|
| JSON 代码块 | ` ```json\n{"name": "...", "arguments": {...}}\n``` ` |
| OpenAI 格式 | `{"name": "...", "arguments": {...}}` |
| Anthropic 格式 | `{"type": "tool_use", "name": "...", "input": {...}}` |
| 通用格式 | `{"function": "...", "args": {...}}` |

```python
# 解析 JSON 代码块
llm_output = '''
我来帮你查询天气：
```json
{"name": "get_weather", "arguments": {"city": "北京"}}
```
'''
calls = parser.parse(llm_output)
print(calls[0].name)       # "get_weather"
print(calls[0].arguments)  # {"city": "北京"}

# 解析 Anthropic 格式
anthropic_output = '{"type": "tool_use", "name": "search", "input": {"query": "Python"}}'
calls = parser.parse(anthropic_output)
```

### 2.8 函数调用验证

LLM 可能生成错误的调用，需要验证：

```python
# 创建调用对象
call = FunctionCall(name="get_weather", arguments={"city": "北京"})

# 验证调用
errors = parser.validate(call)

if errors:
    print(f"验证失败: {errors}")
else:
    print("验证通过，可以执行")
```

**验证检查项**：

| 检查项 | 错误示例 |
|--------|----------|
| 函数是否存在 | `Unknown function: unknown_func` |
| 必需参数是否提供 | `Missing required parameter: city` |
| 参数类型是否正确 | `Parameter 'age': Expected integer, got string` |
| 枚举值是否有效 | `Value must be one of ['celsius', 'fahrenheit']` |
| 未知参数检测 | `Unknown parameter: extra_param` |

## 三、Tool Registry 工具注册

### 3.1 核心概念

**Tool Registry（工具注册表）** 是管理多个工具的中央仓库，实现了服务定位器模式：

```
实际 Agent 需要管理的工具:
├── 搜索类: web_search, wiki_search, code_search
├── 计算类: calculator, unit_convert, date_calc
├── 文件类: read_file, write_file, list_dir
├── API类: weather, stock, translate
└── 系统类: run_command, send_email, create_task
```

**ToolRegistry 解决的问题**：
- 统一管理所有工具
- 支持装饰器快速注册
- 按标签分类过滤
- 动态启用/禁用
- 一键导出为 API 格式

### 3.2 Tool 类结构

`Tool` 类封装了函数及其元信息：

```python
from dataclasses import dataclass
from typing import Callable, List

@dataclass
class Tool:
    name: str                      # 工具名称（LLM 调用时使用）
    description: str               # 工具描述（帮助 LLM 选择）
    func: Callable                 # 实际执行的函数
    parameters: List[FunctionParameter]  # 参数列表
    returns: Optional[str]         # 返回值描述
    tags: List[str]                # 标签（用于分类过滤）
    enabled: bool                  # 是否启用
    requires_confirmation: bool    # 是否需要用户确认
```

**Tool 的核心方法**：

| 方法 | 作用 |
|------|------|
| `__call__(*args, **kwargs)` | 直接调用工具（会检查 enabled 状态） |
| `to_function_definition()` | 转换为 FunctionDefinition |
| `to_openai_schema()` | 导出 OpenAI 格式 |
| `to_anthropic_schema()` | 导出 Anthropic 格式 |
| `get_signature()` | 获取人类可读的函数签名 |

### 3.3 ToolRegistry 核心方法

```python
from src.tool_registry import ToolRegistry

registry = ToolRegistry()
```

**注册方法**：

| 方法 | 作用 | 示例 |
|------|------|------|
| `@registry.register` | 装饰器注册 | `@registry.register` |
| `@registry.register(...)` | 带参数装饰器 | `@registry.register(tags=["math"])` |
| `register_tool(tool)` | 直接注册 Tool 对象 | `registry.register_tool(my_tool)` |
| `unregister(name)` | 注销工具 | `registry.unregister("old_tool")` |

**查询方法**：

| 方法 | 作用 | 返回值 |
|------|------|--------|
| `get(name)` | 按名称获取 | `Tool` 或 `None` |
| `registry[name]` | 索引获取（不存在抛异常） | `Tool` |
| `name in registry` | 检查是否存在 | `bool` |
| `list_tools()` | 列出所有工具 | `List[Tool]` |
| `list_names()` | 列出所有工具名 | `List[str]` |
| `get_by_tag(tag)` | 按标签过滤 | `List[Tool]` |
| `list_tags()` | 列出所有标签 | `List[str]` |

**控制方法**：

| 方法 | 作用 |
|------|------|
| `enable(name)` | 启用工具 |
| `disable(name)` | 禁用工具 |
| `clear()` | 清空所有工具 |

**导出方法**：

| 方法 | 作用 |
|------|------|
| `to_openai_tools()` | 导出所有工具为 OpenAI 格式 |
| `to_anthropic_tools()` | 导出所有工具为 Anthropic 格式 |
| `get_tool_descriptions()` | 生成人类可读的工具描述 |

### 3.4 装饰器注册详解

```python
from src.tool_registry import ToolRegistry

registry = ToolRegistry()

# 方式1：最简注册（自动提取函数名和 docstring）
@registry.register
def search(query: str, max_results: int = 10) -> str:
    """搜索信息"""
    return f"搜索 '{query}' 的前 {max_results} 条结果"

# 方式2：自定义名称
@registry.register(name="web_search")
def my_search_function(query: str) -> str:
    """网页搜索"""
    return f"搜索: {query}"

# 方式3：添加标签（用于分类）
@registry.register(tags=["math", "utility"])
def calculator(expression: str) -> float:
    """计算数学表达式"""
    return eval(expression)

# 方式4：需要用户确认的敏感操作
@registry.register(requires_confirmation=True, tags=["dangerous"])
def delete_file(path: str) -> str:
    """删除文件（危险操作）"""
    import os
    os.remove(path)
    return f"已删除: {path}"

# 方式5：完整配置
@registry.register(
    name="send_email",
    description="发送电子邮件到指定地址",  # 覆盖 docstring
    tags=["communication", "external"],
    requires_confirmation=True,
)
def email_sender(to: str, subject: str, body: str) -> str:
    """原始 docstring（会被 description 覆盖）"""
    return f"邮件已发送到 {to}"
```

### 3.5 全局装饰器 @tool

不想每次创建 ToolRegistry？使用全局 `@tool` 装饰器：

```python
from src.tool_registry import tool, get_default_registry, reset_default_registry

# 重置全局注册表（清空之前的注册）
reset_default_registry()

# 使用全局 @tool 装饰器
@tool
def global_search(query: str) -> str:
    """全局搜索工具"""
    return f"搜索: {query}"

@tool(name="global_calc", tags=["math"])
def my_calculator(expr: str) -> float:
    """全局计算器"""
    return eval(expr)

# 获取全局注册表
global_registry = get_default_registry()
print(global_registry.list_names())  # ['global_search', 'global_calc']
```

### 3.6 标签系统

标签用于对工具进行分类，便于按类别过滤：

```python
# 注册带标签的工具
@registry.register(tags=["search", "web"])
def web_search(query: str) -> str: ...

@registry.register(tags=["search", "local"])
def file_search(pattern: str) -> str: ...

@registry.register(tags=["math"])
def calculator(expr: str) -> float: ...

# 按标签查询
search_tools = registry.get_by_tag("search")  # [web_search, file_search]
math_tools = registry.get_by_tag("math")      # [calculator]

# 列出所有标签
all_tags = registry.list_tags()  # ["search", "web", "local", "math"]

# 按多个标签过滤（返回匹配任意标签的工具）
tools = registry.list_tools(tags=["search", "math"])  # 匹配 search 或 math
```

### 3.7 启用/禁用工具

动态控制工具的可用性：

```python
# 禁用工具
registry.disable("dangerous_tool")
print(registry.get("dangerous_tool").enabled)  # False

# 禁用的工具不会出现在导出中
tools = registry.to_openai_tools(enabled_only=True)  # 不包含 dangerous_tool

# 禁用的工具调用会抛出异常
try:
    registry["dangerous_tool"]("arg")
except RuntimeError as e:
    print(e)  # "Tool 'dangerous_tool' is disabled"

# 重新启用
registry.enable("dangerous_tool")
```

### 3.8 导出为 API 格式

```python
import json

# 导出为 OpenAI 格式
openai_tools = registry.to_openai_tools()
print(json.dumps(openai_tools[0], indent=2))

# 导出为 Anthropic 格式
anthropic_tools = registry.to_anthropic_tools()

# 只导出启用的工具（默认行为）
enabled_tools = registry.to_openai_tools(enabled_only=True)

### 4.9 生命周期钩子

钩子允许在执行前后插入自定义逻辑：

```python
# 定义钩子函数
def log_before(tool, args, context):
    print(f"[LOG] 即将执行: {tool.name}({args})")

def log_after(tool, args, context, result):
    print(f"[LOG] 执行完成: {tool.name} -> {result.status}")

def handle_error(tool, args, context, result):
    print(f"[ERROR] {tool.name} 失败: {result.error}")

# 注册钩子
executor.add_hook("before_execute", log_before)
executor.add_hook("after_execute", log_after)
executor.add_hook("on_error", handle_error)

# 执行时会自动触发钩子
executor.execute("add", {"a": 1, "b": 2})
# [LOG] 即将执行: add({'a': 1, 'b': 2})
# [LOG] 执行完成: add -> success

# 移除钩子
executor.remove_hook("before_execute", log_before)
```

**可用的钩子事件**：

| 事件 | 触发时机 | 回调参数 |
|------|----------|----------|
| `before_execute` | 执行前 | `(tool, args, context)` |
| `after_execute` | 执行后 | `(tool, args, context, result)` |
| `on_error` | 执行失败时 | `(tool, args, context, result)` |

### 5.6 自动修复功能

LLM 有时会生成格式错误的 JSON，`auto_fix=True` 可以自动修复：

```python
# 启用自动修复
parser = StructuredOutputParser(Person, auto_fix=True)

# 常见错误1：尾随逗号
output1 = '{"name": "张三", "age": 30,}'  # 末尾多了逗号
result = parser.parse(output1)  # 自动修复，正常解析

# 常见错误2：单引号
output2 = "{'name': '张三', 'age': 30}"  # 使用了单引号
result = parser.parse(output2)  # 自动转换为双引号

# 常见错误3：Python 布尔值
output3 = '{"name": "张三", "active": True}'  # True 应该是 true
result = parser.parse(output3)  # 自动转换

# 常见错误4：Python None
output4 = '{"name": "张三", "email": None}'  # None 应该是 null
result = parser.parse(output4)  # 自动转换
```

**自动修复规则**：

| 错误类型 | 错误示例 | 修复后 |
|----------|----------|--------|
| 尾随逗号 | `{"a": 1,}` | `{"a": 1}` |
| 单引号 | `{'a': 1}` | `{"a": 1}` |
| Python True | `{"a": True}` | `{"a": true}` |
| Python False | `{"a": False}` | `{"a": false}` |
| Python None | `{"a": None}` | `{"a": null}` |

# ============ 第一步：定义和注册工具 ============

registry = ToolRegistry()

@registry.register(tags=["weather", "api"])
def get_weather(city: str, unit: str = "celsius") -> str:
    """获取指定城市的实时天气信息。

    Args:
        city: 城市名称，如"北京"、"上海"
        unit: 温度单位，celsius（摄氏度）或 fahrenheit（华氏度）

    Returns:
        天气信息字符串
    """
    # 实际应用中这里会调用天气 API
    weather_data = {
        "北京": {"temp": 25, "condition": "晴天", "humidity": 45},
        "上海": {"temp": 28, "condition": "多云", "humidity": 65},
    }

    if city not in weather_data:
        return f"未找到城市 {city} 的天气信息"

    data = weather_data[city]
    temp = data["temp"] if unit == "celsius" else data["temp"] * 9/5 + 32
    unit_symbol = "°C" if unit == "celsius" else "°F"

    return f"{city}: {data['condition']}，{temp}{unit_symbol}，湿度 {data['humidity']}%"

@registry.register(tags=["math", "utility"])
def calculator(expression: str) -> float:
    """计算数学表达式。

    Args:
        expression: 数学表达式，如 "2 + 3 * 4"

    Returns:
        计算结果
    """
    # 注意：实际应用中应使用安全的表达式解析器
    allowed_chars = set("0123456789+-*/.() ")
    if not all(c in allowed_chars for c in expression):
        raise ValueError("表达式包含非法字符")
    return eval(expression)

@registry.register(tags=["search"])
def web_search(query: str, max_results: int = 5) -> str:
    """搜索互联网信息。

    Args:
        query: 搜索关键词
        max_results: 最大返回结果数

    Returns:
        搜索结果摘要
    """
    # 模拟搜索结果
    return f"搜索 '{query}' 的前 {max_results} 条结果：\n1. 结果1\n2. 结果2..."

# ============ 第二步：创建执行器和解析器 ============

executor = ToolExecutor(
    registry=registry,
    default_timeout=30.0,
    max_retries=3,
)

# 从注册表创建函数定义列表
function_defs = [tool.to_function_definition() for tool in registry]
parser = FunctionCallParser(function_defs)

# ============ 第三步：导出工具给 LLM ============

# OpenAI 格式
openai_tools = registry.to_openai_tools()

# Anthropic 格式
anthropic_tools = registry.to_anthropic_tools()

# 人类可读描述（用于 prompt）

# ============ 第四步：处理 LLM 响应 ============

def process_llm_response(llm_output: str) -> str:
    """处理 LLM 的工具调用响应"""

    # 1. 解析工具调用
    try:
        calls = parser.parse(llm_output)
    except Exception as e:
        return f"解析失败: {e}"

    if not calls:
        return "LLM 没有请求调用任何工具"

    # 2. 验证调用
    for call in calls:
        errors = parser.validate(call)
        if errors:
            return f"验证失败: {errors}"

    # 3. 执行工具
    results = []
    for call in calls:
        result = executor.execute_call(call)
        results.append(result)

    # 4. 格式化结果
    output_parts = []
    for result in results:
        if result.is_success:
            output_parts.append(f"[{result.tool_name}] 成功: {result.output}")
        else:
            output_parts.append(f"[{result.tool_name}] 失败: {result.error}")

    return "\n".join(output_parts)

# ============ 第五步：测试 ============

# 模拟 LLM 输出

```json

```
'''

# [get_weather] 成功: 北京: 晴天，25°C，湿度 45%

### 6.3 多轮对话示例

```python
"""
支持多轮工具调用的对话 Agent
"""

class ToolAgent:
    """简单的工具调用 Agent"""

    def __init__(self, registry: ToolRegistry):
        self.registry = registry
        self.executor = ToolExecutor(registry)
        self.parser = FunctionCallParser(
            [t.to_function_definition() for t in registry]
        )
        self.conversation_history = []

    def chat(self, user_message: str, llm_response: str) -> str:
        """处理一轮对话

        Args:
            user_message: 用户输入
            llm_response: LLM 的响应（可能包含工具调用）

        Returns:
            最终回复给用户的消息
        """
        # 记录用户消息
        self.conversation_history.append({
            "role": "user",
            "content": user_message
        })

        # 尝试解析工具调用
        calls = self.parser.parse(llm_response)

        if not calls:
            # 没有工具调用，直接返回 LLM 响应
            self.conversation_history.append({
                "role": "assistant",
                "content": llm_response
            })
            return llm_response

        # 执行工具调用
        tool_results = []
        for call in calls:
            result = self.executor.execute_call(call)
            tool_results.append({
                "tool_name": result.tool_name,
                "result": result.output if result.is_success else result.error,
                "success": result.is_success,
            })

        # 记录工具调用和结果
        self.conversation_history.append({
            "role": "assistant",
            "content": llm_response,
            "tool_calls": [c.to_dict() for c in calls],
        })
        self.conversation_history.append({
            "role": "tool",
            "tool_results": tool_results,
        })

        # 返回工具结果（实际应用中会再次调用 LLM 生成最终回复）
        return str(tool_results)

    def get_tools_for_llm(self, format: str = "openai") -> list:
        """获取 LLM 可用的工具列表"""
        if format == "openai":
            return self.registry.to_openai_tools()
        elif format == "anthropic":
            return self.registry.to_anthropic_tools()
        else:
            raise ValueError(f"Unknown format: {format}")

# 使用示例
agent = ToolAgent(registry)

# 模拟对话
user_input = "北京和上海今天哪个更热？"
llm_response = '''
让我查询两个城市的天气：
```json
[
    {"name": "get_weather", "arguments": {"city": "北京"}},
    {"name": "get_weather", "arguments": {"city": "上海"}}
]
```
'''

result = agent.chat(user_input, llm_response)
print(result)
```

| `SUCCESS` | 执行成功 | 使用 `result.output` |
| `ERROR` | 执行出错 | 检查 `result.error` |
| `TIMEOUT` | 执行超时 | 增加超时或优化工具 |
| `CANCELLED` | 执行取消 | 检查取消原因 |
| `PENDING` | 等待执行 | 等待执行开始 |
| `RUNNING` | 正在执行 | 等待执行完成 |
