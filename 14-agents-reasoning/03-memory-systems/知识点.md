## 1. 概述与动机

### 1.1 为什么 AI Agent 需要记忆系统？

大型语言模型 (LLM) 本身是**无状态**的 - 每次调用都是独立的，模型不会记住之前的交互。这带来了几个关键问题：

**问题 1: 上下文丢失**
```
用户: 我叫张三
AI: 你好张三！
用户: 我的名字是什么？
AI: 抱歉，我不知道你的名字。  ← 无记忆导致的问题
```

**问题 2: Token 限制**
- GPT-4: 8K-128K tokens
- Claude: 100K-200K tokens
- 长对话会超出限制，必须截断

**问题 3: 知识时效性**
- 模型训练数据有截止日期
- 无法获取用户特定信息
- 需要外部知识补充

### 1.2 记忆系统的核心价值

| 能力 | 无记忆 | 有记忆 |
|------|--------|--------|
| 多轮对话 | ❌ 每轮独立 | ✅ 上下文连贯 |
| 用户个性化 | ❌ 通用回复 | ✅ 个性化服务 |
| 长期学习 | ❌ 无法积累 | ✅ 持续改进 |
| 复杂任务 | ❌ 单步执行 | ✅ 多步规划 |

## 2. 认知科学基础

### 2.1 人类记忆系统模型

AI Agent 的记忆系统设计借鉴了认知心理学的 **Atkinson-Shiffrin 模型**：

```
感觉记忆 ──▶ 短期记忆 ──▶ 长期记忆
(毫秒级)     (秒-分钟)     (永久)
   │            │            │
   │            │            ├── 陈述性记忆 (事实、事件)
   │            │            └── 程序性记忆 (技能、习惯)
   │            │
   │            └── 工作记忆 (Baddeley模型)
   │                 ├── 语音环路
   │                 ├── 视空间画板
   │                 └── 中央执行系统
   │
   └── 图像记忆、回声记忆
```

### 2.2 记忆类型映射

| 人类记忆 | AI Agent 对应 | 实现方式 |
|----------|---------------|----------|
| 感觉记忆 | 输入缓冲 | 原始用户输入 |
| 短期记忆 | 对话上下文 | ConversationBuffer |
| 工作记忆 | 活跃上下文 | SlidingWindowMemory |
| 情景记忆 | 事件记录 | MemoryType.EVENT |
| 语义记忆 | 知识库 | MemoryType.KNOWLEDGE |
| 程序记忆 | 工具使用模式 | MemoryType.TASK |

### 2.3 遗忘曲线与记忆衰减

**艾宾浩斯遗忘曲线**描述了记忆随时间的衰减：

$$R(t) = e^{-\frac{t}{S}}$$

其中：
- $R(t)$: 时间 $t$ 后的记忆保持率
- $S$: 记忆强度 (stability)
- $t$: 经过的时间

在 AI Agent 中，我们使用类似的**指数衰减**模型：

$$\text{recency}(m) = e^{-\lambda \cdot \Delta t}$$

## 3. 短期记忆系统

### 3.1 核心数据结构

#### Message 消息类

```python
@dataclass
class Message:

    role: MessageRole          # 角色: system/user/assistant/tool
    content: str               # 消息内容
    timestamp: datetime        # 创建时间戳
    importance: float          # 重要性评分 [0.0, 1.0]
    token_count: Optional[int] # Token 数量 (延迟计算)
    metadata: Dict[str, Any]   # 扩展元数据
```

#### MessageRole 角色枚举

```python
class MessageRole(str, Enum):
    SYSTEM = "system"        # 系统指令 (最高优先级)
    USER = "user"            # 用户输入
    ASSISTANT = "assistant"  # AI 回复
    TOOL = "tool"            # 工具调用结果
```

### 3.2 策略一: ConversationBuffer (完整缓存)

**核心思想**: 保存所有消息，不做任何截断。

**算法复杂度**:
- 添加: $O(1)$
- 检索: $O(n)$
- 空间: $O(n)$

**实现原理**:
```python
class ConversationBuffer(ShortTermMemory):
    def __init__(self, system_message: Optional[str] = None):
        self._messages: List[Message] = []
        if system_message:
            self.add_system_message(system_message)
    
    def add(self, message: Message) -> None:
        self._messages.append(message)
    
    def get_messages(self) -> List[Message]:
        return self._messages.copy()
```

**使用场景**:
- 短对话 (< 20 轮)
- 调试和开发
- 需要完整历史的场景

**局限性**:
- 长对话会超出 Token 限制
- 成本随对话线性增长

### 3.3 策略二: SlidingWindowMemory (滑动窗口)

**核心思想**: 只保留最近的 $k$ 条消息，旧消息自动丢弃。

**数学模型**:
$$\text{Context}_t = \{m_{t-k+1}, m_{t-k+2}, ..., m_t\}$$

其中 $k$ 是窗口大小。

**算法复杂度**:
- 添加: $O(1)$ 平均, $O(k)$ 最坏
- 检索: $O(k)$
- 空间: $O(k)$

**实现原理**:
```python
class SlidingWindowMemory(ShortTermMemory):
    def __init__(self, window_size: int = 10):
        self._window_size = window_size
        self._messages: List[Message] = []
    
    def add(self, message: Message) -> None:
        self._messages.append(message)
        # 保持窗口大小
        non_system = [m for m in self._messages 
                      if m.role != MessageRole.SYSTEM]
        if len(non_system) > self._window_size:
            # 移除最旧的非系统消息
            for i, m in enumerate(self._messages):
                if m.role != MessageRole.SYSTEM:
                    self._messages.pop(i)
                    break
```

**窗口大小选择指南**:

| 场景 | 推荐窗口大小 | 理由 |
|------|-------------|------|
| 简单问答 | 3-5 | 只需最近上下文 |
| 技术支持 | 10-15 | 需要问题描述历史 |
| 复杂对话 | 20-30 | 多步骤任务需要更多上下文 |
| 代码协作 | 30-50 | 代码片段较长 |

### 3.4 策略三: SummaryMemory (摘要记忆)

**核心思想**: 将旧消息压缩为摘要，保留关键信息同时减少 Token 使用。

**工作流程**:
```
原始消息: [M1, M2, M3, M4, M5, M6, M7, M8, M9, M10]
                    ↓ 触发摘要 (超过阈值)
处理后:   [Summary(M1-M5), M6, M7, M8, M9, M10]
                    ↓ 继续对话
          [Summary(M1-M5), Summary(M6-M10), M11, M12, ...]
```

**算法复杂度**:
- 添加: $O(1)$ 正常, $O(s)$ 触发摘要时 ($s$ 为摘要成本)
- 检索: $O(k + \text{summaries})$
- 空间: $O(k + \text{summaries})$

**摘要策略**:

```python
class SimpleSummarizer:
    """简单摘要器 - 提取关键信息"""
    def summarize(self, messages: List[Message]) -> str:
        # 提取每条消息的核心内容
        points = []
        for msg in messages:
            if msg.role == MessageRole.USER:
                points.append(f"用户: {msg.content[:100]}")
            elif msg.role == MessageRole.ASSISTANT:
                points.append(f"助手: {msg.content[:100]}")
        return "对话摘要:\n" + "\n".join(points)

class LLMSummarizer:
    """LLM 摘要器 - 使用大模型生成摘要"""
    def summarize(self, messages: List[Message]) -> str:
        prompt = "请总结以下对话的关键信息:\n"
        for msg in messages:
            prompt += f"{msg.role}: {msg.content}\n"
        return llm.generate(prompt)
```

### 3.5 策略四: TokenBasedMemory (Token 预算)

**核心思想**: 在固定 Token 预算内管理消息，精确控制成本。

**数学模型**:
$$\sum_{m \in \text{Context}} T(m) \leq B - R$$

其中：
- $T(m)$: 消息 $m$ 的 Token 数
- $B$: 总预算
- $R$: 预留空间 (用于回复)

**驱逐策略**:

1. **FIFO (先进先出)**: 移除最旧的消息
2. **重要性优先**: 移除重要性最低的消息
3. **混合策略**: 综合考虑时间和重要性

```python
def _trim_to_budget(self) -> None:
    """驱逐消息直到满足预算"""
    while self.token_count > self._effective_limit:
        # 找到可移除的消息 (非系统消息)
        removable = [(i, m) for i, m in enumerate(self._messages)
                     if m.role != MessageRole.SYSTEM]
        if not removable:
            break
        
        if self._prioritize_recent:
            # FIFO: 移除最旧的
            idx, _ = removable[0]
        else:
            # 重要性: 移除最不重要的
            idx, _ = min(removable, key=lambda x: x[1].importance)
        
        self._messages.pop(idx)
```

## 4. 长期记忆系统

### 4.1 设计目标

长期记忆系统需要满足以下需求：

1. **持久性**: 跨会话保存
2. **可扩展性**: 支持大量记忆
3. **语义检索**: 基于含义而非关键词
4. **高效访问**: 快速检索相关记忆

### 4.3 记忆类型分类

```python
class MemoryType(str, Enum):
```

### 4.4 向量嵌入原理

**文本嵌入**将文本映射到高维向量空间：

$$\text{embed}: \text{Text} \rightarrow \mathbb{R}^d$$

**语义相似性**在向量空间中表现为**几何接近**：

```
向量空间示意:

        "Python编程"
              ●
             /
            /  相似
           /
    "代码开发" ●─────────● "软件工程"
                  相似
    
    
    "烹饪食谱" ●
              (远离，不相似)
```

**嵌入模型对比**:

| 模型 | 维度 | 质量 | 速度 | 成本 | 适用场景 |
|------|------|------|------|------|----------|
| SimpleEmbedding (本项目) | 128 | 低 | 快 | 免费 | 开发测试 |
| all-MiniLM-L6-v2 | 384 | 中 | 快 | 免费 | 本地部署 |
| text-embedding-3-small | 1536 | 高 | 中 | 低 | 生产环境 |
| text-embedding-3-large | 3072 | 最高 | 慢 | 高 | 高精度需求 |

### 4.5 向量存储实现

**InMemoryVectorStore** - 内存向量存储：

```python
class InMemoryVectorStore(VectorStore):
    """
    内存向量存储，使用暴力搜索。
    适用于 < 10,000 条记忆的场景。
    """
    
    def search(self, query_embedding: List[float], k: int = 5,
               filter_fn: Optional[Callable] = None) -> List[Tuple[MemoryEntry, float]]:
        results = []
        for entry in self._entries.values():
            if filter_fn and not filter_fn(entry):
                continue
            similarity = self._cosine_similarity(query_embedding, entry.embedding)
            results.append((entry, similarity))
        
        results.sort(key=lambda x: x[1], reverse=True)
        return results[:k]
    
    @staticmethod
    def _cosine_similarity(a: List[float], b: List[float]) -> float:
        dot = sum(x * y for x, y in zip(a, b))
        norm_a = math.sqrt(sum(x * x for x in a))
        norm_b = math.sqrt(sum(x * x for x in b))
        return dot / (norm_a * norm_b) if norm_a and norm_b else 0.0
```

**扩展到生产环境**:

| 规模 | 推荐方案 | 复杂度 |
|------|----------|--------|
| < 1K | InMemoryVectorStore | $O(n)$ |
| 1K - 100K | FAISS IVF | $O(\sqrt{n})$ |
| 100K - 10M | FAISS HNSW | $O(\log n)$ |

### 4.6 重要性评估

**自动重要性评估**基于启发式规则：

```python
def _estimate_importance(self, content: str) -> float:
    """启发式重要性评估"""
    score = 0.5  # 基础分
    
    # 关键词加分
    keywords = ["important", "remember", "always", "never", "must", "critical"]
    for kw in keywords:
        if kw in content.lower():
            score += 0.1
    
    # 长度加分 (详细信息通常更重要)
    if len(content) > 200:
        score += 0.1
    
    # 问句减分 (问题通常不需要长期记忆)
    if "?" in content:
        score -= 0.1
    
    return max(0.0, min(1.0, score))
```

**高级重要性评估** (使用 LLM):

```python
def llm_importance(content: str) -> float:
    prompt = f"""
    评估以下信息的重要性 (0-1分):
    - 1.0: 关键信息，必须记住
    - 0.7: 重要信息，应该记住
    - 0.5: 一般信息，可以记住
    - 0.3: 次要信息，可能有用
    - 0.0: 不重要，可以忽略
    
    信息: {content}
    
    只返回数字分数:
    """
    return float(llm.generate(prompt))
```

## 5. 记忆检索策略

### 5.1 检索策略概述

记忆检索是记忆系统的核心功能,它决定了 AI Agent 能够从长期记忆中找到相关信息的能力。一个好的检索策略需要平衡**相关性**、**时效性**和**多样性**。

**检索目标**:
- 找到与当前上下文最相关的记忆
- 避免信息过载 (不返回太多记忆)
- 保持记忆的新鲜度 (优先新记忆)
- 提供多样化的视角 (不重复相似内容)

### 5.2 核心评分机制

#### 综合评分公式

记忆检索的核心是**多维度评分**,综合考虑多个因素:

$$\text{score}(m) = \alpha \cdot \text{sim}(q, m) + \beta \cdot \text{recency}(m) + \gamma \cdot \text{importance}(m)$$

其中:
- $\text{sim}(q, m)$: 查询 $q$ 与记忆 $m$ 的语义相似度 [0, 1]
- $\text{recency}(m)$: 记忆的新近度 [0, 1]
- $\text{importance}(m)$: 记忆的重要性 [0, 1]
- $\alpha, \beta, \gamma$: 权重系数,满足 $\alpha + \beta + \gamma = 1$

**通俗解释**:
想象你在找一本书:
- **语义相似度**: 书的内容是否与你想要找的主题相关?
- **新近度**: 这本书是新出版的还是旧书? (新信息通常更有价值)
- **重要性**: 这本书是经典著作还是普通读物? (重要的内容优先考虑)

#### 语义相似度计算

**余弦相似度** (Cosine Similarity):

$$\text{sim}(q, m) = \frac{\vec{q} \cdot \vec{m}}{|\vec{q}| \cdot |\vec{m}|} = \frac{\sum_{i=1}^{d} q_i m_i}{\sqrt{\sum_{i=1}^{d} q_i^2} \cdot \sqrt{\sum_{i=1}^{d} m_i^2}}$$

**直观理解**:
```
向量相似度示意图:

q ●───────● m (相似度高)
    ↖  θ
      ↖
        ● (角度小 = 相似)

q ●───────────────────● m (相似度低)
          θ   ↖
              ↖
                ● (角度大 = 不相似)
```

**数值范围**: -1 到 1
- 1.0: 完全相同 (方向一致)
- 0.0: 正交 (无关)
- -1.0: 完全相反 (方向相反)

在实际应用中,我们通常归一化到 [0, 1]:

```python
def cosine_similarity(a: List[float], b: List[float]) -> float:
    """计算余弦相似度"""
    dot_product = sum(x * y for x, y in zip(a, b))
    norm_a = math.sqrt(sum(x * x for x in a))
    norm_b = math.sqrt(sum(x * x for x in b))
    
    if norm_a == 0 or norm_b == 0:
        return 0.0
    
    raw_similarity = dot_product / (norm_a * norm_b)
    # 归一化到 [0, 1]
    return (raw_similarity + 1) / 2
```

#### 新近度计算

**指数衰减模型**:

$$\text{recency}(m) = e^{-\lambda \cdot \Delta t}$$

其中:
- $\Delta t = t_{\text{now}} - t_{\text{memory}}$: 时间差
- $\lambda$: 衰减率 (控制遗忘速度)

**衰减率选择**:

| $\lambda$ 值 | 半衰期 | 适用场景 |
|-------------|--------|----------|
| 0.01 | ~69 天 | 长期记忆 (用户偏好) |
| 0.1 | ~7 天 | 中期记忆 (项目信息) |
| 1.0 | ~1 天 | 短期记忆 (临时任务) |

```python
def recency_score(memory_time: datetime, current_time: datetime, 
                  decay_rate: float = 0.1) -> float:
    """计算新近度分数"""
    delta = (current_time - memory_time).total_seconds() / 86400  # 转换为天
    return math.exp(-decay_rate * delta)
```

```
假设 decay_rate = 0.1 (半衰期约7天):

1天前创建的记忆:  recency = e^(-0.1×1) = 0.90  (很新)
7天前创建的记忆:  recency = e^(-0.1×7) = 0.50  (中等)
30天前创建的记忆: recency = e^(-0.1×30) = 0.05 (较旧)
```

### 5.3 检索算法实现

#### 基础检索器

```python
class MemoryRetriever:
    """记忆检索器"""
    
    def __init__(self, vector_store: VectorStore, 
                 alpha: float = 0.7,  # 相似度权重
                 beta: float = 0.2,   # 新近度权重
                 gamma: float = 0.1): # 重要性权重
        self.vector_store = vector_store
        self.alpha = alpha
        self.beta = beta
        self.gamma = gamma
    
    def retrieve(self, query: str, k: int = 5,
                 memory_type: Optional[MemoryType] = None) -> List[MemoryEntry]:
        """
        检索相关记忆
        
        Args:
            query: 查询文本
            k: 返回的记忆数量
            memory_type: 记忆类型过滤
        
        Returns:
            按相关性排序的记忆列表
        """
        # 1. 生成查询向量
        query_embedding = self._embed(query)
        
        # 2. 向量搜索
        current_time = datetime.now()
        candidates = self.vector_store.search(query_embedding, k=k*3)
        
        # 3. 重新排序 (综合评分)
        scored_memories = []
        for memory, sim in candidates:
            # 应用类型过滤
            if memory_type and memory.memory_type != memory_type:
                continue
            
            # 计算新近度
            recency = math.exp(-0.1 * (current_time - memory.timestamp).days)
            
            # 综合评分
            score = (self.alpha * sim + 
                    self.beta * recency + 
                    self.gamma * memory.importance)
            
            scored_memories.append((memory, score))
        
        # 4. 排序并返回 Top-K
        scored_memories.sort(key=lambda x: x[1], reverse=True)
        return [memory for memory, _ in scored_memories[:k]]
```

### 5.4 高级检索策略

#### 多样性增强 (MMR)

**问题**: 简单的相似度检索可能返回大量重复内容。

**解决方案**: Maximal Marginal Relevance (MMR)

$$\text{MMR} = \lambda \cdot \text{sim}(q, d) - (1-\lambda) \cdot \max_{d_i \in S} \text{sim}(d, d_i)$$

其中:
- $S$: 已选择的文档集合
- $d$: 候选文档
- $\lambda$: 相关性-多样性权衡参数

**算法流程**:

```python
def mmr_retrieve(query: str, k: int = 5, lambda_param: float = 0.7) -> List[MemoryEntry]:
    """使用 MMR 算法检索多样化的记忆"""
    
    # 1. 获取候选集合 (比目标数量多)
    candidates = retrieve(query, k=k*5)
    
    # 2. 初始化
    selected = []
    remaining = candidates.copy()
    
    # 3. 贪心选择
    while len(selected) < k and remaining:
        best_score = -float('inf')
        best_memory = None
        
        for memory in remaining:
            # 相关性分数
            relevance = similarity(query, memory)
            
            # 多样性分数 (与已选记忆的最大相似度)
            if selected:
                diversity = max(similarity(memory, s) for s in selected)
            else:
                diversity = 0
            
            # MMR 分数
            mmr_score = lambda_param * relevance - (1 - lambda_param) * diversity
            
            if mmr_score > best_score:
                best_score = mmr_score
                best_memory = memory
        
        if best_memory:
            selected.append(best_memory)
            remaining.remove(best_memory)
    
    return selected
```

**示例对比**:

```
查询: "Python 性能优化"

纯相似度检索:
1. "如何提高 Python 代码性能" (相似度: 0.95)
2. "Python 性能调优技巧" (相似度: 0.93) ← 重复
3. "优化 Python 循环性能" (相似度: 0.90) ← 重复
4. "Python 多线程性能" (相似度: 0.88) ← 重复
5. "Python 性能分析工具" (相似度: 0.85) ← 重复

MMR 检索 (λ=0.7):
1. "如何提高 Python 代码性能" (相关性: 0.95, 多样性: 0.00)
2. "使用 NumPy 加速计算" (相关性: 0.75, 多样性: 0.30) ← 不同角度
3. "异步编程提升并发" (相关性: 0.70, 多样性: 0.35) ← 不同方法
4. "Cython 编译优化" (相关性: 0.65, 多样性: 0.40) ← 不同工具
5. "算法复杂度优化" (相关性: 0.60, 多样性: 0.45) ← 不同层面
```

### 5.5 检索效果评估

#### 评估指标

**准确率** (Precision):
$$\text{Precision} = \frac{\text{检索到的相关记忆数}}{\text{检索到的记忆总数}}$$

**召回率** (Recall):
$$\text{Recall} = \frac{\text{检索到的相关记忆数}}{\text{所有相关记忆数}}$$

**F1 分数**:
$$\text{F1} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

**平均倒数排名** (MRR):
$$\text{MRR} = \frac{1}{|Q|} \sum_{i=1}^{|Q|} \frac{1}{\text{rank}_i}$$

其中 $\text{rank}_i$ 是第 $i$ 个查询的第一个相关结果的排名。

#### A/B 测试框架

```python
class RetrievalEvaluator:
    """检索系统评估器"""
    
    def evaluate(self, retriever: MemoryRetriever, 
                 test_queries: List[Query]) -> Dict[str, float]:
        """评估检索性能"""
        
        metrics = {
            'precision@1': [],
            'precision@5': [],
            'mrr': []
        }
        
        for query in test_queries:
            results = retriever.retrieve(query.text, k=5)
            
            # Precision@1
            if results and results[0] in query.relevant_memories:
                metrics['precision@1'].append(1.0)
            else:
                metrics['precision@1'].append(0.0)
            
            # Precision@5
            relevant_at_5 = sum(1 for r in results[:5] 
                              if r in query.relevant_memories)
            metrics['precision@5'].append(relevant_at_5 / 5)
            
            # MRR
            for i, result in enumerate(results):
                if result in query.relevant_memories:
                    metrics['mrr'].append(1.0 / (i + 1))
                    break
            else:
                metrics['mrr'].append(0.0)
        
        # 计算平均值
        return {k: sum(v) / len(v) for k, v in metrics.items()}
```

## 6. 数学基础与算法

### 6.1 向量空间模型

#### 向量表示

文本通过嵌入模型转换为向量:

$$\text{embed}(t) = [e_1, e_2, ..., e_d] \in \mathbb{R}^d$$

其中 $d$ 是向量维度。

**维度选择**:
- **低维** (64-128): 快速但损失语义信息
- **中维** (256-768): 平衡速度和质量
- **高维** (1024-3072): 最佳质量但计算成本高

#### 距离度量

**欧几里得距离** (Euclidean Distance):

$$d_{\text{euclid}}(\vec{a}, \vec{b}) = \sqrt{\sum_{i=1}^{d} (a_i - b_i)^2}$$

**曼哈顿距离** (Manhattan Distance):

$$d_{\text{manhattan}}(\vec{a}, \vec{b}) = \sum_{i=1}^{d} |a_i - b_i|$$

**余弦相似度** (Cosine Similarity):

$$\text{sim}_{\text{cosine}}(\vec{a}, \vec{b}) = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| \cdot |\vec{b}|}$$

**选择指南**:

| 度量方法 | 优点 | 缺点 | 适用场景 |
|---------|------|------|----------|
| 欧几里得距离 | 直观,考虑绝对值 | 对向量长度敏感 | 图像相似度 |
| 曼哈顿距离 | 计算简单 | 稀疏向量表现差 | 网格路径规划 |
| 余弦相似度 | 关注方向,不受长度影响 | 忽略绝对大小 | 文本语义相似度 |

### 6.2 近似最近邻搜索

#### 问题定义

**精确搜索** (Brute Force):
- 时间复杂度: $O(n \cdot d)$
- $n$: 向量数量
- $d$: 向量维度
- 适用于: $n < 10,000$

**近似搜索** (ANN):
- 时间复杂度: $O(\log n \cdot d)$ 或更低
- 牺牲少量精度换取大幅速度提升
- 适用于: $n > 10,000$

#### 树形方法: KD-Tree

**原理**: 递归分割空间

```
2D 空间分割示例:

初始空间:
┌────────────────────────────────────┐
│                                    │
│                                    │
│                                    │
│                                    │
└────────────────────────────────────┘

第一次分割 (按 x 坐标):
┌──────────────┬─────────────────────┐
│              │                     │
│   Region 1   │    Region 2         │
│              │                     │
└──────────────┴─────────────────────┘
      x < 5.0          x >= 5.0

第二次分割 (按 y 坐标):
┌──────────────┬─────────────────────┐
│    R1A       │    R2A              │
│   y < 3.0    │   y < 3.0           │
├──────────────┼─────────────────────┤
│    R1B       │    R2B              │
│  y >= 3.0    │  y >= 3.0           │
└──────────────┴─────────────────────┘
```

**查询过程**:
1. 从根节点开始
2. 根据分割条件选择子树
3. 递归搜索直到叶节点
4. 回溯检查邻近区域

**复杂度**:
- 构建: $O(n \log n)$
- 查询: $O(\log n)$ 平均, $O(n)$ 最坏
- 维度灾难: $d > 20$ 时效率下降

#### 图方法: HNSW (Hierarchical Navigable Small World)

**核心思想**: 分层图结构

```
HNSW 结构示意:

Layer 2 (最高层, 稀疏):
    Entry ───────────────────> Target
           (长距离跳跃)

Layer 1 (中层):
    Entry ───> Node1 ───> Node3 ───> Target
      │           │           │
      └──────> Node2 ────────┘

Layer 0 (最底层, 密集):
    Entry─Node1─Node2─Node3─Node4─Node5─...─Target
      │     │  │  │     │     │           │
      └─────┘  └──┴─────┴─────┴───────────┘
       (局部连接, 精细搜索)
```

**搜索算法**:

```python
def hnsw_search(query: Vector, entry_point: Node, k: int) -> List[Node]:
    """HNSW 搜索算法"""
    
    # 1. 从顶层开始,贪婪搜索到最近邻
    current_point = entry_point
    for layer in reversed(range(max_layer)):
        current_point = _greedy_search_on_layer(
            query, current_point, layer
        )
    
    # 2. 在最底层进行精细搜索
    candidates = [current_point]
    visited = {current_point}
    
    while candidates:
        # 取最近的候选点
        current = candidates.pop(0)
        
        # 检查邻居
        for neighbor in current.neighbors(layer=0):
            if neighbor in visited:
                continue
            
            visited.add(neighbor)
            distance = cosine_distance(query, neighbor.vector)
            
            # 动态维护最近邻列表
            if len(results) < k or distance < results[-1].distance:
                results.insert_sorted(neighbor, distance)
                candidates.add(neighbor)
    
    return results[:k]
```

**优势**:
- 查询速度: $O(\log n)$
- 高召回率 (> 95%)
- 支持增量更新

#### 聚类方法: IVF (Inverted File Index)

**原理**: 预先聚类,搜索时只查询相关聚类

```
IVF 结构示意:

训练阶段:
1. 所有向量 ──K-Means───> 1000 个聚类中心
   [v1, v2, ..., v10000]

2. 构建倒排索引:
   Cluster 0: [v5, v23, v67, ...]
   Cluster 1: [v2, v89, v134, ...]
   ...
   Cluster 999: [v45, v178, v256, ...]

查询阶段:
1. 找到最近的聚类中心 (查询点在 Cluster 5 附近)
2. 只搜索 Cluster 5 及其邻近聚类 (如 4, 6)
3. 在这些聚类中进行精确搜索
```

**参数选择**:
- `nlist`: 聚类数量 (通常 $\sqrt{n}$)
- `nprobe`: 搜索的聚类数量 (通常 1-100)

**权衡**:
```
nprobe = 1:   速度快,召回率低
nprobe = 10:  平衡 (推荐)
nprobe = 100: 召回率高,速度慢
```

### 6.3 优化算法

#### 学习索引

**传统索引**: 固定规则 (如 B-Tree 的二分查找)

**学习索引**: 机器学习模型预测位置

```python
class LearnedIndex:
    """基于学习的索引"""
    
    def __init__(self):
        self.model = LinearRegression()
        self.min_key = None
        self.max_key = None
        self.data_size = 0
    
    def build(self, keys: List[float], positions: List[int]):
        """训练索引模型"""
        self.min_key = min(keys)
        self.max_key = max(keys)
        self.data_size = len(keys)
        
        # 学习 key 到 position 的映射
        X = np.array(keys).reshape(-1, 1)
        y = np.array(positions)
        self.model.fit(X, y)
    
    def predict(self, key: float) -> int:
        """预测位置"""
        # 归一化到 [0, 1]
        normalized = (key - self.min_key) / (self.max_key - self.min_key)
        # 预测位置
        position = int(normalized * self.data_size)
        return max(0, min(self.data_size - 1, position))
    
    def search(self, key: float, actual_data: List) -> Any:
        """搜索操作"""
        # 1. 预测位置
        predicted_pos = self.predict(key)
        
        # 2. 在预测位置附近进行局部搜索
        search_range = 10  # 搜索半径
        left = max(0, predicted_pos - search_range)
        right = min(len(actual_data), predicted_pos + search_range)
        
        # 3. 线性搜索局部范围
        for i in range(left, right):
            if actual_data[i].key == key:
                return actual_data[i].value
        
        return None
```

**优势**:
- 比传统索引更紧凑
- 对均匀分布的数据特别有效
- 可以自适应数据分布

#### 量化压缩

**目标**: 减少内存占用,提升缓存效率

**标量量化** (Scalar Quantization):
```
原始向量 (float32): [1.234, 2.567, 3.890, 4.123]
每个值 4 字节 → 总共 16 字节

量化后 (uint8):    [123,  256,  389,  412]
每个值 1 字节 → 总共 4 字节 (节省 75%)
```

```python
def scalar_quantize(vectors: List[List[float]], 
                    bits: int = 8) -> List[List[int]]:
    """标量量化"""
    
    # 1. 计算每个维度的范围
    dim = len(vectors[0])
    min_vals = [float('inf')] * dim
    max_vals = [float('-inf')] * dim
    
    for v in vectors:
        for i, val in enumerate(v):
            min_vals[i] = min(min_vals[i], val)
            max_vals[i] = max(max_vals[i], val)
    
    # 2. 量化
    quantized = []
    levels = 2 ** bits - 1
    
    for v in vectors:
        quantized_vec = []
        for i, val in enumerate(v):
            # 归一化到 [0, 1]
            normalized = (val - min_vals[i]) / (max_vals[i] - min_vals[i])
            # 量化到整数
            quantized_val = int(normalized * levels)
            quantized_vec.append(quantized_val)
        quantized.append(quantized_vec)
    
    return quantized, min_vals, max_vals
```

**乘积量化** (Product Quantization):
- 将向量分割成子向量
- 对每个子向量分别量化
- 进一步压缩: 每个子向量只需要 8 bits

```
原始向量 (1024 维, float32): 1024 * 4 = 4096 字节

PQ (8 个子向量, 每个 128 维):
  每个子向量量化为 256 个聚类中心之一
  存储: 8 * log2(256) = 8 * 8 = 64 bits = 8 字节
  
压缩比: 4096 / 8 = 512x
```

```python
        # 触发记忆提取和存储
        self._extract_and_store(message)
    
    def get_context(self, query: str, max_tokens: int = 2000) -> str:
        """获取增强的上下文"""
        # 1. 获取短期记忆
        stm_context = self.short_term.get_messages()
        
        # 2. 检索相关长期记忆
        ltm_memories = self.retriever.retrieve(query, k=5)
        
        # 3. 组合上下文
        context_parts = []
        
        # 添加长期记忆
        if ltm_memories:
            context_parts.append("相关记忆:")
            for memory in ltm_memories:
                context_parts.append(f"- {memory.content}")
        
        # 添加短期对话历史
        if stm_context:
            context_parts.append("\n对话历史:")
            for msg in stm_context[-10:]:  # 最近 10 条
                context_parts.append(f"{msg.role}: {msg.content}")
        
        return "\n".join(context_parts)
    
    def _extract_and_store(self, message: Message) -> None:
        """从消息中提取并存储重要信息"""
        # 1. 提取事实
        facts = self._extract_facts(message)
        for fact in facts:
            self.long_term.add(
                content=fact,
                memory_type=MemoryType.FACT,
                source=message.id
            )
        
        # 2. 提取偏好
        preferences = self._extract_preferences(message)
        for pref in preferences:
            self.long_term.add(
                content=pref,
                memory_type=MemoryType.PREFERENCE,
                source=message.id
            )
```

### 7.2 数据持久化

#### 存储方案选择

**内存存储** (In-Memory):
- 优点: 最快访问速度,简单实现
- 缺点: 数据易失,容量有限
- 适用: 开发测试,缓存层

**文件存储** (File-based):
- 优点: 持久化,简单备份
- 缺点: 并发性能差,扩展性差
- 适用: 单机应用,原型系统

**关系数据库** (PostgreSQL/MySQL):
- 优点: ACID 保证,成熟生态
- 缺点: 向量搜索需要插件
- 适用: 结构化元数据存储

**向量数据库** (Pinecone/Milvus/Weaviate):
- 优点: 专为向量优化,高性能
- 缺点: 学习成本,运维复杂
- 适用: 生产环境,大规模部署

### 7.3 并发控制

#### 读写锁

```python
import threading

class RWLock:
    """读写锁"""
    
    def __init__(self):
        self._readers = 0
        self._writers = 0
        self._read_ready = threading.Condition(threading.Lock())
        self._write_ready = threading.Condition(threading.Lock())
    
    def acquire_read(self):
        """获取读锁"""
        self._read_ready.acquire()
        try:
            while self._writers > 0:
                self._read_ready.wait()
            self._readers += 1
        finally:
            self._read_ready.release()
    
    def release_read(self):
        """释放读锁"""
        self._read_ready.acquire()
        try:
            self._readers -= 1
            if self._readers == 0:
                self._write_ready.notify()
        finally:
            self._read_ready.release()
    
    def acquire_write(self):
        """获取写锁"""
        self._write_ready.acquire()
        self._writers += 1
        self._write_ready.release()
        
        self._read_ready.acquire()
        while self._readers > 0:
            self._read_ready.wait()
    
    def release_write(self):
        """释放写锁"""
        self._readers = 0  # 清空读者
        self._writers -= 1
        self._read_ready.notifyAll()
        self._read_ready.release()

class ConcurrentMemoryStore:
    """并发安全的记忆存储"""
    
    def __init__(self):
        self._memories = {}
        self._lock = RWLock()
    
    def add(self, memory: MemoryEntry) -> None:
        """添加记忆 (写操作)"""
        self._lock.acquire_write()
        try:
            self._memories[memory.id] = memory
        finally:
            self._lock.release_write()
    
    def get(self, memory_id: str) -> Optional[MemoryEntry]:
        """获取记忆 (读操作)"""
        self._lock.acquire_read()
        try:
            return self._memories.get(memory_id)
        finally:
            self._lock.release_read()
    
    def search(self, query: str) -> List[MemoryEntry]:
        """搜索记忆 (读操作)"""
        self._lock.acquire_read()
        try:
            return [m for m in self._memories.values() 
                   if query.lower() in m.content.lower()]
        finally:
            self._lock.release_read()
```

#### 指数退避重试

```python
import time
import random

def retry_with_backoff(func, max_retries=3, base_delay=1.0, max_delay=60.0):
    """带指数退避的重试装饰器"""
    
    def wrapper(*args, **kwargs):
        for attempt in range(max_retries):
            try:
                return func(*args, **kwargs)
            except Exception as e:
                if attempt == max_retries - 1:
                    raise  # 最后一次重试失败,抛出异常
                
                # 计算延迟: base_delay * (2 ^ attempt) + 随机抖动
                delay = min(
                    base_delay * (2 ** attempt) + random.uniform(0, 1),
                    max_delay
                )
                
                print(f"Attempt {attempt + 1} failed: {e}. "
                      f"Retrying in {delay:.2f}s...")
                time.sleep(delay)
    
    return wrapper

# 使用示例
```

```python
from enum import Enum
from datetime import datetime, timedelta

class CircuitState(Enum):
    CLOSED = "closed"       # 正常工作
    OPEN = "open"           # 熔断 (快速失败)
    HALF_OPEN = "half_open" # 半开 (尝试恢复)

class CircuitBreaker:
    """断路器"""
    
    def __init__(self, 
                 failure_threshold=5,
                 timeout=60,
                 success_threshold=2):
        self.failure_threshold = failure_threshold
        self.timeout = timeout  # 熔断持续时间 (秒)
        self.success_threshold = success_threshold  # 半开状态成功次数
        
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.success_count = 0
        self.last_failure_time = None
    
    def call(self, func, *args, **kwargs):
        """通过断路器调用函数"""
        
        # 检查是否应该尝试恢复
        if self.state == CircuitState.OPEN:
            if datetime.now() - self.last_failure_time > timedelta(seconds=self.timeout):
                self.state = CircuitState.HALF_OPEN
                self.success_count = 0
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = func(*args, **kwargs)
            
            # 成功: 更新状态
            if self.state == CircuitState.HALF_OPEN:
                self.success_count += 1
                if self.success_count >= self.success_threshold:
                    self.state = CircuitState.CLOSED
                    self.failure_count = 0
            elif self.state == CircuitState.CLOSED:
                self.failure_count = 0
            
            return result
            
        except Exception as e:
            # 失败: 更新状态
            self.failure_count += 1
            self.last_failure_time = datetime.now()
            
            if self.failure_count >= self.failure_threshold:
                self.state = CircuitState.OPEN
            
            raise e
```

### 8.1 缓存策略

#### 多级缓存架构

```
L1 Cache (内存): 最热数据,最快访问
    ↓ (miss)
L2 Cache (Redis): 热数据,快速访问
    ↓ (miss)
L3 Storage (DB): 全量数据,较慢访问
```

```python
class MultiLevelCache:
    """多级缓存"""
    
    def __init__(self):
        self.l1_cache = {}  # 内存缓存
        self.l2_client = redis.Redis()  # Redis 缓存
        self.db_client = DatabaseClient()
    
    def get(self, key: str) -> Optional[Any]:
        """获取数据 (从 L1 到 L3)"""
        
        # L1: 内存缓存
        if key in self.l1_cache:
            return self.l1_cache[key]
        
        # L2: Redis 缓存
        value = self.l2_client.get(key)
        if value:
            self.l1_cache[key] = value  # 回填 L1
            return value
        
        # L3: 数据库
        value = self.db_client.get(key)
        if value:
            self.l2_client.setex(key, 3600, value)  # 回填 L2
            self.l1_cache[key] = value  # 回填 L1
        
        return value
    
    def set(self, key: str, value: Any, ttl: int = 3600) -> None:
        """设置数据 (写入所有层级)"""
        self.l1_cache[key] = value
        self.l2_client.setex(key, ttl, value)
        self.db_client.set(key, value)
```

#### 缓存淘汰策略

**LRU (Least Recently Used)**:

```python
from collections import OrderedDict

class LRUCache:
    """LRU 缓存"""
    
    def __init__(self, capacity: int):
        self.cache = OrderedDict()
        self.capacity = capacity
    
    def get(self, key: str) -> Optional[Any]:
        """获取数据 (更新访问顺序)"""
        if key not in self.cache:
            return None
        
        # 移到末尾 (最近使用)
        self.cache.move_to_end(key)
        return self.cache[key]
    
    def put(self, key: str, value: Any) -> None:
        """添加数据"""
        if key in self.cache:
            self.cache.move_to_end(key)
        else:
            if len(self.cache) >= self.capacity:
                # 移除最久未使用的项
                self.cache.popitem(last=False)
        
        self.cache[key] = value
```

**LFU (Least Frequently Used)**:

```python
import heapq

class LFUCache:
    """LFU 缓存"""
    
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.key_to_value = {}
        self.key_to_freq = {}
        self.freq_to_keys = defaultdict(set)
        self.min_freq = 0
    
    def get(self, key: str) -> Optional[Any]:
        """获取数据"""
        if key not in self.key_to_value:
            return None
        
        # 增加访问频率
        self._increase_freq(key)
        return self.key_to_value[key]
    
    def put(self, key: str, value: Any) -> None:
        """添加数据"""
        if self.capacity <= 0:
            return
        
        if key in self.key_to_value:
            self._increase_freq(key)
            self.key_to_value[key] = value
            return
        
        # 容量检查
        if len(self.key_to_value) >= self.capacity:
            # 移除最低频率的键
            min_freq_keys = self.freq_to_keys[self.min_freq]
            evict_key = min_freq_keys.pop()
            if not min_freq_keys:
                del self.freq_to_keys[self.min_freq]
            del self.key_to_value[evict_key]
            del self.key_to_freq[evict_key]
        
        # 添加新项
        self.key_to_value[key] = value
        self.key_to_freq[key] = 1
        self.freq_to_keys[1].add(key)
        self.min_freq = 1
    
    def _increase_freq(self, key: str) -> None:
        """增加访问频率"""
        old_freq = self.key_to_freq[key]
        new_freq = old_freq + 1
        
        # 更新频率
        self.key_to_freq[key] = new_freq
        self.freq_to_keys[old_freq].remove(key)
        self.freq_to_keys[new_freq].add(key)
        
        # 清理空集合
        if not self.freq_to_keys[old_freq]:
            del self.freq_to_keys[old_freq]
            if old_freq == self.min_freq:
                self.min_freq += 1
```

### 8.2 批处理优化

#### 向量批处理

```python
class BatchEmbeddingService:
    """批处理嵌入服务"""
    
    def __init__(self, batch_size: int = 100, timeout: float = 0.1):
        self.batch_size = batch_size
        self.timeout = timeout
        self.queue = []
        self.lock = threading.Lock()
        self.results = {}
    
    def embed_async(self, text: str) -> str:
        """异步嵌入 (返回任务 ID)"""
        task_id = str(uuid.uuid4())
        
        with self.lock:
            self.queue.append((task_id, text))
            
            # 达到批量大小时触发处理
            if len(self.queue) >= self.batch_size:
                self._process_batch()
        
        return task_id
    
    def get_result(self, task_id: str, timeout: float = 1.0) -> List[float]:
        """获取结果 (阻塞等待)"""
        start = time.time()
        while task_id not in self.results:
            if time.time() - start > timeout:
                raise TimeoutError("Embedding timeout")
            time.sleep(0.01)
        
        return self.results.pop(task_id)
    
    def _process_batch(self) -> None:
        """处理批量任务"""
        batch = self.queue[:self.batch_size]
        self.queue = self.queue[self.batch_size:]
        
        # 提取文本
        texts = [text for _, text in batch]
        task_ids = [task_id for task_id, _ in batch]
        
        # 批量调用 API
        embeddings = self._call_api_batch(texts)
        
        # 存储结果
        for task_id, embedding in zip(task_ids, embeddings):
            self.results[task_id] = embedding
    
    def _call_api_batch(self, texts: List[str]) -> List[List[float]]:
        """批量调用 API"""
        response = openai.Embedding.create(
            model="text-embedding-3-small",
            input=texts
        )
```

#### 水平分片

```python
class ShardedVectorStore:
    """分片向量存储"""
    
    def __init__(self, num_shards: int = 10):
        self.shards = [InMemoryVectorStore() for _ in range(num_shards)]
        self.num_shards = num_shards
    
    def _get_shard(self, key: str) -> InMemoryVectorStore:
        """根据键获取分片"""
        shard_id = hash(key) % self.num_shards
        return self.shards[shard_id]
    
    def add(self, memory: MemoryEntry) -> None:
        """添加记忆 (路由到对应分片)"""
        shard = self._get_shard(memory.id)
        shard.add(memory)
    
    def search(self, query_embedding: List[float], 
               k: int = 5) -> List[Tuple[MemoryEntry, float]]:
        """搜索所有分片并合并结果"""
        
        # 并行搜索所有分片
        with ThreadPoolExecutor() as executor:
            futures = [
                executor.submit(shard.search, query_embedding, k)
                for shard in self.shards
            ]
            
            all_results = []
            for future in futures:
                all_results.extend(future.result())
        
        # 全局排序并返回 Top-K
        all_results.sort(key=lambda x: x[1], reverse=True)
        return all_results[:k]
```

```python
class ReadWriteSeparatedMemory:
    """读写分离的记忆系统"""
    
    def __init__(self, master_config: dict, replica_configs: List[dict]):
        self.master = VectorStore(**master_config)
        self.replicas = [VectorStore(**config) for config in replica_configs]
        self.current_replica = 0
    
    def add(self, memory: MemoryEntry) -> None:
        """写操作 -> 主节点"""
        self.master.add(memory)
    
    def get(self, memory_id: str) -> Optional[MemoryEntry]:
        """读操作 -> 从节点 (负载均衡)"""
        replica = self._get_replica()
        return replica.get(memory_id)
    
    def search(self, query_embedding: List[float], 
               k: int = 5) -> List[Tuple[MemoryEntry, float]]:
        """搜索 -> 从节点"""
        replica = self._get_replica()
        return replica.search(query_embedding, k)
    
    def _get_replica(self) -> VectorStore:
        """轮询选择从节点"""
        replica = self.replicas[self.current_replica]
        self.current_replica = (self.current_replica + 1) % len(self.replicas)
        return replica
```

### 10.1 神经符号记忆系统

```
                    │   Perceptual    │
                    │   (神经网络)     │
                    │  - 模式识别      │
                    │  - 向量表示      │
                    └────────┬────────┘

                             ▼

                    │  Symbolic Layer │
                    │   (符号系统)     │
                    │  - 逻辑推理      │
                    │  - 知识图谱      │
                    │  - 因果关系      │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │  Executive      │
                    │  Control        │
                    │  (决策控制)      │
                    └─────────────────┘
```

**优势**:
- 神经网络: 处理模糊,不完整的输入
- 符号系统: 提供可解释的推理过程
- 结合: 兼具灵活性和逻辑性

```python
class NeuroSymbolicMemory:
    """神经符号记忆系统"""
    
    def __init__(self):
        # 神经网络部分: 向量存储
        self.vector_store = VectorStore()
        
        # 符号部分: 知识图谱
        self.knowledge_graph = KnowledgeGraph()
        
        # 推理引擎
        self.reasoner = LogicalReasoner()
    
    def add_memory(self, content: str, facts: List[Fact]):
        """添加记忆 (双重表示)"""
        
        # 1. 神经表示: 向量化
        embedding = self.embed(content)
        self.vector_store.add(content, embedding)
        
        # 2. 符号表示: 提取事实和关系
        for fact in facts:
            self.knowledge_graph.add_entity(fact.subject)
            self.knowledge_graph.add_entity(fact.object)
            self.knowledge_graph.add_relation(
                fact.subject, 
                fact.predicate, 
                fact.object
            )
    
    def query(self, question: str) -> QueryResult:
        """查询 (结合检索和推理)"""
        
        # 1. 神经检索: 找到相关记忆
        similar_memories = self.vector_store.search(question, k=5)
        
        # 2. 符号推理: 逻辑推导
        logical_conclusions = self.reasoner.deduce(
            question,
            self.knowledge_graph
        )
        
        # 3. 结合结果
        return QueryResult(
            retrieved_memories=similar_memories,
            deduced_facts=logical_conclusions
        )
```

```python
    """动态记忆网络"""
    
    def __init__(self):
        self.memory_slots = []  # 动态记忆槽
        self.controller = MemoryController()
    
    def write(self, information: Any, importance: float):
        """写入记忆 (动态分配)"""
        
        # 1. 评估是否需要新记忆槽
        if not self._has_capacity(information, importance):
            # 驱逐低重要性记忆
            self._evict_least_important()
        
        # 2. 创建或更新记忆槽
        slot = MemorySlot(
            content=information,
            importance=importance,
            timestamp=datetime.now()
        )
        
        self.memory_slots.append(slot)
    
    def read(self, query: str) -> List[Any]:
        """读取记忆 (注意力机制)"""
        
        # 计算查询与每个记忆槽的注意力权重
        attention_weights = []
        for slot in self.memory_slots:
            weight = self._compute_attention(query, slot)
            attention_weights.append(weight)
        
        # 加权读取
        result = []
        for slot, weight in zip(self.memory_slots, attention_weights):
            if weight > 0.1:  # 阈值过滤
                result.append((slot.content, weight))
        
        return sorted(result, key=lambda x: x[1], reverse=True)
    
    def _compute_attention(self, query: str, slot: MemorySlot) -> float:
        """计算注意力权重"""
        # 综合相关性、新近度、重要性
        relevance = self._similarity(query, slot.content)
        recency = self._recency(slot.timestamp)
        
        return 0.7 * relevance + 0.2 * recency + 0.1 * slot.importance
```

```python
class FederatedMemory:
    """联邦记忆系统"""
    
    def __init__(self):
        self.local_model = EmbeddingModel()
        self.global_model = None
    
    def local_update(self, local_data: List[str]):
        """本地训练"""
        # 在本地数据上训练
        self.local_model.train(local_data)
        
        # 生成模型更新 (梯度或参数)
        model_update = self.local_model.get_update()
        return model_update
    
    def aggregate_updates(self, updates: List[ModelUpdate]) -> ModelUpdate:
        """聚合更新 (联邦平均)"""
        
        # 简单平均
        aggregated = ModelUpdate()
        for param_name in updates[0].keys():
            values = [update[param_name] for update in updates]
            aggregated[param_name] = sum(values) / len(values)
        
        return aggregated
    
    def apply_global_update(self, global_update: ModelUpdate):
        """应用全局更新"""
        self.local_model.apply_update(global_update)
```

### 10.4 多模态记忆

#### 跨模态检索

支持文本、图像、音频等多种模态的记忆:

```python
class MultiModalMemory:
    """多模态记忆系统"""
    
    def __init__(self):
        self.text_encoder = TextEncoder()
        self.image_encoder = ImageEncoder()
        self.audio_encoder = AudioEncoder()
        self.fusion_layer = FusionLayer()
        self.vector_store = VectorStore()
    
    def add_memory(self, content: Any, modality: str):
        """添加多模态记忆"""
        
        # 根据模态选择编码器
        if modality == "text":
            embedding = self.text_encoder.encode(content)
        elif modality == "image":
            embedding = self.image_encoder.encode(content)
        elif modality == "audio":
            embedding = self.audio_encoder.encode(content)
        else:
            raise ValueError(f"Unknown modality: {modality}")
        
        # 存储向量
        self.vector_store.add(
            id=str(uuid.uuid4()),
            vector=embedding,
            metadata={"modality": modality, "content": content}
        )
    
    def cross_modal_retrieve(self, query: Any, 
                            query_modality: str, 
                            target_modality: str = None) -> List[Any]:
        """跨模态检索"""
        
        # 编码查询
        if query_modality == "text":
            query_embedding = self.text_encoder.encode(query)
        elif query_modality == "image":
            query_embedding = self.image_encoder.encode(query)
        
        # 检索
        results = self.vector_store.search(query_embedding, k=10)
        
        # 过滤目标模态
        if target_modality:
            results = [
                r for r in results 
                if r.metadata["modality"] == target_modality
            ]
        
        return results
```
